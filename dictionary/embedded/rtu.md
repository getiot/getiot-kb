# RTU 远程终端单元



**RTU** 是 Remote Terminal Unit 的缩写，即远程终端单元。也称为远程终端控制系统，负责对现场信号、工业设备的监测和控制。

RTU 是构成企业综合自动化系统的核心装置，通常由信号输入/输出模块、微控制器、有线/无线通讯设备、电源及外壳等部分组成。RTU 支持多种网络协议，通过自身的控制软件，可以实现企业中央监控与调度系统对生产现场一次仪表的遥测、遥控、遥信和遥控等功能。

与 [DTU](/dictionary/dtu/) 相比，RTU 具备控制功能，能够采集数字量、模拟量的输入，控制数字量、模拟量的输出。
