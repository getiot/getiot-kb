# DTU 数据传输单元



**DTU** 是 Data Transfer Unit 的缩写，即数据传输单元。是专门用于将串口数据转换为 IP 数据，或将 IP 数据转换为串口数据，并通过 GPRS 等移动通信网络进行传送的无线终端设备。

![](https://static.getiot.tech/ato-dtu-data-transfer-unit.jpg#center-300)

DTU 在物联网领域应用非常广泛，通常用于在远端将 PLC、监测仪表等下位机设备的数据透传到服务器上。我们可以把 DTU 看作一个网关设备，不具备联网能力的设备通过连接一个 DTU 模块，就可以赋予其物联网连接能力。

![](https://static.getiot.tech/application-scenario-of-data-transfer-unit-dtu.jpg#center)
