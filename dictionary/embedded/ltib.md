# LTIB



**LTIB**（Linux Target Image Builder）是一个开发符合 GNU/Linux 标准映像的构建工具，LTIB 支持 BootLoader 和 kernel 的构建，包含数百个软件包以及通用跨平台的根文件系统，可用于为许多嵌入式目标平台（包括 PowerPC、ARM、Coldfire）开发和部署 BSP（板级支持包）。 

LTIB 项目最早由飞思卡尔公司开发，由于 Linux 开源世界太多软件版本不断升级，不同的软件由不同的志愿者维护，因此相互之间存在兼容性问题。因此，LTIB 项目就是要整合众多开源软件，其目标是尽量提供一个方便使用的软件包，避免那些琐碎繁杂的配置安装工作。

除了 LTIB，常见的 Linux 构建工具还包括 T2 SDE、PTXdist、buildroot、uClinux-dist、Denx ELDK、OpenEmbedded 等。
