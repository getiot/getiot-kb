# 什么是 Web 3.0？

![](https://static.getiot.tech/web3-banner.jpg#center)

## Web 3.0 是什么 

Web 3.0，即第三代互联网，意思是由 DLT（分布式账本技术）支持的、基于区块链的去中心化网络世界，也将是驱动元宇宙的基础建设技术。简单来说，Web 3.0 就是互联网的区块链化。

Web 3.0 通常有四个标签：

1. 统一的身份认证系统
2. 数据确权与授权
3. 隐私保护与抗审查
4. 去中心化运行

在 Web 3.0 的世界里，所有权及掌控权均是去中心化的，建设者和用户都可持有 NFT 等代币而享有特定网络服务。Web 3.0 能否在未来成为主流，仍是未知之数。但在全球区块链技术热潮带动下，Web 3.0 不再是纸上谈兵的理论或流行用语，而是颠覆网络世界的科技革命。

## Web 1.0、Web 2.0、Web 3.0 的区别

![](https://static.getiot.tech/web123.jpg#center)

### Web 1.0（1990-2005年）

Web 1.0 或者说第一代互联网，主要特点是网络平台单向地向用户提供内容，而大多数用户则都是内容消费者，创作者则是构建网站的开发人员或运营人员。

中国早期的三大门户网站 —— 搜狐、新浪、网易就是 Web 1.0 的典型代表。

Web 1.0 的模式是平台创造、平台所有、平台控制、平台受益。

### Web 2.0（2005-2020年）

Web 2.0 或者说第二代互联网，也就是当代的网络形式。内容具有互动性，用户不仅可以在网络平台上传自己的内容，包括文字、图片、视频等，还可以与其他用户进行交流。互联网从平台向用户的单向传播，变成了用户与用户的双向互动。

抖音、博客、微博、豆瓣、知乎、推特（Twitter）、Meta 等平台都是 Web 2.0 的典型代表。

Web 2.0 的模式是用户创造、平台所有、平台控制、平台分配。

### Web 3.0（目前处于开端）

Web 3.0 背后的概念是，让数据本身依托于开放的数学算法与协议，不依赖于机构甚至个人。建立 Web 3.0 的应用程序成为 DApp（Decentralized Application），强调网络开放而且分散地安全。

对用户而言，Web 3.0 和 Web 2.0 的体验可能相差不大，差异主要在于使用者或创作者能对自己贡献的内容保有所有权，而能获得一定程度的回报。隐私方面，用户能清楚知道这些数据的用途，并且具有决策权。

Web 3.0 的模式是用户创造、用户所有、用户控制、协议分配。
