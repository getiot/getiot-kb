# 什么是区块链？



区块链由两个英文单词 Block 和 Chain 组成，顾名思义，它包含两个方面的意思 —— Block（模块、单元），表示每一个账户存储信息；Chain（链条），表示一连串的交易，而交易的细节就存在 Block 中。



## 比特币和区块链

比特币实际上是一个由随机数算法产生的随机数，这个随机数在整个互联网上是唯一的，而且是可以验证其真伪的。比特币在被挖矿者挖出来时，就产生一个带有这样特殊随机数的 Block，当这个比特币通过交易转到第二个人手里时，在该 Block 中就记录下了交易的信息，这个过程本质上是一个加密的信息传输过程。一旦交易完成，它就被通知到整个互联网上，大家就知道相应的比特币的拥有者改变了。

所有比特币散布在整个互联网中，通过公开密钥来发送和传播，拥有者和交易的过程都是匿名的，而且没有一个中心能够集中控制，因此特别适合洗钱。



## 区块链的应用

除了像比特币这种记录钱的交易，区块链还能用于记录其他的交易和传输。如果在每一件商品制造出来时就产生这样一个区块链，并且在运输和销售时利用区块链记录全过程，那么这个商品整个生命周期的流通过程就是可追踪的。当消费者购买这个商品时，就可以看到这个产品是如何一步步流转到自己手上。由于区块链和商品是一一对应的，既然不可能产生两个相同的区块链，也就不可能复制同一个商品，从而杜绝假冒伪劣产品。

当然，要实现上述过程还需要 RFID 等技术，来自动记录每一件商品的流通和交易的全过程。总而言之，区块链和 RFID 等技术的应用会使得我们未来的社会变得更加精细化和智能化。
