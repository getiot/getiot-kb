# 什么是“新基建”？



**新基建**（China New Infrastructure）是“新型基础设施建设”的简称，是在智慧经济时代相对于传统基建（俗称的“铁公基”）提出的新概念。

新基建主要包括 5G 基站建设、特高压、城际高速铁路和城市轨道交通、新能源汽车充电桩、大数据中心、人工智能、工业互联网七大领域。

![](https://static.getiot.tech/new-infrastructure-china-2021.png#center)

业内通常将其分类为信息网、交通网和能源网三大网络。

|   信息网   |      交通网      |      能源网      |
| :--------: | :--------------: | :--------------: |
| 5G基站建设 | 高铁、城轨、城际 |      特高压      |
| 大数据中心 |                  | 新能源汽车充电桩 |
|  人工智能  |                  |                  |
| 工业互联网 |                  |                  |

新基建离不开物联网，物联网可以说是“无处不在，无所不用”，在互联网基础上解决人与物、物与物之间的关系。大数据中心的数据采集、融合人工智能的 AIoT、工业互联设备和平台的建设、泛在电力物联网等领域都可以找出物联网技术和设备所能应用的场景。具体来说，由于新基建的数据采集和传输是必不可少的，那么物联网感知层、传输层、平台层、应用层使用场景必不可少。
