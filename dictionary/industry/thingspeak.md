# ThingSpeak 物联网平台



**ThingSpeak** 是 Mathworks 公司在物联网（Internet of Things）大潮下推出的一个产品线，它是一个提供物联网数据收集和数据分析（IoT Analytics）的云平台。通过 ThingSpeak 平台服务，能够帮助用户聚合、可视化和分析云中的实时数据流。

大多数使用 Thingspeak 的用户都是 Maker（创客），他们有工程和硬件方面的经验，开发和使用可联网的硬件收集数据，并把数据传向云端，Thingspeak 扮演的角色是物联网的后端，即免费存储硬件所收集的数据，以及提供免费的在线使用 MATLAB 分析这些数据的功能。当然，您也可以从 ThingSpeak 通道（Channel ）读取数据，以便在 MATLAB 中进行分析或可视化。还可以将数据从 MATLAB 写入通道，并在通道上可视化结果。

![](https://static.getiot.tech/thingspeak-matlab-simulink.svg#center)

使用 ThingSpeak  通过互联网（或局域网）使用 HTTP 和 MQTT 协议存储和检索事物的数据，可以创建传感器记录应用程序、位置跟踪应用程序以及带有状态更新的社交网络。MATLAB 的 Thingspeak 工具箱可以让把这些小程序的执行结果保存在 Thingspeak 的通道当中。这些程序功能看上去简单，但是都是有云端的服务自动帮你执行，你甚至不需要在本地安装 MATLAB。从这个角度来看，Thingspeak 把 MATLAB 从一个语言，转成了一种服务。
