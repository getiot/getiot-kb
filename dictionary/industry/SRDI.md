# 什么是“专精特新”？

“专精特新”是国家为引导中小企业走专业化、精细化、特色化、新颖化发展之路，增强自主创新能力和核心竞争力，不断提高中小企业发展质量和水平而实施的重大工程。也是从“中国制造”到“中国智造”的战略转型。

## 起源

- **政策起点**
  - 2011年：工信部首次提出"专精特新"培育概念
  - 2021年：北交所成立，定位"服务创新型中小企业主阵地"
  - 十四五规划：明确发展"单项冠军"和"小巨人"企业
  - 2022年："专精特新"写入政府工作报告
- **国际背景呼应**
  - 德国"隐形冠军"理论（赫尔曼·西蒙）对比
  - 日本"町工厂"匠人精神借鉴
  - 美国"利基市场"创新模式参考



## 定义

“专精特新”的英文缩写是 **SRDI**，对应四个单词 Specialized、Refinement、Differential 和 Innovation，具体含义如下。

| 中文       | 英文         | 描述                                                         |
| ---------- | ------------ | ------------------------------------------------------------ |
| **专业化** | Specialized  | 指采用专项技术或工艺通过专业化生产制造的专用性强、专业特点明显、市场专业性强的产品。 |
| **精细化** | Refinement   | 指采用先进适用技术或工艺，按照精益求精的理念，建立精细高效的管理制度和流程，通过精细化管理，精心设计生产的精良产品。 |
| **特色化** | Differential | 指采用独特的工艺、技术、配方或特殊原料研制生产的，具有地域特点或具有特殊功能的产品。 |
| **新颖化** | Innovation   | 指依靠自主创新、转型科技成果、联合创新或引进消化吸收再创新方式研制生产的，具有自主知识产权的高新技术产品。 |



## 启示

2015年《政府工作报告》中首次提出实施“中国制造2025”，坚持创新驱动、智能转型、强化基础、绿色发展，加快从制造大国转向制造强国。要实现这一目标，就需要各类技术企业的支撑，尤其是专精特新企业。他们在产业链中起到关键作用，解决“卡脖子”技术问题，比如芯片、人工智能、工业软件、新材料等领域。

建议大学应届毕业生找工作，除了关注“大厂”以外，可以多留意所在城市的“专精特新”企业。以物联网为例，物联网产业链涵盖传感器、通信模组、边缘计算、云平台等多环节，有许多专精特新企业聚焦不同细分领域。例如四足机器人公司「宇树科技」、气体传感器市占率全球前三的「汉威科技」、覆盖全国20万农田的「托普云农」、5G 模组供应商「广和通」、智能语音模组供应商「云知声」、远程心电监测设备商「乐普医疗」等等。
