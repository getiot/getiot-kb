# 什么是 IFTTT？

![](https://static.getiot.tech/if-this-then-that.png#center)

**IFTTT** 是 “If This Then That” 的简写，也就是如果发生了这件事，则执行另一件事。同时，IFTTT 也是一个网络服务平台，通过其他不同平台的条件来决定是否执行下一条命令。它在物联网领域备受青睐，可理解为各种不同互联网平台与现实世界的桥梁。

IFTTT 公司于 2010 年创立，2011 年 9 月开始推出服务，支持包括 LinkedIn、Dropbox、Evernote 以及 Instagram 等许多网络应用。简单来说，使用 IFTTT 可以帮你轻松串联各种云端服务。

IFTTT 是通过各应用的 API 授权，根据 “if this then that” 的逻辑，自动帮你将网络应用们相互连接的应用。可以说 IFTTT 是应用的应用，针对整个互联网的宏语言。IFTTT 的关联逻辑曾激发了很多人强烈的创造欲，为自己量身打造触发事件。比如：

- 如果（IF）室温低于 17 ℃，那么（Then）给我发一条短信或电子邮件。
- 如果（IF）我离开家了，那么（Then）关闭家里的 Hue 灯。（注：Hue 是飞利浦的智能灯）

IFTTW 寻找下述问题的答案：

- 是该做预防性维护的时间了吗？
- 是该调整配置的时间吗？
- 是该预定消耗品的时间了吗？
- 是到了采购新配件的时候了吗？
- 是到需要技术人员的时候了吗？
- 我们需要更换产品吗？如果更换？

当你在物联网解决方案中使用分析引擎的时候，你拿到的不只是后视镜看到的东西(例如事件的历史日志)，还包括未来的预测（基于历史日志训练出来的模型）。

机器学习算法会将大量的数据，数十亿的信息点，转换成清晰的模式。通过检查历史系统中的数据，来了解过去发生了什么，机器学习算法会找到哪些人类很难找到的预测模型。

这些预测帮助生成解决问题的策略和方法，通过类似事情和场景的经验上可以获得启发，可以适配到各种重要的系统中。如果我们能够提前知道问题或者不期望的结果，那么我们就可以使用这些使能来影响商业决策流程。

例如，让我们看一个关于自动泊车亭物联网解决方案 (如图 5-2) 。通过预测分析，车场的管理员发现停车亭是否有失效出错的可能，提醒他采取一些预防措施。这这种场景下，机器学习算法通过对历史数据分析发现，当每天有大量的停车交易，然后伴随着大量的落差，同时外部平均空气低于某个门槛是，停车亭的信用卡接收器就会在短时间内失败。这些启发式算法，通过从一组不同情境因素和长时间数据得来，需要现场工程师几十年地经验才能让产品了解。这些发现，让机器学习算法，成为了停车亭的一个新的输入，一个预测 API。
