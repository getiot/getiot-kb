# 飞浆



**飞浆**是百度研发的一款技术领先、功能完备的产业级深度学习开源开放平台。它集深度学习核心框架、基础模型库、端到端开发套件、工具组件和服务平台为一体，助力产业智能化，致力于让深度学习技术的创新与应用更简单，与合作伙伴一起帮助越来越多的行业完成 AI 能力赋能。

![](https://static.getiot.tech/paddlepaddle-framework.png#center)

飞浆四大领先技术：

1. 开发便捷的产业级深度学习框架
2. 支持超大规模深度学习模型的训练
3. 多端多平台部署、高性能推理引擎
4. 面向产业应用、开源开放、覆盖多领域的工业级模型库

应用案例：

- 与北京林业大学合作的“AI识别虫”
- 智能零件质检机
- 与南方电网广东能源技术公司联合研发的电网智能巡检解决方案

随着飞浆赋能行业进程的加快，小到智能桃子分拣机、零件质检，大到城市规划、病虫害监测、无人驾驶、预防性医疗保健等，飞浆已在工业、农业、服务业、零售、通讯、地产、医疗、互联网等众多行业中实现落地应用。
