# EdgerOS

![](https://static.getiot.tech/edgeros-logo.png#center)

**EdgerOS** 是一款基于翼辉 SylixOS 内核打造的消费级智能边缘计算操作系统，从层次关系上与 Android 使用 Linux 内核类似。可应用于面向智慧家庭、智慧汽车、智慧园区等领域，有效降低开发门槛、缩短开发周期，为物联网带来全新智慧化体验。


**EdgerOS 主要特点：**

- 自主研发，稳定可靠，生命力强，高度可定制；
- 采用互联网技术栈，功能丰富，高度封装，开发非常简单；
- 开放平台，兼容不同厂商设备，激发无限创意；
- 连接能力强，支持以太网、Wi-Fi、ZigBee、LoRa 等通信协议；
- 平台应用天然支持多用户和远程访问；
- 方便的应用管理和分发；
- 一套代码实现 iOS、Android、Windows、macOS 和 Linux 等全平台支持；
- 免费。
