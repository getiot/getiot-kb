# ESP32 开发教程

![ESP32 教程](https://static.getiot.tech/cover-esp32-tutorial.webp#center)

ESP-BOX 是乐鑫信息科技发布的新一代 AIoT 应用开发平台，旨在让开发者更轻松地将人工智能融入物联网应用中。它搭载了乐鑫自家的芯片，集成了丰富的传感器、通信模块，为开发者提供了一个全面而强大的 AIoT 开发平台。

本教程通过一系列实战项目，带你从零开始构建 ESP-BOX 应用。从基础的传感器数据采集，到复杂的 AIoT 系统，你将学会如何将 ESP-BOX 的潜能转化为实际应用，释放你的创意力。
