# reTerminal 简介



## 概述

**reTerminal** 是 Seeed Studio 设计的一款开发套件，是 reThings 家族的成员之一。reTerminal 由树莓派计算模块4（简称 CM4）驱动，拥有四核 Cortex-A72 CPU，运行频率为 1.5GHz，配备了足够的内存（4GB）来执行多任务，也有足够的 eMMC 存储（32GB）来安装操作系统，可以实现快速启动时间和流畅的整体体验。

同时，reTerminal 具有双频 2.4GHz/5GHz Wi-Fi 和蓝牙 5.0 BLE 的无线连接，具有 5 英寸 IPS 电容式多点触摸屏幕，分辨率为 1280 x 720。可以说是一款面向未来的人机界面（HMI）设备，能够轻松有效地与物联网和云系统合作，在边缘解锁无穷的场景。这也是其被命名为 “Re-Terminal” 的原因。

![](https://static.getiot.tech/reTerminal_wiki_thumb.png#center-400)

此外，reTerminal 提供了一个高速扩展接口和丰富的 I/O 接口，具有更多的扩展性。该设备具有安全功能，如具有基于硬件的安全密钥存储的加密协处理器。它还内置了加速器、光传感器和 RTC（实时时钟）等模块。reTerminal 还有一个千兆以太网端口，用于更快的网络连接，也有双 USB 2.0 Type-A 端口。reTerminal 上的 40 针 Raspberry Pi 兼容头为广泛的物联网应用打开了方便之门。

reTerminal 开箱即带 Raspberry Pi 操作系统。因此，你所要做的就是把它连接到电源上，并立即开始构建你的物联网、人机界面和边缘人工智能应用。

## 功能特性

reTerminal 硬件具有如下功能特性：

- 集成模块化设计，具有高稳定性和可扩展性；
- 以 Raspberry Pi 计算机模块 4（CM4）为核心，配备 4GB 内存和 32GB eMMC 大容量存储；
- 5 英寸 IPS 电容式多点触摸屏幕，1280 x 720，293 PPI。
- 采用双频 2.4GHz/5GHz Wi-Fi 和蓝牙 5.0 BLE 进行无线连接。
- 高速扩展接口和丰富的 I/O，可实现更多的扩展性。
- 具有基于硬件的安全密钥存储的加密协处理器。
- 内置加速器、光线传感器和 RTC 等模块。
- 千兆位以太网端口和双 USB 2.0 Type-A 端口。
- 用于物联网应用的 40 针 Raspberry Pi 兼容针座。
