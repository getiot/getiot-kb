# reTerminal 教程

![reTerminal 教程](https://static.getiot.tech/cover-reterminal-tutorial.webp#center)

reTerminal 是 Seeed Studio 设计的一款基于树莓派计算模块4（简称 CM4）的开发套件，拥有四核 Cortex-A72 CPU，运行频率为 1.5GHz，配备了足够的内存（4GB）来执行多任务，也有足够的 eMMC 存储（32GB）来安装操作系统。

同时，reTerminal 还配备了可触摸显示屏、Wi-Fi 和蓝牙无线连接等功能。可以说是一款面向未来的人机界面（HMI）设备，能够轻松有效地与物联网和云系统合作，在边缘解锁无穷的场景。
