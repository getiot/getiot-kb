# STM32MPU 产品类型



STM32MPU 目前分为 STM32MP1 和 STM32MP2 两大产品系列。

- **STM32MP1**：STM32MP1 微处理器包含单 Arm® Cortex®-A7 产品系列和单/双 Arm® Cortex®-A7 与 Cortex®-M4 内核的多核异构产品系列。是一款通用微处理器产品组合，可轻松开发多种灵活的应用，实现理想的性能和功耗。
- **STM32MP2**：STM32MP2 微处理器是基于双核 Arm® Cortex®-A35 和 Cortex®-M33 的 64 位微处理器。是一款通用型微处理器产品组合，适用于需要高级多媒体功能的安全工业 4.0 和边缘计算应用。另外，部分产品嵌入了神经处理单元（NPU）。



## STM32MP1

STM32MP1 系列产品旨在满足工业 4.0、智慧城市和智能家居应用日益增长的安全需求。除了安全性，该系列产品还能有效地降低了能耗和成本。 

目前，STM32MP1 系列微处理器包含两种主要配置 —— STM32MP13x 和 STM32MP15x。其中，STM32MP13 产品线有助于优化能耗和降低成本，同时为入门级 Linux、裸机或基于 RTOS 的系统提供经认证的安全性。STM32MP15 产品线则提供异构处理，以支持 Linux 和实时应用。



### STM32MP13

STM32MP13 系列包含三条产品线，同样封装的引脚兼容。

| 产品线         | 资源配置                                                     |
| -------------- | ------------------------------------------------------------ |
| **STM32MP131** | 单 Cortex-A7 内核，最高 1Ghz，以太网。                       |
| **STM32MP133** | 单 Cortex-A7 内核，最高 1Ghz，CAN FD，双以太网。             |
| **STM32MP135** | 单 Cortex-A7 内核，最高 1GHz，摄像头，双以太网，以及 LCD 并行接口。 |



### STM32MP15

STM32MP15 系列包含三条产品线，同样封装的引脚兼容。

| 产品线         | 资源配置                                                     |
| -------------- | ------------------------------------------------------------ |
| **STM32MP151** | 单 Cortex-A7 内核@800 MHz、Cortex-M4 内核@209 MHz            |
| **STM32MP153** | 双 Cortex-A7 内核@800 MHz、Cortex-M4 内核@209 MHz，以及 CAN FD。 |
| **STM32MP157** | 双 Cortex-A7 内核@800 MHz、Cortex-M4 内核@209 MHz、3D GPU、DSI 显示接口，以及CAN FD。 |



## STM32MP2

STM32MP25 系列是 STM32MP2 系列的首款产品，预计 2023 年第四季度可提供 STM32MP25 样品。它是一款搭载神经处理单元的 64 位微处理器，拥有高达 6,000 DMIPS 的计算能力，可为智能互联应用的发展提供有力支持，适用于需要高端多媒体功能的安全工业 4.0 和高级边缘计算应用。
