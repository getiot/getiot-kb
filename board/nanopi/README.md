# NanoPi 系列开发板



NanoPi 是友善电子（FriendlyELEC）推出的一系列 Linux 开发板，包括 NEO、Duo、M1、M2、M3、M4、R1、R4、R5、R6 等型号，它们体积小巧、功能强大，将是你的掌上创客神器。

本教程会选取其中几款经典的 NanoPi 开发板，介绍它们的硬件平台和基本使用。例如经典的 NanoPi NEO，它使用 Allwinner H3 处理器，拥有高达 512MB 的内存，可以运行 UbuntuCore 等 Linux 系统。以及基于 Rockchip RK3588S 处理器的 NanoPi R6S，不仅拥有四核 Cortex-A76 + 四核 Cortex-A55 的 CPU，还拥有 GPU、VPU 等协处理器，性能强悍，可用于开发 AIoT 边缘计算应用。
