# Blue Pill 简介



**Blue Pill** 是一款基于 ARM Cortex M3 微控制器 STM32F103C8T6 的开发板最小系统，翻译过来有一个好听的名字叫“蓝色药丸”。Blue Pill 的外观看起来很像 Arduino Nano，但是它包含了更多的功能，因此也被称为 STM32duino。

<img src="https://static.getiot.tech/STM32F103C8T6_Blue_Pill.jpg" width="600" />



## 硬件资源

- 主控制器：[STM32F103C8T6](https://www.st.com/en/microcontrollers-microprocessors/stm32f103c8.html)，ARM Cortex-M3 内核，主频 72MHz，封装为 48 pins 的 LOFP
- 存储：64 KB 片上 Flash，20 KB 片上 SRAM
- 电源：支持 3.3V 或 5V 引脚输入，以及 USB 供电（+5V）
- I/O
  - 复位按键
  - BOOT0 和 BOOT1 跳帽
  - 电源 LED 指示灯
  - 用户 LED 灯（PC13）
- 扩展接口
  - Header 1 扩展 I/O
  - Header 2 扩展 I/O
  - SWD 调试接口
  - 1 个 USB 接口
