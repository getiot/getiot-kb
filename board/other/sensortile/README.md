# SensorTile.box 教程



本课程以意法半导体 SensorTile 开发工具包为基础，为年轻的工程师和技术人员提供构建物联网系统所需的基础知识，如可穿戴消费设备、可穿戴医疗设备、住宅物联网系统和车联网系统。

> 配对秘钥：123456



## 软件

- ST BLE Sensor
- Algo Builder 简单的算法图形设计（只支持 Windows）
- Qeexo AutoML（支持 Windows 和 MacOS）
- Unicleo-GUI
- Unico-GUI
- STM32CubeProgrammer
