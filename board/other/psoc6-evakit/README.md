# 英飞凌 PSoC6 评估板套件

![](https://static.getiot.tech/PSoC6-RTT-banner.png)

本教材介绍英飞凌（Infineon）和 RT-Thread 联合推出的 PSoC 6 系列芯片评估套件 Psoc6-evaluationkit-062S2 的开发方法。该套件的主控制器 CY8C624ABZI-S2D44（PSoC 62xA 系列）是一款 32 位双核 CPU 系统，包括主频 150MHz 的 ARM Cortex-M4 和主频 100MHz 的 ARM Cortex-M0，并且拥有 2MB Flash 和 1MB SRAM。
