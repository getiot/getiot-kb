# 树莓派4代B型



Raspberry Pi 4 Model B（树莓派4代B型）是树莓派最新发布的第四代产品， 性能与树莓派 3B+相比无论是处理器速度，还是多媒体和内存上都有显著提升。Raspberry Pi 4B 拥有与入门级 x86 PC 系统相媲美的桌面性能，给您带来高品质体验。

Raspberry Pi 4B 具备 1.5Ghz 运行的 64 位四核处理器，最高支持以 60fps 速度刷新的 4K 分辨率的双显示屏，高达 4GB RAM（可根据型号选择 1GB、2GB、4GB），2.4/5.0 Ghz 双频无线 LAN，蓝牙 5.0/BLE，千兆以太网，USB3.0，和 PoE 功能。

## 技术规格

- 处理器：博通 BCM2711，四核 Cortex-A72、64 位 SoC、主频 1.5GHz
- 内存：1GB、2GB 或 4GB LPDDR4 SDRAM
- GPU：500 MHz VideoCore VI，支持 OpenGL ES 3.0
- 网络：双频 IEEE 802.11ac 无线 + 蓝牙5.0，千兆以太网
- USB：2×USB 3.0、2×USB 2.0 端口
- GPIO：向前兼容树莓派的标准 40 针引脚
- 视频和声音：
  - 2×micro-HDMI 输出（4kp60 或 4kp30）
  - 2通道 MIPI DSI 显示端口
  - 2通道 MIPI CSI 摄像头端口
  - 4极立体声音频和复合视频端口
- 多媒体：
  - HEVC / H.265（4kp60 解码）
  - AVC / H.264（1080p60解码 / 1080p30编码）
- 存储：Micro SD 卡槽，用于加载操作系统和数据存储
- 电源输入：5V DC（USB-C、3A）、GPIO 接头支持 5V DC @ 3A，或以太网供电（需单独的 PoE HAT）
