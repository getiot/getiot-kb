# 潘多拉 STM32L4 IoT 开发板

![潘多拉 IoT Board 开发板](https://static.getiot.tech/cover-pandora-iot-board-tutorial.webp#center)

潘多拉（Pandora）开发板也称为 IoT Board，是一款由 RT-Thread 和正点原子联合推出的基于 STM32L4（Cortex-M4 内核）的物联网开发板。该开发板搭载了丰富的外设资源，包括 LCD 显示屏、Wi-Fi、蓝牙、USB、SD 卡插槽、QSPI Flash、音频接口、按键、蜂鸣器、LED 灯等等，是学习 STM32 嵌入式开发的硬件平台。

本教程基于 RT-Thread 物联网操作系统，介绍如何在潘多拉（Pandora）开发板上运行 RT-Thread 系统，并借助 RT-Thread 丰富的组件和强大的生态，完成从点亮 LED 灯到使用文件系统、无线网络，再到数据采集和发布到物联网云平台等一系列实验。

通过本教程的学习，你将掌握基于 RT-Thread 和 STM32 的嵌入式开发技术，为创建你的物联网项目打下坚实基础。
