# Wio Terminal OLED 显示



如果你需要第二个屏幕与 Wio Terminal 一起显示，那么可以考虑 Grove 接口的 OLED 显示屏。它采用 I2C 通信接口，简单易用，并且价格便宜，是一个不错的选择。你可以用它来显示图形和数据，为 Wio Terminal 添加更多交互功能。

![](https://static.getiot.tech/Grove-OLED-Displey-0.96-SSD1315-pin.jpg#center)



## 安装依赖库

首先需要为 Wio Terminal 安装 OLED 图形库 `U8g2`。

1、打开 Arduino IDE，点击 *工具 > 管理库* 打开“库管理器”。

2、在搜索框输入“U8g2”，在列表中找到它并安装最新版本即可。



## U8g2 库用法

使用 u8g2 软件库初始化 I2C 接口的 OLED 显示屏时，需要指定 I2C 的引脚，包括作为时钟的 SCL 和作为数据的 SDA。

```cpp showLineNumbers
U8G2_SSD1306_128X64_NONAME_1_SW_I2C u8g2(U8G2_R0, 
                                         SCL,  /* clock */
                                         SDA,  /* data */
                                         U8X8_PIN_NONE); /* reset */
```

初始化之后，可以用下面的逻辑控制 OLED 显示：

1. 调用 `u8g2.firstPage()` 设置当前页码为 0；
2. 开始一个 do-while 循环，并在循环体内部绘制一些东西（图形、字符）；
3. 只要 `u8g2.nextPage()` 返回 `true` 就循环。

关于 U8g2 库的详细用法，请参考官方 [Wiki](https://github.com/olikraus/u8g2/wiki)。
