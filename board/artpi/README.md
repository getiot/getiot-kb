# ART-Pi 教程

![ART-Pi 教程](https://static.getiot.tech/cover-artpi-tutorial.webp#center)

ART-Pi 是一款运行 RT-Thread 物联网操作系统的开源硬件平台。ART-Pi 能很好的满足绝大多数开发人员的 DIY 想法，其具备性能强大的主控、实用的外设、丰富的扩展接口，是 RT-Thread 团队耗时半年精心打磨出来的精品，也是学习、DIY、产品原型验证的不二之选。

本教程将介绍 ART-Pi 的基本情况，基于 RT-Thread 系统完成多个物联网实验。通过学习本教程，你将学会如何利用 RT-Thread 强大的生态系统快速构建自己的物联网项目。
