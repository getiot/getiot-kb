# NodeMCU 教程

![NodeMCU 教程](https://static.getiot.tech/cover-nodemcu-tutorial.webp#center)

NodeMCU 是一款基于 ESP8266 Wi-Fi 模块的开发板，它小巧玲珑，却蕴含着强大的物联网和嵌入式开发潜能。NodeMCU 的魅力在于其强大的功能和便捷的开发方式，它拥有 Wi-Fi 连接能力，可以轻松实现设备互联、数据传输，甚至是云端控制。同时，NodeMCU 的开源设计和丰富的资源库，使其成为物联网创新的理想选择。

NodeMCU 的编程是简单而强大的，在本教程中，我们将学习如何使用 Arduino IDE 来进行 NodeMCU 的开发。了解如何通过编写代码实现 Wi-Fi 连接、传感器数据采集、控制执行器等功能。这将是你步入物联网开发的重要一步。我们还会通过一系列实战项目，带你从零开始构建 NodeMCU 应用。从简单的 LED 控制、温湿度监测，到更复杂的智能家居系统。
