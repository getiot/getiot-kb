# 电流、电压和电阻

电流、电压和电阻是电路中最基本的三个物理量。理解它们，是学习电路的基础。

## 什么是电流？

### 电流的定义

**电流**（Current）：单位时间内通过导体横截面的电荷量。

$$
I = \frac{Q}{t}
$$
或者（瞬时电流）：

$$
I = \frac{dQ}{dt}
$$
其中：
- $I$：电流（单位：安培，A）
- $Q$：电荷量（单位：库仑，C）
- $t$：时间（单位：秒，s）

**通俗理解**：电流就是"电荷流动的速率"，像"水流"一样。

### 电流的特点

1. **标量**：电流只有大小，没有方向（但在电路分析中，需要规定方向）
2. **过程量**：电流与时间有关，是过程量
3. **方向性**：电流的方向是正电荷流动的方向（实际上电子流动方向相反）

### 电流的方向

**规定**：电流的方向是正电荷流动的方向。

**实际**：
- 在金属导体中，电荷载体是电子（负电荷）
- 电子流动方向与电流方向相反
- 电流方向：从正极到负极（电源外部）
- 电子流动方向：从负极到正极（电源外部）

**通俗理解**：
- 电流方向：正电荷流动的方向（从正到负）
- 电子流动方向：电子流动的方向（从负到正）

### 电流的单位

电流的单位：

1. **安培**（A）：国际单位
   - 1 A = 1 C/s（库仑每秒）
   - 常用单位

2. **常用单位**：
   - 毫安（mA），1 mA = $10^{-3}$ A
   - 微安（$\mu$A），1 $\mu$A = $10^{-6}$ A
   - 千安（kA），1 kA = $10^3$ A

### 恒定电流

**恒定电流**：大小和方向都不变的电流。

**特点**：
- 电流大小：$I = \text{常数}$
- 方向：不变

**条件**：需要恒定的电压和恒定的电阻。

## 什么是电压？

### 电压的定义

**电压**（Voltage）：两点之间的电势差，也称为**电位差**。

$$
U = V_2 - V_1 = \Delta V
$$
其中：
- $U$：电压（单位：伏特，V）
- $V_1$、$V_2$：两点的电势（单位：V）

**通俗理解**：电压就是"电势差"，像"高度差"一样，是电流流动的"推动力"。

### 电压的特点

1. **标量**：电压只有大小，没有方向（但有正负，表示电势高低）
2. **相对量**：电压是两点之间的电势差
3. **驱动电流**：电压是电流流动的原因

### 电压的单位

电压的单位：

1. **伏特**（V）：国际单位
   - 1 V = 1 J/C（焦耳每库仑）
   - 常用单位

2. **常用单位**：
   - 毫伏（mV），1 mV = $10^{-3}$ V
   - 微伏（$\mu$V），1 $\mu$V = $10^{-6}$ V
   - 千伏（kV），1 kV = $10^3$ V

### 常见电压

**常见电压值**：

| 电压源 | 电压值 |
|:------:|:------:|
| 干电池 | 1.5 V |
| 手机电池 | 3.7 V（标称） |
| USB 接口 | 5 V |
| 汽车电池 | 12 V |
| 家庭用电（中国） | 220 V |
| 家庭用电（美国） | 120 V |
| 工业用电 | 380 V |
| 高压输电 | 110 kV、220 kV、500 kV |

## 什么是电阻？

### 电阻的定义

**电阻**（Resistance）：导体对电流的阻碍作用。

$$
R = \frac{U}{I}
$$
其中：
- $R$：电阻（单位：欧姆，$\Omega$）
- $U$：电压（单位：V）
- $I$：电流（单位：A）

**通俗理解**：电阻就是"阻碍电流流动的能力"，像"水管中的阻力"一样。

### 电阻的特点

1. **标量**：电阻只有大小，没有方向
2. **导体属性**：电阻是导体的属性，与电压和电流无关（在一定范围内）
3. **阻碍电流**：电阻越大，电流越小

### 电阻的单位

电阻的单位：

1. **欧姆**（$\Omega$）：国际单位
   - 1 $\Omega$ = 1 V/A（伏特每安培）
   - 常用单位

2. **常用单位**：
   - 千欧（k$\Omega$），1 k$\Omega$ = $10^3$ $\Omega$
   - 兆欧（M$\Omega$），1 M$\Omega$ = $10^6$ $\Omega$
   - 毫欧（m$\Omega$），1 m$\Omega$ = $10^{-3}$ $\Omega$

### 电阻定律

**电阻定律**：导体的电阻与导体的长度成正比，与导体的横截面积成反比。

$$
R = \rho\frac{L}{A}
$$
其中：
- $R$：电阻（单位：$\Omega$）
- $\rho$：电阻率（单位：$\Omega$·m）
- $L$：导体长度（单位：m）
- $A$：横截面积（单位：m²）

**通俗理解**：
- 长度越长，电阻越大（像"路越长越难走"）
- 横截面积越大，电阻越小（像"路越宽越好走"）
- 材料不同，电阻率不同

### 电阻率

**电阻率**（$\rho$）：表示材料导电能力的物理量。

**单位**：欧姆·米（$\Omega$·m）

**常见材料的电阻率**：

| 材料 | 电阻率（$\Omega$·m） |
|:----:|:-----------------:|
| 银 | $1.6 \times 10^{-8}$ |
| 铜 | $1.7 \times 10^{-8}$ |
| 铝 | $2.8 \times 10^{-8}$ |
| 铁 | $9.7 \times 10^{-8}$ |
| 水（纯） | 约 $10^5$ |
| 玻璃 | $10^{10} - 10^{14}$ |
| 橡胶 | $10^{13} - 10^{16}$ |

**通俗理解**：
- 电阻率越小，导电能力越强（导体）
- 电阻率越大，导电能力越弱（绝缘体）

## 电流、电压、电阻的关系

### 欧姆定律

**欧姆定律**（Ohm's Law）：通过导体的电流与导体两端的电压成正比，与导体的电阻成反比。

$$
I = \frac{U}{R}
$$
或者：

$$
U = IR
$$
或者：

$$
R = \frac{U}{I}
$$
**通俗理解**：

- 电压越大，电流越大（像"压力越大，水流越快"）
- 电阻越大，电流越小（像"阻力越大，水流越慢"）

### 关系图解

```
电压 (U) ────→ 电流 (I)
    ↑              ↓
    │              │
    └─── 电阻 (R) ──┘
```

**记忆口诀**：
- $I = \frac{U}{R}$（电流 = 电压 ÷ 电阻）
- $U = IR$（电压 = 电流 × 电阻）
- $R = \frac{U}{I}$（电阻 = 电压 ÷ 电流）

## 实际应用

### 游戏开发

在游戏开发中，电流、电压和电阻用于：

- **电路模拟**：模拟电路中的电流、电压、电阻
- **物理引擎**：模拟电子系统
- **游戏机制**：电路解谜游戏

```javascript
// 电流、电压和电阻的应用
class CircuitBasics {
  // \text{欧姆定律}：\text{计算电流}
  static calculateCurrent(voltage, resistance) {
    // I = U/R
    return voltage / resistance;
  }
  
  // 欧姆定律：计算电压
  static calculateVoltage(current, resistance) {
    // U = IR
    return current * resistance;
  }
  
  // 欧姆定律：计算电阻
  static calculateResistance(voltage, current) {
    // R = U/I
    return voltage / current;
  }
  
  // 电阻定律：计算电阻
  static calculateResistanceFromMaterial(resistivity, length, area) {
    // R = ρL/A
    return resistivity * length / area;
  }
  
  // 计算电荷量
  static calculateCharge(current, time) {
    // Q = It
    return current * time;
  }
  
  // 从电荷量计算电流
  static calculateCurrentFromCharge(charge, time) {
    // I = Q/t
    return charge / time;
  }
}

// 使用示例
let current = CircuitBasics.calculateCurrent(12, 100);
// 电压 12 V，电阻 100 Ω
// I = 12 / 100 = 0.12 A = 120 mA

let voltage = CircuitBasics.calculateVoltage(0.1, 50);
// 电流 0.1 A，电阻 50 Ω
// U = 0.1 × 50 = 5 V

let resistance = CircuitBasics.calculateResistance(9, 0.3);
// 电压 9 V，电流 0.3 A
// R = 9 / 0.3 = 30 Ω

let materialResistance = CircuitBasics.calculateResistanceFromMaterial(1.7e-8, 10, 1e-6);
// 铜导线（电阻率 1.7×10⁻⁸ Ω·m），长度 10 m，横截面积 1 mm² = 1×10⁻⁶ m²
// R = 1.7e-8 × 10 / 1e-6 = 0.17 Ω
```

## 常见问题

### 1. 求电流

**问题**：电阻为 50 $\Omega$ 的导体，两端电压为 10 V，求电流。

**分析**：

$$I = \frac{U}{R} = \frac{10}{50} = 0.2 \text{ A} = 200 \text{ mA}$$

### 2. 求电压

**问题**：电流为 0.5 A 的电路，电阻为 20 $\Omega$，求电压。

**分析**：

$$U = IR = 0.5 \times 20 = 10 \text{ V}$$

### 3. 求电阻

**问题**：导体两端电压为 12 V，电流为 0.3 A，求电阻。

**分析**：

$$R = \frac{U}{I} = \frac{12}{0.3} = 40 \text{ }\Omega$$

### 4. 求电荷量

**问题**：电流为 2 A 的电路，通电 5 分钟，求通过导体的电荷量。

**分析**：

$$t = 5 \text{ \text{分钟}} = 300 \text{ \text{秒}}$$

$$Q = It = 2 \times 300 = 600 \text{ C}$$

### 5. 电阻定律

**问题**：铜导线（电阻率 $1.7 \times 10^{-8}$ $\Omega$·m）长 100 m，横截面积为 2 mm²，求电阻。

**分析**：

$$A = 2 \text{ mm}^2 = 2 \times 10^{-6} \text{ m}^2$$

$$R = \rho\frac{L}{A} = 1.7 \times 10^{-8} \times \frac{100}{2 \times 10^{-6}} = 0.85 \text{ }\Omega$$

## 常见错误

1. **混淆电流和电荷量**：电流是 $I = \frac{Q}{t}$，不是 $I = Q$
2. **电压方向错误**：电压是电势差，有正负，表示电势高低
3. **单位错误**：电流单位是 A，电压单位是 V，电阻单位是 $\Omega$
4. **公式混淆**：欧姆定律的三种形式容易混淆，要记住 $I = \frac{U}{R}$

## 小结

电流、电压和电阻的核心内容：

1. **电流**（$I = \frac{Q}{t}$）：
   - 单位时间内通过导体横截面的电荷量
   - 单位：安培（A）
   - 方向：正电荷流动的方向

2. **电压**（$U = V_2 - V_1$）：
   - 两点之间的电势差
   - 单位：伏特（V）
   - 是电流流动的"推动力"

3. **电阻**（$R = \rho\frac{L}{A}$）：
   - 导体对电流的阻碍作用
   - 单位：欧姆（$\Omega$）
   - 与长度成正比，与横截面积成反比

4. **欧姆定律**（$I = \frac{U}{R}$）：
   - 电流与电压成正比，与电阻成反比
   - $U = IR$，$R = \frac{U}{I}$

**记住**：电流、电压、电阻是电路的基本物理量，欧姆定律描述了它们的关系！
