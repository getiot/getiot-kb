# 圆周运动和万有引力

圆周运动是物体沿圆形轨迹运动的运动形式，万有引力是宇宙中最基本的力之一。理解圆周运动和万有引力，能更好地分析天体运动、卫星轨道等问题。

本教程将系统地介绍圆周运动和万有引力的基本概念：

- **匀速圆周运动**：理解圆周运动的基本规律
- **向心力和向心加速度**：理解圆周运动的动力学
- **万有引力定律**：理解万有引力的规律
- **开普勒定律**：理解行星运动的规律
- **卫星运动和轨道**：理解卫星的运动规律
- **宇宙速度**：理解三种宇宙速度的含义

## 为什么重要？

对于 STEM 创客和独立开发者，圆周运动和万有引力知识非常实用：

- **游戏开发**：物理引擎需要模拟圆周运动，角色绕点旋转、轨道运动等
- **机器人控制**：机器人的圆周路径规划、轨道跟踪需要圆周运动知识
- **航空航天**：理解卫星轨道、火箭发射需要万有引力知识
- **传感器应用**：GPS、导航系统等需要理解圆周运动和万有引力
