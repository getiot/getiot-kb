# 运动图像分析

用图像描述运动，直观又清晰！学会读图，就能一眼看出物体的运动规律。

## 为什么用图像？

图像比公式更直观：
- **一目了然**：一眼看出运动特点
- **找规律**：发现速度和加速度的变化
- **解问题**：从图像中直接读取信息

## 位置-时间图（x-t 图）

### 图的含义

**横轴**：时间 $t$  
**纵轴**：位置 $x$

### 图的斜率

**斜率 = 速度**

$$
\text{斜率} = \frac{\Delta x}{\Delta t} = v
$$


- **斜率 > 0**：向正方向运动
- **斜率 < 0**：向负方向运动
- **斜率 = 0**：静止
- **斜率变大**：加速运动
- **斜率变小**：减速运动

### 常见图像

#### 1. 匀速直线运动

图像是一条**直线**

```
    x
    |     /
    |   /
    | /
    |______ t
```

特点：
- 直线斜率不变
- 速度恒定

#### 2. 匀加速直线运动

图像是一条**抛物线**

```
    x
    |     .
    |   .
    | .
    |______ t
```

特点：
- 曲线斜率逐渐增大
- 速度逐渐增大

#### 3. 静止

图像是一条**水平直线**

```
    x
    |____
    |______ t
```

特点：
- 斜率为 0
- 位置不变

## 速度-时间图（v-t 图）

### 图的含义

**横轴**：时间 $t$  
**纵轴**：速度 $v$

### 图的斜率

**斜率 = 加速度**

$$\text{斜率} = \frac{\Delta v}{\Delta t} = a$$

- **斜率 > 0**：加速运动
- **斜率 < 0**：减速运动
- **斜率 = 0**：匀速运动

### 图的面积

**面积 = 位移**

$$\text{位移} = \int v \, dt \approx \text{\text{图\text{像\text{下方的}面}积}}$$

对于匀速运动：
$$\text{位移} = v \times t = \text{\text{矩\text{形\text{的}面}积}}$$

对于匀加速运动：
$$\text{位移} = \frac{1}{2} \times (v_0 + v) \times t = \text{\text{梯\text{形\text{的}面}积}}$$

### 常见图像

#### 1. 匀速直线运动

图像是一条**水平直线**

```
    v
    |______
    |______ t
```

特点：
- 速度不变
- 斜率为 0（加速度为 0）

#### 2. 匀加速直线运动

图像是一条**倾斜直线**

```
    v
    |   /
    | /
    |______ t
```

特点：
- 速度均匀增加
- 斜率不变（加速度恒定）

#### 3. 静止

图像与横轴重合

```
    v
    |______ t
```

特点：
- 速度为 0
- 斜率为 0

## 加速度-时间图（a-t 图）

### 图的含义

**横轴**：时间 $t$  
**纵轴**：加速度 $a$

### 图的面积

**面积 = 速度变化量**

$$
\Delta v = \int a \, dt \approx \text{\text{图\text{像下方的面}积}}
$$
对于匀加速运动：
$$
\Delta v = a \times t = \text{\text{矩\text{形的面}积}}
$$


### 常见图像

#### 匀加速运动

图像是一条**水平直线**

```
    a
    |______
    |______ t
```

特点：
- 加速度恒定
- 速度均匀变化

## 如何从图像读取信息？

### 步骤 1：确定图像类型

- **x-t 图**：看位置变化
- **v-t 图**：看速度变化
- **a-t 图**：看加速度变化

### 步骤 2：读取关键信息

#### 从 x-t 图读取：
- **位置**：直接读取纵坐标
- **速度**：看斜率
- **位移**：两点间的位置差

#### 从 v-t 图读取：
- **速度**：直接读取纵坐标
- **加速度**：看斜率
- **位移**：看面积（注意正负）

#### 从 a-t 图读取：
- **加速度**：直接读取纵坐标
- **速度变化量**：看面积

### 步骤 3：判断运动类型

- **匀速运动**：v-t 图是水平线
- **匀加速运动**：v-t 图是倾斜直线
- **静止**：v-t 图与横轴重合

## 实际应用

### 游戏开发

在游戏中，可以用图像控制动画：

```javascript
// 位置-时间图控制位移
function getPositionAtTime(t) {
  return calculateFromGraph(x_t_graph, t);
}

// 速度-时间图控制速度
function getVelocityAtTime(t) {
  return calculateFromGraph(v_t_graph, t);
}
```

### 机器人控制

机器人的运动规划可以用图像表示：
- 规划位置-时间曲线
- 规划速度-时间曲线
- 确保平滑运动

### 传感器数据可视化

从传感器读取的数据，可以用图像显示：
- 位置传感器 → x-t 图
- 速度传感器 → v-t 图
- 加速度计 → a-t 图

## 常见错误

1. **混淆图像类型**：x-t 图的斜率是速度，不是加速度
2. **忽略方向**：速度有正负，位移也有正负
3. **面积的正负**：v-t 图在横轴下方的面积是负位移

## 小结

- **x-t 图**：斜率 = 速度，直接读位置
- **v-t 图**：斜率 = 加速度，面积 = 位移
- **a-t 图**：面积 = 速度变化量

掌握图像分析，运动规律一目了然！
