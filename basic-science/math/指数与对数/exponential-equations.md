# 指数方程

指数方程是未知数出现在指数位置的方程。解指数方程的关键是"去指数"，通常需要用到对数的知识！

## 什么是指数方程？

**指数方程**是未知数出现在指数位置的方程。

### 基本形式

```
aˣ = b  （a > 0 且 a ≠ 1，b > 0）
```

**例子**：
- 2ˣ = 8
- 3ˣ = 27
- 10ˣ = 1000
- 5ˣ = 25

## 解指数方程的方法

### 方法 1：化为同底数（最常用）

如果方程两边可以化为同底数的幂，直接比较指数。

#### 步骤

1. 把方程两边化为同底数的幂
2. 比较指数
3. 解出未知数

#### 例子 1：简单情况

```
2ˣ = 8
```

**步骤**：
1. 把 8 写成 2 的幂：8 = 2³
2. 所以：2ˣ = 2³
3. 比较指数：x = 3
4. 检验：2³ = 8 ✓

#### 例子 2：稍复杂

```
3ˣ = 27
```

**步骤**：
1. 把 27 写成 3 的幂：27 = 3³
2. 所以：3ˣ = 3³
3. 比较指数：x = 3
4. 检验：3³ = 27 ✓

#### 例子 3：分数

```
2ˣ = 1/8
```

**步骤**：
1. 把 1/8 写成 2 的幂：1/8 = 2⁻³
2. 所以：2ˣ = 2⁻³
3. 比较指数：x = -3
4. 检验：2⁻³ = 1/2³ = 1/8 ✓

### 方法 2：取对数法

如果无法化为同底数，两边取对数。

#### 步骤

1. 方程两边取对数（常用对数或自然对数）
2. 利用对数的运算法则化简
3. 解出未知数

#### 例子 1

```
2ˣ = 10
```

**步骤**：
1. 两边取常用对数：lg(2ˣ) = lg 10
2. 利用幂的对数法则：x lg 2 = lg 10
3. 因为 lg 10 = 1，所以：x lg 2 = 1
4. 求解：x = 1 / lg 2 ≈ 1 / 0.301 ≈ 3.32
5. 检验：2^3.32 ≈ 10 ✓

#### 例子 2

```
3ˣ = 5
```

**步骤**：
1. 两边取自然对数：ln(3ˣ) = ln 5
2. 利用幂的对数法则：x ln 3 = ln 5
3. 求解：x = ln 5 / ln 3 ≈ 1.609 / 1.099 ≈ 1.46
4. 检验：3^1.46 ≈ 5 ✓

### 方法 3：换元法

如果指数是复合形式，可以用换元法。

#### 例子

```
2^(2x) - 3 × 2ˣ + 2 = 0
```

**步骤**：
1. 设 t = 2ˣ，则 2^(2x) = (2ˣ)² = t²
2. 原方程变成：t² - 3t + 2 = 0
3. 因式分解：(t - 1)(t - 2) = 0
4. 所以 t = 1 或 t = 2
5. 当 t = 1 时：2ˣ = 1 = 2⁰，所以 x = 0
6. 当 t = 2 时：2ˣ = 2 = 2¹，所以 x = 1
7. 检验：
   - x = 0：2⁰ - 3×2⁰ + 2 = 1 - 3 + 2 = 0 ✓
   - x = 1：2² - 3×2¹ + 2 = 4 - 6 + 2 = 0 ✓
8. 所以解是：x = 0 或 x = 1

## 特殊类型的指数方程

### 类型 1：aˣ = aʸ

如果 aˣ = aʸ（a > 0 且 a ≠ 1），则 x = y。

**例子**：
- 2ˣ = 2³，所以 x = 3

### 类型 2：aˣ = bˣ

如果 aˣ = bˣ（a, b > 0 且 a, b ≠ 1），通常需要取对数。

**例子**：
- 2ˣ = 3ˣ
- 两边除以 3ˣ（或取对数）：(2/3)ˣ = 1
- 所以 (2/3)ˣ = (2/3)⁰
- 所以 x = 0

### 类型 3：a^(f(x)) = b^(g(x))

指数是函数的情况，通常需要取对数。

**例子**：
- 2^(x+1) = 3^(x-1)
- 两边取对数：lg(2^(x+1)) = lg(3^(x-1))
- 化简：(x+1)lg 2 = (x-1)lg 3
- 展开：x lg 2 + lg 2 = x lg 3 - lg 3
- 移项：x(lg 2 - lg 3) = -lg 3 - lg 2
- 求解：x = -(lg 3 + lg 2)/(lg 2 - lg 3)

## 生活中的应用

#### 人口增长

- 👥 人口每年增长 2%，多少年后人口翻倍？
  - 设原人口为 P，t 年后人口为 P(1.02)ᵗ
  - 翻倍：P(1.02)ᵗ = 2P
  - 所以：(1.02)ᵗ = 2
  - 两边取对数：t lg 1.02 = lg 2
  - 求解：t = lg 2 / lg 1.02 ≈ 35 年

#### 放射性衰变

- ☢️ 放射性物质半衰期是 10 年，多少年后剩余 1/4？
  - 设原质量为 M，t 年后剩余 M(1/2)^(t/10)
  - (1/2)^(t/10) = 1/4 = (1/2)²
  - 所以：t/10 = 2
  - 求解：t = 20 年

#### 复利计算

- 💰 本金 1000 元，年利率 5%，按复利计算，多少年后本息和达到 2000 元？
  - 1000(1.05)ᵗ = 2000
  - 所以：(1.05)ᵗ = 2
  - 两边取对数：t lg 1.05 = lg 2
  - 求解：t = lg 2 / lg 1.05 ≈ 14.2 年

## 常见错误

#### 错误 1：底数相同但指数不同时直接相等

```
❌ 错误：2ˣ = 8，所以 x = 8/2 = 4
✅ 正确：2ˣ = 8 = 2³，所以 x = 3
```

#### 错误 2：取对数时忘记运算法则

```
❌ 错误：lg(2ˣ) = lg 2 × x
✅ 正确：lg(2ˣ) = x lg 2
```

#### 错误 3：检验时计算错误

解完方程后要检验，确保答案正确！
