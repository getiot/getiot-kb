# 数学基础：加法

加法是我们最早学会的数学运算之一！就像把东西合在一起一样简单。让我们一起来学习加法吧！

## 什么是加法？

**加法**就是把两个或多个数合在一起，得到它们的总和。

加法的符号是 **+**（加号），读作"加"或"plus"。

**基本形式**

```
3 + 2 = 5
 ↑   ↑   ↑
加数 加数 和
```

- **加数**：参与相加的数（3 和 2）
- **和**：相加的结果（5）

## 生活中的加法

#### 购物

- 🛒 买了一个 5 元的苹果和一个 3 元的香蕉
  - 总共花了：5 + 3 = 8 元

#### 数东西

- 🍎 原来有 3 个苹果，又买了 2 个
  - 现在有：3 + 2 = 5 个苹果

#### 时间

- ⏰ 上午学习了 2 小时，下午学习了 3 小时
  - 一共学习了：2 + 3 = 5 小时

## 加法的计算方法

### 一位数加法

最简单的加法，直接心算：

```
1 + 1 = 2
2 + 3 = 5
5 + 4 = 9
```

### 多位数加法（竖式计算）

当数字较大时，用竖式计算更清晰：

#### 不进位加法

```
  23
+ 15
----
  38
```

**步骤**：
1. 对齐数位（个位对个位，十位对十位）
2. 从右到左逐位相加
3. 个位：3 + 5 = 8
4. 十位：2 + 1 = 3
5. 结果：38

#### 进位加法

当某一位相加超过 10 时，需要进位：

```
  28
+ 15
----
  43
```

**步骤**：
1. 个位：8 + 5 = 13（写 3，向十位进 1）
2. 十位：2 + 1 + 1（进位）= 4
3. 结果：43

**进位规则**：
- 当某一位相加等于或大于 10 时，向高位进 1
- 本位只保留个位数

### 三个数相加

可以依次相加：

```
3 + 4 + 5 = (3 + 4) + 5 = 7 + 5 = 12
```

或者用竖式：

```
   3
   4
+  5
----
  12
```

## 小数的加法

对齐小数点，然后相加：

```
  3.25
+ 1.75
------
  5.00
```

**步骤**：
1. 对齐小数点
2. 从右到左逐位相加
3. 十分位：2 + 7 = 9
4. 百分位：5 + 5 = 10（写 0，向十分位进 1）
5. 个位：3 + 1 + 1（进位）= 5
6. 结果：5.00

## 分数的加法

### 同分母分数相加

分母相同，分子相加：

```
1/4 + 2/4 = 3/4
```

**步骤**：
1. 分母不变
2. 分子相加：1 + 2 = 3
3. 结果：3/4

### 异分母分数相加

先通分，再相加：

```
1/2 + 1/3 = 3/6 + 2/6 = 5/6
```

**步骤**：
1. 找最小公倍数：2 和 3 的最小公倍数是 6
2. 通分：1/2 = 3/6，1/3 = 2/6
3. 分子相加：3 + 2 = 5
4. 结果：5/6

## 加法的性质

### 交换律

两个数相加，交换位置，和不变：

```
3 + 5 = 5 + 3 = 8
```

**理解**：先有 3 个苹果再有 5 个，和先有 5 个再有 3 个，总数一样。

### 结合律

三个数相加，先加前两个或先加后两个，和不变：

```
(3 + 5) + 2 = 3 + (5 + 2) = 10
```

**理解**：分组方式不同，但总数相同。

### 零的性质

任何数加 0，结果还是这个数：

```
5 + 0 = 5
0 + 5 = 5
```

**理解**：加上"没有"，数量不变。

## 加法的技巧

### 凑十法

把数字凑成 10，计算更简单：

```
7 + 5 = 7 + 3 + 2 = 10 + 2 = 12
```

**步骤**：
1. 把 5 分成 3 和 2
2. 7 + 3 = 10
3. 10 + 2 = 12

### 拆数法

把大数拆成容易计算的数：

```
18 + 7 = 18 + 2 + 5 = 20 + 5 = 25
```

### 估算

不需要精确计算时，可以估算：

```
28 + 15 ≈ 30 + 15 = 45
（实际是 43，估算值接近）
```

## 加法的应用

#### 求和问题

- 求几个数的总和
- 求连续数的和

#### 增加问题

- 原来有多少，增加了多少，现在有多少
- 增长率计算

#### 组合问题

- 几种物品的组合数量
- 路径选择问题
