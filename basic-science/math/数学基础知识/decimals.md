# 数学基础：小数

学会了整数，现在让我们认识一种更"精确"的数字 —— **小数**！小数帮助我们表示"不是整数"的数量。

## 什么是小数？

**小数**是表示部分数量的数字，比如：

- 1.5（一个半）
- 3.14（三点一四）
- 0.25（零点二五）

小数由**整数部分**、**小数点**和**小数部分**组成：

```
   3  .  1  4
   ↑     ↑  ↑
整数   小数 小数
部分   点  部分
```

## 小数的读法

### 基本读法

- **0.5**：读作"零点五"或"十分之五"
- **1.25**：读作"一点二五"或"一又百分之二十五"
- **3.14159**：读作"三点一四一五九"

### 小数位数的名称

从右到左，小数部分每一位都有名称：

```
3  .   1    4    1    5     9
   ↑   ↑    ↑    ↑    ↑     ↑
    十分位 百分位 千分位 万分位 十万分位
```

- **十分位**：小数点后第一位（表示十分之一）
- **百分位**：小数点后第二位（表示百分之一）
- **千分位**：小数点后第三位（表示千分之一）

## 小数和分数的关系

小数和分数可以互相转换！

### 小数转分数

- **0.5** = 5/10 = 1/2（十分之五等于二分之一）
- **0.25** = 25/100 = 1/4（百分之二十五等于四分之一）
- **0.75** = 75/100 = 3/4（百分之七十五等于四分之三）

**规律**：
- 一位小数 → 分母是 10
- 两位小数 → 分母是 100
- 三位小数 → 分母是 1000

### 分数转小数

用分子除以分母：
- **1/2** = 1 ÷ 2 = 0.5
- **1/4** = 1 ÷ 4 = 0.25
- **3/4** = 3 ÷ 4 = 0.75

## 生活中的小数

### 价格

- 💰 一本书：29.99 元（二十九元九角九分）

- 📏 身高：1.65 米（一米六十五厘米）
- ⚖️ 体重：45.5 千克（四十五点五千克）
- 📐 长度：2.5 厘米（二点五厘米）

- ⏰ 跑步用时：12.5 秒（十二点五秒）

### 科学数据

- 🌡️ 体温：36.5°C

## 小数的运算

### 加法

对齐小数点，然后相加：

```
  3.25
+ 1.75
------
  5.00
```

就像你有 3.25 元，又得到 1.75 元，现在有 5.00 元。

### 减法

对齐小数点，然后相减：

```
  5.50
- 2.25
------
  3.25
```

就像你有 5.50 元，花了 2.25 元，还剩 3.25 元。

### 乘法

先按整数乘法计算，然后数小数点后有多少位：

```
  2.5
× 1.2
------
   50
  25
------
  3.00
```

**规律**：两个小数相乘，结果的小数位数 = 两个小数的小数位数之和
- 2.5（1位） × 1.2（1位） = 3.00（2位）

### 除法

移动小数点，使除数变成整数：

```
12.5 ÷ 2.5 = 125 ÷ 25 = 5
```

**步骤**：
1. 把除数和被除数的小数点都向右移动相同位数
2. 使除数变成整数
3. 按整数除法计算

## 小数的大小比较

### 比较规则

1. **先比较整数部分**：整数部分大的，整个小数就大
   - 3.5 > 2.9（因为 3 > 2）

2. **整数部分相同，比较小数部分**：从十分位开始，逐位比较
   - 2.35 > 2.32（因为十分位都是 3，但百分位 5 > 2）
   - 1.25 < 1.3（因为十分位 2 < 3）

### 比较示例

```
0.1 < 0.2 < 0.25 < 0.3 < 0.5 < 1.0
```

## 特殊小数

### 有限小数

小数部分位数有限的小数：
- 0.5（一位小数）
- 0.25（两位小数）
- 0.125（三位小数）

### 无限小数

小数部分位数无限的小数：
- **循环小数**：0.333... = 0.3̅（三循环）
- **无限不循环小数**：π = 3.1415926535...（圆周率）

## 小数的近似

有时候我们需要把小数"四舍五入"：

- **四舍五入到整数**：
  - 3.4 ≈ 3（3.4 更接近 3）
  - 3.6 ≈ 4（3.6 更接近 4）

- **四舍五入到一位小数**：
  - 3.45 ≈ 3.5（百分位是 5，向前进 1）
  - 3.44 ≈ 3.4（百分位是 4，舍去）
