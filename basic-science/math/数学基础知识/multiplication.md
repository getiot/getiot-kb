# 数学基础：乘法

乘法是加法的"快速版本"！当我们把相同的数加很多次时，用乘法会更方便。让我们一起来学习乘法吧！

## 什么是乘法？

**乘法**是把相同的数加很多次的简便方法。

乘法的符号是 **×**（乘号）或 **·**（点号），读作"乘"或"times"。

### 基本形式

```
3 × 4 = 12
 ↑   ↑   ↑
乘数 乘数 积
```

- **乘数**：参与相乘的数（3 和 4）
- **积**：相乘的结果（12）

### 乘法的本质

乘法就是重复加法：

```
3 × 4 = 3 + 3 + 3 + 3 = 12
```

**理解**：3 个 4，或者 4 个 3，结果都是 12。

## 生活中的乘法

#### 购物

- 🛒 一个苹果 3 元，买 4 个
  - 总共：3 × 4 = 12 元

#### 数东西

- 🍎 每盘有 5 个苹果，有 3 盘
  - 一共有：5 × 3 = 15 个苹果

#### 时间

- ⏰ 每天学习 2 小时，学习 5 天
  - 一共学习了：2 × 5 = 10 小时

#### 面积

- 📐 长方形的长是 5 米，宽是 3 米
  - 面积：5 × 3 = 15 平方米

## 乘法的计算方法

### 乘法口诀表

熟记乘法口诀表，是快速计算的基础：

```
1×1=1  1×2=2  1×3=3  ...  1×9=9
2×1=2  2×2=4  2×3=6  ...  2×9=18
3×1=3  3×2=6  3×3=9  ...  3×9=27
...
9×1=9  9×2=18 9×3=27 ...  9×9=81
```

### 一位数乘法

直接使用口诀：

```
3 × 4 = 12
5 × 6 = 30
7 × 8 = 56
```

### 多位数乘法（竖式计算）

#### 两位数乘一位数

```
  23
×  4
----
  92
```

**步骤**：
1. 从右到左，用一位数依次乘多位数的每一位
2. 个位：3 × 4 = 12（写 2，向十位进 1）
3. 十位：2 × 4 + 1（进位）= 9
4. 结果：92

#### 两位数乘两位数

```
  23
× 15
----
 115  （23 × 5）
 23   （23 × 10，实际是 23 × 1，但要写在十位上）
----
 345
```

**步骤**：
1. 先用个位数乘被乘数：23 × 5 = 115
2. 再用十位数乘被乘数：23 × 1 = 23（写在十位上，实际是 230）
3. 把两个结果相加：115 + 230 = 345

### 小数的乘法

先按整数乘法计算，再确定小数点的位置：

```
  2.5
× 1.2
----
   50  （25 × 2）
  25   （25 × 1）
----
  3.00
```

**步骤**：
1. 先忽略小数点，按整数乘法计算：25 × 12 = 300
2. 数小数点后的位数：2.5（1位） + 1.2（1位） = 2位
3. 在结果中从右往左数 2 位，点上小数点：3.00

**规律**：积的小数位数 = 两个乘数的小数位数之和

### 分数的乘法

分子乘分子，分母乘分母：

```
1/2 × 1/3 = (1×1)/(2×3) = 1/6
2/3 × 3/4 = (2×3)/(3×4) = 6/12 = 1/2
```

**步骤**：
1. 分子相乘：1 × 1 = 1
2. 分母相乘：2 × 3 = 6
3. 结果：1/6
4. 能约分的要约分

## 乘法的性质

### 交换律

两个数相乘，交换位置，积不变：

```
3 × 5 = 5 × 3 = 15
```

**理解**：3 个 5 和 5 个 3，总数一样。

### 结合律

三个数相乘，先乘前两个或先乘后两个，积不变：

```
(3 × 5) × 2 = 3 × (5 × 2) = 30
```

### 分配律

一个数乘两个数的和，等于这个数分别乘这两个数，再把积相加：

```
3 × (5 + 2) = 3 × 5 + 3 × 2 = 15 + 6 = 21
```

**理解**：3 个（5+2）等于 3 个 5 加上 3 个 2。

### 1 的性质

任何数乘 1，结果还是这个数：

```
5 × 1 = 5
1 × 5 = 5
```

### 0 的性质

任何数乘 0，结果都是 0：

```
5 × 0 = 0
0 × 5 = 0
```

**理解**：0 个任何东西，都是 0。

## 乘法的技巧

### 凑整法

把数字凑成整十、整百，计算更简单：

```
25 × 4 = 25 × 2 × 2 = 50 × 2 = 100
```

### 分解法

把大数分解成容易计算的数：

```
12 × 15 = 12 × (10 + 5) = 12 × 10 + 12 × 5 = 120 + 60 = 180
```

### 平方数

记住一些常用的平方数：

```
1² = 1
2² = 4
3² = 9
4² = 16
5² = 25
...
10² = 100
```

### 估算

不需要精确计算时，可以估算：

```
28 × 15 ≈ 30 × 15 = 450
（实际是 420，估算值接近）
```

```

```

```

5 × 5 = 5² = 25
```
