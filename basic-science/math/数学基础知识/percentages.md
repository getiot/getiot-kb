# 数学基础：百分数

百分数是我们生活中最常见的数学表达方式之一！从考试成绩到商品折扣，百分数无处不在。

## 什么是百分数？

**百分数**表示一个数是另一个数的百分之几，用符号 **%** 表示。

百分数实际上是一种特殊的分数，分母固定为 100：

```
50% = 50/100 = 1/2 = 0.5
25% = 25/100 = 1/4 = 0.25
75% = 75/100 = 3/4 = 0.75
```

### 百分号的含义

**%** 读作"百分之"或"percent"（英文）：
- **50%**：读作"百分之五十"或"五十 percent"
- **100%**：读作"百分之百"或"一百 percent"，表示全部、完整

## 百分数、分数、小数的转换

### 百分数转小数

去掉百分号，小数点向左移动两位：

```
50% = 0.50 = 0.5
25% = 0.25
100% = 1.00 = 1
125% = 1.25
```

### 小数转百分数

小数点向右移动两位，加上百分号：

```
0.5 = 0.50 = 50%
0.25 = 25%
1 = 1.00 = 100%
1.25 = 125%
```

### 分数转百分数

先把分数转成小数，再转成百分数：

```
1/2 = 0.5 = 50%
1/4 = 0.25 = 25%
3/4 = 0.75 = 75%
1/3 = 0.333... ≈ 33.3%
```

## 生活中的百分数

### 考试成绩

- 📝 数学考试得了 95 分，满分 100 分 = **95%**
- 📝 语文考试得了 80 分，满分 100 分 = **80%**

### 商品折扣

- 🛍️ 原价 100 元，打 8 折 = 打 **80%** = 现价 80 元
- 🛍️ 原价 200 元，打 5 折 = 打 **50%** = 现价 100 元

### 概率和统计

- 🎲 抛硬币，正面朝上的概率 = **50%**
- 📊 班级有 30 个学生，其中 18 个是女生 = 女生占 **60%**

### 浓度和比例

- 🧪 盐水浓度 = **5%**（表示 100 克盐水中含 5 克盐）
- 🥛 牛奶含脂肪 **3%**（表示 100 毫升牛奶中含 3 毫升脂肪）

### 增长率

- 📈 今年收入比去年增长 **20%**
- 📉 股票价格下跌 **10%**

## 百分数的计算

### 求一个数的百分之几

用这个数乘以百分数（转成小数）：

```
求 200 的 25%：
200 × 25% = 200 × 0.25 = 50
```

**例子**：
- 一件衣服原价 200 元，打 8 折（80%），现价是多少？
  - 200 × 80% = 200 × 0.8 = 160 元

### 求一个数是另一个数的百分之几

用这个数除以另一个数，再乘以 100%：

```
求 50 是 200 的百分之几：
50 ÷ 200 × 100% = 0.25 × 100% = 25%
```

**例子**：
- 考试得了 80 分，满分 100 分，得分率是多少？
  - 80 ÷ 100 × 100% = 80%

### 已知一个数的百分之几，求这个数

用已知的数除以百分数（转成小数）：

```
已知一个数的 25% 是 50，求这个数：
50 ÷ 25% = 50 ÷ 0.25 = 200
```

**例子**：
- 一件衣服打 8 折后是 160 元，原价是多少？
  - 160 ÷ 80% = 160 ÷ 0.8 = 200 元

## 百分数的应用

### 折扣计算

**公式**：现价 = 原价 × 折扣率

- 原价 100 元，打 9 折（90%）：100 × 0.9 = 90 元
- 原价 200 元，打 7.5 折（75%）：200 × 0.75 = 150 元

### 增长率计算

**公式**：增长率 = (新值 - 旧值) ÷ 旧值 × 100%

- 去年收入 10000 元，今年收入 12000 元
  - 增长率 = (12000 - 10000) ÷ 10000 × 100% = 20%

### 百分比变化

**公式**：变化率 = (变化量) ÷ 原值 × 100%

- 股票从 100 元涨到 110 元
  - 涨幅 = (110 - 100) ÷ 100 × 100% = 10%

## 常见的百分数

### 常用百分数对应表

| 百分数 | 分数 | 小数 | 含义 |
|:------:|:----:|:----:|:----:|
| 0% | 0/100 | 0 | 完全没有 |
| 25% | 1/4 | 0.25 | 四分之一 |
| 50% | 1/2 | 0.5 | 一半 |
| 75% | 3/4 | 0.75 | 四分之三 |
| 100% | 1 | 1 | 全部、完整 |

### 特殊百分数

- **0%**：完全没有
- **50%**：一半
- **100%**：全部、完整
- **200%**：两倍（超过 100% 表示超过原值）
