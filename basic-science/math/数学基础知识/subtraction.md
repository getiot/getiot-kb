# 数学基础：减法

减法是加法的"反向操作"，就像把东西拿走一样。让我们一起来学习减法吧！

## 什么是减法？

**减法**是从一个数中减去另一个数，得到它们的差。

减法的符号是 **-**（减号），读作"减"或"minus"。

**基本形式**

```
5 - 2 = 3
 ↑   ↑   ↑
被减数 减数 差
```

- **被减数**：被减去的数（5）
- **减数**：要减去的数（2）
- **差**：相减的结果（3）

## 减法与加法的关系

减法是加法的逆运算：

```
如果 3 + 2 = 5
那么 5 - 2 = 3
     5 - 3 = 2
```

**理解**：
- 加法：知道两部分，求总数
- 减法：知道总数和一部分，求另一部分

## 生活中的减法

#### 购物找零

- 💰 买了一个 8 元的玩具，给了 10 元
  - 应该找零：10 - 8 = 2 元

#### 消耗物品

- 🍎 原来有 10 个苹果，吃了 3 个
  - 还剩：10 - 3 = 7 个苹果

#### 时间计算

- ⏰ 现在是下午 3 点，2 小时前是几点？
  - 3 - 2 = 1 点（下午 1 点）

#### 距离计算

- 📏 从家到学校 5 公里，已经走了 2 公里
  - 还剩：5 - 2 = 3 公里

## 减法的计算方法

### 一位数减法

最简单的减法，直接心算：

```
5 - 2 = 3
9 - 4 = 5
8 - 3 = 5
```

### 多位数减法（竖式计算）

当数字较大时，用竖式计算：

#### 不退位减法

```
  38
- 15
----
  23
```

**步骤**：
1. 对齐数位（个位对个位，十位对十位）
2. 从右到左逐位相减
3. 个位：8 - 5 = 3
4. 十位：3 - 1 = 2
5. 结果：23

#### 退位减法

当某一位不够减时，需要向高位借位：

```
  32
- 15
----
  17
```

**步骤**：
1. 个位：2 - 5 不够减，向十位借 1
2. 个位变成：12 - 5 = 7
3. 十位：3 - 1（被借走 1）- 1 = 1
4. 结果：17

**退位规则**：
- 当某一位不够减时，向高位借 1
- 借来的 1 相当于本位的 10

### 连续减法

可以依次相减：

```
10 - 3 - 2 = (10 - 3) - 2 = 7 - 2 = 5
```

## 小数的减法

对齐小数点，然后相减：

```
  5.50
- 2.25
------
  3.25
```

**步骤**：
1. 对齐小数点
2. 从右到左逐位相减
3. 百分位：0 - 5 不够减，向十分位借 1
4. 百分位变成：10 - 5 = 5
5. 十分位：5 - 1（被借走 1）- 2 = 2
6. 个位：5 - 2 = 3
7. 结果：3.25

## 分数的减法

### 同分母分数相减

分母相同，分子相减：

```
3/4 - 1/4 = 2/4 = 1/2
```

**步骤**：
1. 分母不变
2. 分子相减：3 - 1 = 2
3. 约分：2/4 = 1/2

### 异分母分数相减

先通分，再相减：

```
1/2 - 1/3 = 3/6 - 2/6 = 1/6
```

**步骤**：
1. 找最小公倍数：2 和 3 的最小公倍数是 6
2. 通分：1/2 = 3/6，1/3 = 2/6
3. 分子相减：3 - 2 = 1
4. 结果：1/6

## 减法的性质

### 减法的交换律不成立

减法不能交换位置：

```
5 - 3 = 2
3 - 5 = -2  （结果不同！）
```

**注意**：减法没有交换律！

### 减法的结合律不成立

减法不能随意结合：

```
(10 - 3) - 2 = 7 - 2 = 5
10 - (3 - 2) = 10 - 1 = 9  （结果不同！）
```

**注意**：减法没有结合律！

### 零的性质

任何数减 0，结果还是这个数：

```
5 - 0 = 5
```

任何数减它自己，结果是 0：

```
5 - 5 = 0
```

## 减法的技巧

### 凑整法

把减数凑成整十、整百，计算更简单：

```
25 - 8 = 25 - 5 - 3 = 20 - 3 = 17
```

### 借位技巧

熟练掌握借位，提高计算速度：

```
  42
- 18
----
  24
```

**快速方法**：
- 个位：12 - 8 = 4（直接想 2 不够减 8，借位后是 12）
- 十位：4 - 1 - 1 = 2

### 估算

不需要精确计算时，可以估算：

```
52 - 18 ≈ 50 - 20 = 30
（实际是 34，估算值接近）
```

## 减法的应用

#### 求差问题

- 两个数相差多少
- 比较大小

#### 剩余问题

- 原来有多少，用去多少，还剩多少
- 消耗、减少问题

#### 时间差

- 计算时间间隔
- 计算年龄差

#### 距离差

- 计算剩余距离
- 计算高度差

## 减法与负数的关系

当被减数小于减数时，结果是负数：

```
3 - 5 = -2
```

**理解**：
- 你有 3 个苹果，要给别人 5 个
- 不够给，还欠 2 个
- 所以结果是 -2
