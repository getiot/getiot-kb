# 数列概述

数列是按一定规律排列的一列数，是数学中重要的概念，在数学、物理、计算机科学等领域都有广泛应用！

## 什么是数列？

**数列**（Sequence）是按一定顺序排列的一列数。

### 简单理解

数列就像"排队"：

- 每个数都有自己的"位置"（第1个、第2个、第3个...）
- 这些数按照某种规律排列
- 我们可以用公式表示第 n 个数是多少

### 例子

```
1, 2, 3, 4, 5, ...        （自然数数列）
2, 4, 6, 8, 10, ...       （偶数数列）
1, 4, 9, 16, 25, ...      （平方数数列）
1, 1, 2, 3, 5, 8, ...     （斐波那契数列）
```

## 为什么要学数列？

### 描述规律

数列帮助我们描述和发现规律：

- 📊 **数据分析**：分析数据的规律和趋势
- 🔢 **数学建模**：用数列描述实际问题
- 💻 **算法设计**：理解算法的时间复杂度

### 解决实际问题

数列在解决实际问题中非常有用：

- 💰 **金融计算**：复利、分期付款等
- 📈 **增长模型**：人口增长、经济增长等
- ⚙️ **工程问题**：优化设计、资源分配等

### 培养逻辑思维

学习数列能培养我们的逻辑思维能力：

- 发现规律
- 归纳总结
- 推理证明

## 数列的分类

### 按项数分类

- **有穷数列**：项数有限
- **无穷数列**：项数无限

### 按规律分类

- **等差数列**：相邻两项的差相等
- **等比数列**：相邻两项的比相等
- **斐波那契数列**：特殊的递推数列
- **调和数列**：倒数为等差数列的数列

### 按单调性分类

- **递增数列**：每一项都比前一项大
- **递减数列**：每一项都比前一项小
- **常数列**：所有项都相等
- **摆动数列**：有增有减
