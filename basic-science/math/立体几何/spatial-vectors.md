# 空间向量

空间向量是描述空间位置和方向的重要工具！理解空间向量，能帮助我们更好地理解空间几何。

## 什么是空间向量？

**空间向量**（Spatial Vector）是既有大小又有方向的量，在三维空间中表示。

### 简单理解

空间向量就像"带方向的箭头"：

- 有起点和终点
- 有长度（大小）
- 有方向

### 表示方法

空间向量可以用：

- **有向线段**：$\overrightarrow{AB}$（从 $A$ 到 $B$）
- **坐标表示**：$\vec{v} = (x, y, z)$
- **单位向量**：$\vec{i} = (1, 0, 0)$，$\vec{j} = (0, 1, 0)$，$\vec{k} = (0, 0, 1)$

## 空间向量的坐标表示

### 坐标形式

如果向量 $\vec{v}$ 的起点是原点 $O(0, 0, 0)$，终点是 $P(x, y, z)$，则：

$$\vec{v} = (x, y, z)$$

其中：
- **$x$**：$x$ 轴方向的分量
- **$y$**：$y$ 轴方向的分量
- **$z$**：$z$ 轴方向的分量

### 模长（大小）

向量 $\vec{v} = (x, y, z)$ 的模长：

$$|\vec{v}| = \sqrt{x^2 + y^2 + z^2}$$

**例子**：
- 向量 $\vec{v} = (3, 4, 5)$
- 模长 $|\vec{v}| = \sqrt{3^2 + 4^2 + 5^2} = \sqrt{9 + 16 + 25} = \sqrt{50} = 5\sqrt{2}$

## 空间向量的运算

### 加法

如果 $\vec{u} = (x_1, y_1, z_1)$，$\vec{v} = (x_2, y_2, z_2)$，则：

$$\vec{u} + \vec{v} = (x_1 + x_2, y_1 + y_2, z_1 + z_2)$$

**几何意义**：向量加法的平行四边形法则或三角形法则

### 减法

如果 $\vec{u} = (x_1, y_1, z_1)$，$\vec{v} = (x_2, y_2, z_2)$，则：

$$\vec{u} - \vec{v} = (x_1 - x_2, y_1 - y_2, z_1 - z_2)$$

### 数乘

如果 $\vec{v} = (x, y, z)$，$k$ 是实数，则：

$$k\vec{v} = (kx, ky, kz)$$

**几何意义**：
- 如果 $k > 0$，方向不变，长度变为原来的 $k$ 倍
- 如果 $k < 0$，方向相反，长度变为原来的 $|k|$ 倍

### 点积（数量积）

如果 $\vec{u} = (x_1, y_1, z_1)$，$\vec{v} = (x_2, y_2, z_2)$，则：

$$\vec{u} \cdot \vec{v} = x_1x_2 + y_1y_2 + z_1z_2$$

**几何意义**：

$$\vec{u} \cdot \vec{v} = |\vec{u}||\vec{v}|\cos\theta$$

其中 $\theta$ 是两向量的夹角

**性质**：
- 如果 $\vec{u} \perp \vec{v}$，则 $\vec{u} \cdot \vec{v} = 0$
- 如果 $\vec{u} \parallel \vec{v}$，则 $\vec{u} \cdot \vec{v} = |\vec{u}||\vec{v}|$（同向）或 $-|\vec{u}||\vec{v}|$（反向）

### 叉积（向量积）

如果 $\vec{u} = (x_1, y_1, z_1)$，$\vec{v} = (x_2, y_2, z_2)$，则：

$$\vec{u} \times \vec{v} = \begin{vmatrix}
\vec{i} & \vec{j} & \vec{k} \\
x_1 & y_1 & z_1 \\
x_2 & y_2 & z_2
\end{vmatrix} = (y_1z_2 - z_1y_2, z_1x_2 - x_1z_2, x_1y_2 - y_1x_2)$$

**几何意义**：
- 结果是一个向量，垂直于 $\vec{u}$ 和 $\vec{v}$ 所在的平面
- 方向由右手法则确定
- 模长 $|\vec{u} \times \vec{v}| = |\vec{u}||\vec{v}|\sin\theta$（$\theta$ 是两向量的夹角）

## 单位向量

### 定义

**单位向量**是模长为 1 的向量。

### 求法

如果 $\vec{v} \neq \vec{0}$，则单位向量：

$$\vec{e} = \frac{\vec{v}}{|\vec{v}|}$$

**例子**：
- 向量 $\vec{v} = (3, 4, 5)$
- 模长 $|\vec{v}| = 5\sqrt{2}$
- 单位向量 $\vec{e} = \frac{(3, 4, 5)}{5\sqrt{2}} = \left(\frac{3}{5\sqrt{2}}, \frac{4}{5\sqrt{2}}, \frac{5}{5\sqrt{2}}\right)$

## 空间向量的应用

### 表示位置

- 📍 **点的位置**：用向量表示点的位置
- 📐 **位移**：用向量表示位移

### 表示方向

- 🧭 **方向**：用向量表示方向
- 📐 **法向量**：用向量表示平面的法向量

### 计算

- 📊 **距离**：用向量计算距离
- 📐 **角度**：用向量计算角度
- 📦 **面积**：用叉积计算面积

## 生活中的应用

#### 物理

- ⚡ **力**：力是向量
- 🚀 **速度**：速度是向量
- 📐 **加速度**：加速度是向量

#### 计算机图形学

- 💻 **3D 图形**：用向量表示 3D 图形
- 🎮 **游戏开发**：用向量进行游戏开发

#### 工程

- 🏗️ **工程计算**：用向量进行工程计算
- ⚙️ **机械设计**：用向量进行机械设计

## 常见错误

#### 错误 1：向量和标量混淆

- **向量**：有大小和方向
- **标量**：只有大小，没有方向

#### 错误 2：点积和叉积混淆

- **点积**：结果是标量
- **叉积**：结果是向量

#### 错误 3：模长计算错误

模长公式是 $\sqrt{x^2 + y^2 + z^2}$，不要忘记开平方。

2. 如果向量 $\vec{v} = (3, 4, 5)$，求 $|\vec{v}|$ 和单位向量
3. 如果向量 $\vec{u} = (1, 0, 0)$，$\vec{v} = (0, 1, 0)$，求 $\vec{u} \cdot \vec{v}$ 和 $\vec{u} \times \vec{v}$
4. 应用题：用向量计算空间中两点 $A(1, 2, 3)$ 和 $B(4, 5, 6)$ 之间的距离
