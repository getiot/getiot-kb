# 无理方程

无理方程是根号下含有未知数的方程。解无理方程的关键是"去根号"，同样需要特别注意检验！

## 什么是无理方程？

**无理方程**是根号下含有未知数的方程。

**例子**：

```
√(x + 1) = 3
√(x - 2) + √(x + 3) = 5
√(2x + 1) = x - 1
```

## 解无理方程的方法

### 基本步骤

1. **移项**（把根号单独放在一边）
2. **两边平方**（去根号）
3. **解整式方程**
4. **检验**（⚠️ 非常重要！把解代入原方程验证）

### 例子 1：简单无理方程

```
√(x + 1) = 3
```

**步骤**：
1. 根号已经在一边，直接两边平方：
   ```
   [√(x + 1)]² = 3²
   x + 1 = 9
   ```
2. 求解：x = 8
3. **检验**：
   - 左边：√(8 + 1) = √9 = 3
   - 右边：3
   - 左边 = 右边 ✓
   - 且根号下 8 + 1 = 9 ≥ 0 ✓
4. 所以 x = 8 是方程的解

### 例子 2：需要移项

```
√(x - 2) = x - 4
```

**步骤**：
1. 根号已经在一边，两边平方：
   ```
   [√(x - 2)]² = (x - 4)²
   x - 2 = x² - 8x + 16
   ```
2. 移项：x² - 8x + 16 - x + 2 = 0
3. 化简：x² - 9x + 18 = 0
4. 因式分解：(x - 3)(x - 6) = 0
5. 所以 x = 3 或 x = 6
6. **检验**：
   - 当 x = 3 时：
     - 左边：√(3 - 2) = √1 = 1
     - 右边：3 - 4 = -1
     - 左边 ≠ 右边 ✗
     - 所以 x = 3 是增根，舍去
   - 当 x = 6 时：
     - 左边：√(6 - 2) = √4 = 2
     - 右边：6 - 4 = 2
     - 左边 = 右边 ✓
     - 且根号下 6 - 2 = 4 ≥ 0 ✓
7. 所以 x = 6 是方程的解

### 例子 3：两个根号

```
√(x + 1) + √(x - 2) = 5
```

**步骤**：
1. 移项：√(x + 1) = 5 - √(x - 2)
2. 两边平方：
   ```
   [√(x + 1)]² = [5 - √(x - 2)]²
   x + 1 = 25 - 10√(x - 2) + (x - 2)
   ```
3. 化简：x + 1 = 23 - 10√(x - 2) + x
4. 移项：10√(x - 2) = 22
5. 化简：√(x - 2) = 2.2
6. 再次平方：x - 2 = 4.84
7. 求解：x = 6.84
8. **检验**：
   - 左边：√(6.84 + 1) + √(6.84 - 2) = √7.84 + √4.84 ≈ 2.8 + 2.2 = 5
   - 右边：5
   - 左边 ≈ 右边 ✓
9. 所以 x = 6.84 是方程的解

## 增根问题

### 为什么会产生增根？

两边平方时，我们可能引入使原方程不成立的解。

**例子**：
```
√(x - 2) = -3
```

- 左边：√(x - 2) ≥ 0（根号值非负）
- 右边：-3 < 0
- 所以原方程**无解**

但如果两边平方：
```
x - 2 = 9
x = 11
```

- x = 11 是平方后得到的，但代入原方程：
  - √(11 - 2) = √9 = 3 ≠ -3
- 所以 x = 11 是**增根**

### 如何避免增根？

1. **检验**：把解代入原方程验证
2. **检查根号下的值**：确保根号下的表达式 ≥ 0
3. **检查根号的值**：如果原方程是 √A = B，要确保 B ≥ 0

## 检验的重要性

**检验步骤**：

1. 把解代入原方程的**根号下**
2. 检查根号下的值是否 ≥ 0
3. 计算根号的值，代入原方程验证等式是否成立
4. 如果等式不成立，这个解是**增根**，要舍去

## 特殊情况的处理

### 情况 1：根号下为负数

如果解使根号下的值为负数，这个解是增根。

### 情况 2：根号值为负数

如果原方程是 √A = B，且 B < 0，则方程无解（因为根号值 ≥ 0）。

### 情况 3：多个根号

需要多次平方，每次平方后都要检验。

## 生活中的应用

#### 距离问题

- 📏 根据勾股定理，两点间距离涉及平方根
  - 可以建立无理方程求解

#### 物理问题

- ⚽ 自由落体、抛体运动等涉及根号
  - 可以建立无理方程求解

## 常见错误

### 错误 1：忘记检验

解无理方程**必须检验**，否则可能得到增根！

### 错误 2：平方时展开错误

平方时要仔细展开，特别是 (a - b)² = a² - 2ab + b²。

### 错误 3：忽略根号值的非负性

根号的值总是 ≥ 0，这是判断增根的重要依据。
