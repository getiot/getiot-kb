# 方程概述

方程是数学中最重要的工具之一！它帮助我们解决"未知数"的问题，就像侦探破案一样，通过已知的线索找出答案。

## 什么是方程？

**方程**（Equation）是用等号连接两个代数表达式的数学式子，表示两个量相等。

简单理解，方程就像天平：

```
左边 = 右边
```

- 左边和右边必须平衡（相等）
- 我们的任务就是找出让天平平衡的"未知数"

例子：

```
3 + 2 = 5          ← 这是等式（没有未知数）
x + 2 = 5          ← 这是方程（有未知数 x）
2x - 3 = 7         ← 这也是方程
x² + 3x = 10       ← 这也是方程
```

## 为什么要学方程？

### 解决实际问题

方程帮助我们解决生活中的各种问题：

- 🍎 **购物问题**：一个苹果多少钱？
- ⏰ **时间问题**：需要多长时间完成任务？
- 📏 **测量问题**：这个长方形的长是多少？
- 💰 **经济问题**：需要多少本金才能达到目标？

### 培养逻辑思维

解方程的过程就是逻辑推理的过程：

1. **分析问题**：找出已知条件和未知数
2. **建立方程**：用数学语言表达问题
3. **解方程**：运用数学方法求解
4. **验证答案**：检查答案是否正确

这个过程能很好地训练我们的逻辑思维能力！

## 方程的分类

### 按未知数个数分类

- **一元方程**：只有一个未知数，如 x + 2 = 5
- **二元方程**：有两个未知数，如 x + y = 10
- **三元方程**：有三个未知数，如 x + y + z = 15

### 按未知数的最高次数分类

- **一次方程**：未知数的最高次数是 1，如 2x + 3 = 7
- **二次方程**：未知数的最高次数是 2，如 x² - 5x + 6 = 0
- **高次方程**：未知数的最高次数大于 2，如 x³ + 2x = 10

### 按方程形式分类

- **整式方程**：分母中没有未知数，如 2x + 3 = 7
- **分式方程**：分母中有未知数，如 1/(x+1) = 2
- **无理方程**：根号下有未知数，如 √(x+1) = 3
