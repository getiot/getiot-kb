# SquareLine Studio 开发工具



SquareLine Studio 是 LVGL 官方推出的一款跨平台 UI 开发工具，支持 Windows、Linux 和 macOS 平台。SquareLine Studio 采用所见即所得的开发方式，可大大减少用户开发 UI 的时间。



## 安装

下载地址：[https://squareline.io/downloads](https://squareline.io/downloads)

SquareLine_Studio_Linux_v1_1_1.zip

```bash
mkdir SquareLine_Studio
unzip SquareLine_Studio_Linux_v1_1_1.zip -d SquareLine_Studio
```



```bash
chmod +x setup.sh 
./setup.sh
```
