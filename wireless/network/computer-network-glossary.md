# 计算机网络名词解释

计算机网络是现代信息技术的核心组成部分，涉及许多专业术语和技术概念，本文介绍一些计算机网络中常见的名词及其解释。

- **OSI 七层模型**：国际标准化组织（ISO）制定的一个用于计算机或通信系统间互联的标准体系，这个模型把网络通信的工作分为7层，分别是物理层、数据链路层、网络层、传输层、会话层、表示层和应用层。OSI 是 Open System Interconnection 的缩写，因此也称为一般称为 OSI 参考模型。
- **交换机**（Switch）：用于连接多个网络设备（如计算机、服务器、打印机等）的硬件设备，通过报文（数据帧）交换接收和转发数据到目标设备。交换机是一种多端口的网桥，属于 OSI 体系结构的第二层，在数据链路层使用 MAC 地址转发数据。
- **路由器**（Router）：用于连接多个网络或子网的设备，在网络间起网关的作用，并根据数据包的目的地址（IP 地址）选择最佳路径进行转发。路由器属于 OSI 体系结构的第三层，即网络层。实际上，现在一些交换机也可以在网络层转发数据，这种交换机也被称为三层交换机。
- **调制解调器**（Modem）：Modulator（调制器）和 Demodulator（解调器）的组合，用于将数字信号转换为模拟信号（调制），或将模拟信号转换为数字信号（解调）。Modem 在国内常被称为“猫”，例如“光猫”就是通过光纤接入互联网的 Modem。
- **WAN**（Wide Area Network）：广域网，覆盖范围较广的网络，通常跨越城市、国家或全球。
- **LAN**（Local Area Network）：局域网，覆盖范围较小的网络，通常在一个建筑或校园内。
- **VLAN**（Virtual Local Area Network）：虚拟局域网，通过逻辑划分将物理网络划分为多个虚拟网络。
- **MAN**（Metropolitan Area Network）：城域网，覆盖范围介于局域网和广域网之间的网络，通常覆盖一个城市或地区。
- **以太网**（Ethernet）：一种广泛使用的局域网（LAN）技术，用于连接计算机、服务器、打印机等设备。它是由 IEEE 802.3 标准制定的技术标准，规定了包括物理层的连线、电子信号和介质访问控制的内容。支持双绞线、光纤等多种传输介质，支持 10Mbps、100Mbps、1Gbps、10Gbps 等多种速率。
- **TCP/IP**：一组用于互联网通信的协议族，是一种泛称，TCP/IP 协议族也是整个互联网的基础协议。
- **协议**（Protocol）：网络通信中的一组规则和标准，用于定义数据的格式、传输方式和错误处理机制。例如 IP、TCP、UDP、HTTP、FTP、SMTP 协议等等。
- **IP**（Internet Protocol，互联网协议）：IP 是网络层的核心协议，用于在互联网上进行数据包的传输。IP 也是互联网的基础协议，位于网络层，支持多种网络架构，例如 TCP、UDP 都是在 IP 协议基础上实现的。
- **TCP**（Transmission Control Protocol，传输控制协议）：一种面向连接的、可靠的、基于字节流的传输层协议。在数据传输之前，需要建立连接（三次握手）。并且通过确认、重传、拥塞控制等机制保证数据的可靠传输。适用于对可靠性要求较高的应用，如 HTTP、HTTPS、FTP、SMTP等。
- **UDP**（User Datagram Protocol，用户数据报协议）：一种无连接的、不可靠的传输层协议。UDP 不需要建立连接，直接发送数据，因此速度快、开销小。但是由于不保证数据的可靠传输，因此可能出现丢包或乱序。适用于对实时性要求较高的应用，如视频会议、在线游戏、DNS 查询等。
- **FTP**（File Transfer Protocol，文件传输协议）：用于在客户端和服务器之间传输文件的网络协议。FTP 基于 TCP 协议，可以暂停和恢复文件传输，默认端口为 21。
- **SMTP**（Simple Mail Transfer Protocol，简单邮件传输协议）：用于发送电子邮件。SMTP 基于 TCP 协议，邮件内容以文本形式传输，默认端口为 25。
- **HTTP**（Hypertext Transfer Protocol，超文本传输协议）：用于传输超文本（如 HTML）的协议，是 Web 的基础协议。HTTP 也是基于 TCP 协议，每一次浏览网页都是一次 HTTP 请求，默认端口为 80。
- **IP 地址**（Internet Protocol Address）：用于标识网络设备的唯一地址，分为 IPv4 和 IPv6 两种版本。IPv4 使用32位地址，如 `192.168.1.1`；而 IPv6 使用128位地址。
- **端口**（Port）：在网络通信中，端口是一个逻辑概念，用于标识计算机上运行的特定应用程序或服务。例如，HTTP 服务通常使用端口 80，HTTPS 使用端口 443。
- **MAC 地址**（Media Access Control Address）：一种硬件地址，用于标识网络设备的物理接口，是全球唯一的。由 48 位（6个字节）地址，通常以十六进制表示，如 `00:1A:2B:3C:4D:5E`。
- **子网掩码**（Subnet Mask）：用于区分 IP 地址中的网络部分和主机部分的掩码，通过子网掩码可以将 IP 地址划分为不同的子网，如 `255.255.255.0`（对应 CIDR 表示法 `/24`）。
- **DNS**（Domain Name System）：域名系统，用于将域名（如 `www.example.com`）转换为 IP 地址。有了 DNS，用户就可以通过域名访问互联网资源，而不是记住 IP 地址。
- **网关**（Gateway）：网络节点，用于连接不同的网络或子网，并在它们之间转发数据。网关通常作为网络的入口或出口，例如家庭路由器的 WAN 口。
- **防火墙**（Firewall）：一种网络安全设备，用于监控和控制网络流量，防止未经授权的访问。防火墙可以根据规则允许或拒绝特定流量，防止恶意攻击和数据泄露。
- **NAT**（Network Address Translation）：网络地址转换，用于将一个 IP 地址空间的地址转换为另一个地址空间的地址。NAT 技术可以节省 IP 地址，通过端口复用实现多个设备共享一个公网 IP，允许私有 IP 地址的设备通过公网 IP 地址访问互联网。
- **带宽**（Bandwidth）：网络链路的最大数据传输速率，通常以 bps（位/秒）或 Mbps（兆位/秒）表示。
- **延迟**（Latency）：数据在网络中传输的延迟时间，通常以毫秒（ms）表示。
- **吞吐量**（Throughput）：单位时间内实际传输的数据量，通常低于带宽。
- **丢包率**（Packet Loss Rate）：网络中丢失的数据包占总发送数据包的比例。
- **无线局域网**（WLAN，Wireless Local Area Network）：使用无线通信技术（如 Wi-Fi）实现的局域网，允许设备在一定范围内无线连接。
- **Wi-Fi**（Wireless Fidelity）：一种基于 IEEE 802.11 标准的无线网络技术，用于实现设备之间的无线通信。支持多种频段（2.4GHz 和 5GHz），提供无线接入点（AP）连接，允许设备接入互联网。
- **蓝牙**（Bluetooth）：一种短距离（10米以内）无线通信技术，主要用于设备之间的低功耗连接。实现设备之间的无线配对和数据传输。常用于耳机、手机、智能手表等设备。
- **SSID**（Service Set Identifier）：无线网络的名称，用于标识一个无线网络。用户通过 SSID 连接到特定的无线网络，可以隐藏 SSID 以增强安全性。
- **信道**（Channel）：在无线通信中，信道是指无线频段的划分，用于避免信号干扰。
- **AP**（Access Point，接入点）：无线网络中的设备，用于提供无线信号覆盖和接入服务。允许无线设备连接到有线网络。可以扩展无线网络的覆盖范围。
- **WEP/WPA/WPA2/WPA3**（加密协议）：无线网络的安全加密协议，用于保护无线网络免受未经授权的访问。
  - WEP（Wired Equivalent Privacy）：早期加密协议，安全性较低。
  - WPA（Wi-Fi Protected Access）：改进的加密协议。
  - WPA2：更安全的加密协议，广泛使用。
  - WPA3：最新的加密协议，提供更强的安全性。
- **RSSI**（Received Signal Strength Indicator，无线信号强度）：无线信号的强度指标，用于衡量设备接收到的无线信号的强度。评估无线网络的覆盖范围和信号质量。RSSI 值越高，信号质量越好。
- **无线频段**（2.4GHz/5GHz）：无线网络使用的频段，常见的有 2.4GHz 和 5GHz。
  - **2.4GHz**：覆盖范围广，但速率较低，适合远距离传输。
  - **5GHz**：速率高，但覆盖范围较小，适合近距离高速传输。
- **Mesh 网络**（Mesh Network）：一种分布式网络架构，通过多个节点（路由器或扩展器）组成一个无缝覆盖的网络。可以提高无线网络的覆盖范围和稳定性，适合大户型或复杂环境的无线覆盖。
- **QoS**（Quality of Service）：服务质量，是指使用在网络上运行的机制或技术来控制流量，确保关键应用程序在有限的网络容量下的性能。QoS 是网络的一种安全机制， 用来解决网络延迟和阻塞等问题。
- **PoE**（Power over Ethernet）：以太网供电，通过以太网电缆同时传输数据和电力。为网络设备（如 IP 摄像头、无线 AP）提供电力。使用 PoE 的优势是可以简化布线，降低安装成本。
- **静态 IP 地址**（Static IP Address）：固定分配的 IP 地址，不会自动更改。适用于需要固定 IP 地址的设备（如服务器、打印机），提高设备的可访问性。
- **动态 IP 地址**（Dynamic IP Address）：通过 DHCP 服务器动态分配的 IP 地址。自动管理 IP 地址分配，避免手动配置，提高 IP 地址的利用率。
- **DHCP**（Dynamic Host Configuration Protocol）：动态主机配置协议，用于自动分配 IP 地址。自动为设备分配 IP 地址、子网掩码、网关和 DNS 服务器，可简化网络管理，避免 IP 地址冲突。
- **UPnP**（Universal Plug and Play）：一种网络协议，用于简化设备之间的自动发现和配置。可自动配置端口转发规则，支持设备之间的无缝通信。
- **端口转发**（Port Forwarding）：将外部网络的特定端口请求转发到内部网络的特定设备。允许外部设备访问内部网络中的服务（如 FTP 服务器），常用于家庭网络和小型企业网络。
- **私网穿透**（NAT Traversal）：一种用于在 NAT（网络地址转换）环境下，使位于私有网络（如家庭或企业内网）中的设备能够被外部网络访问的技术。它通过在私有网络和公网之间建立隧道，实现数据的传输。
- **广播**（Broadcast）：广播是一种网络通信方式，指数据包从一个源节点发送到网络中所有节点。其优点是无需知道目标设备的具体地址即可发送数据，缺点是广播会占用大量网络带宽，可能导致网络拥塞。
- **单播**（Unicast）：单播是一种网络通信方式，指数据包从一个源节点发送到一个特定的目标节点。单播是最常见的网络通信方式，适用于点对点的通信，数据包只发送到一个指定的目标地址。
- **组播**（Multicast）：组播是一种网络通信方式，指数据包从一个源节点发送到一组特定的目标节点。组播使用特殊的组播地址来标识目标组，虽然数据包只发送一次，但可以在网络中分叉，到达多个目标节点。
- **网络拥塞**（Network Congestion）：是指网络中的数据流量超过网络的承载能力，导致数据传输延迟增加、丢包或服务质量下降的现象。可以通过协议（如 TCP 的拥塞控制机制）动态调整发送速率，或升级网络设备，提升链路容量。
- **滑动窗口**（Sliding Window）：滑动窗口是一种流量控制机制，用于控制发送方和接收方之间的数据传输速率，以避免发送方发送过多数据导致接收方或网络拥塞。工作原理是接收方通过滑动窗口通知发送方其接收缓冲区的大小；发送方根据窗口大小调整发送数据的量。
- **RJ45**：以太网常见的网络硬件接口类型，用于连接以太网电缆（如双绞线）。
