# MQTT 库实现



MQTT client 库有多种实现，包括 Android、Arduino、Ruby、C、C++、C#、Go、iOS、Java、JavaScript 语言的各种实现版本。因此在使用过程中，我们并不需要自己按照 MQTT 的协议规范来实现一个 MQTT client，直接使用对应的开源库即可。



## MQTT Client

Paho-mqtt 是较为知名的 MQTT client 库，它提供多种语言的实现。

- [paho.mqtt.c](https://github.com/eclipse/paho.mqtt.c)
- [paho.mqtt.cpp](https://github.com/eclipse/paho.mqtt.cpp)
- [paho.mqtt.embedded-c](https://github.com/eclipse/paho.mqtt.embedded-c)
- [paho.mqtt.golang](https://github.com/eclipse/paho.mqtt.golang)
- [paho.mqtt.java](https://github.com/eclipse/paho.mqtt.java)
- [paho.mqtt.android](https://github.com/eclipse/paho.mqtt.android)
- [paho.mqtt.javascript](https://github.com/eclipse/paho.mqtt.javascript)
- [paho.mqtt.python](https://github.com/eclipse/paho.mqtt.python)
- [paho.mqtt.rust](https://github.com/eclipse/paho.mqtt.rust)
