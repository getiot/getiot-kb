# 网络协议基础教程

![网络协议教程](https://static.getiot.tech/cover-protocol-tutorial.webp#center)

在数字时代，网络协议是信息传输和通信的基础，无论是互联网上的网页浏览，还是物联网设备之间的通信，都离不开各种网络协议的支持。

本教程将带你了解网络协议的世界，涵盖从传输层到应用层的各类协议，助你建立对网络通信的全面认识。

- **传输层协议**：TCP、UDP ...
- **网络层协议**：IP、ICMP ...
- **应用层协议**：HTTP、FTP、DNS ...
- **网络时间协议**：NTP、PTP ...
- **位置服务协议**：GPS ...
- **工业控制协议**：CAN、ProfiBus ...
