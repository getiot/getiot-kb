# YuzukiMavericks 开发板

![](https://static.getiot.tech/YuzukiMavericks-Board.jpg#center)

**YuzukiMavericks** 是一个开源的 U 盘形状的小型 Linux 开发板，遵循 CERN Open Hardware License 开源协议。主控制器是全志的 F1C200s，支持运行 Linux 5.4 内核。

F1C200s 是全志的一款高度集成、低功耗的移动应用处理器，可用于多种多媒体音视频设备中。全志 F1C200s 基于 ARM 9 架构（ARM926ejs 内核，主频默认 408MHz），内置 64MB DDR1 内存。支持高清视频解码，包括 H. 264、H.263、MPEG 1/2/4 等。还带有 100M 的 SPI 接口、2个 SDIO 接口、1个 USB OTG 接口，以及 CSI 摄像头接口、LCD RGB 显示屏接口、I2S 音频接口等多种外设接口。

软件适配：

- Linux Kernel 5.4.180 主线内核
- Uboot 2020.07
- Buildroot 2022.01
- 支持 SPI NOR 和 SPI NAND
- 支持 TF 卡
- 一路音频 + TV 输出
- 一路音频 + TV 输入
- 支持电脑 MTP 作为 U 盘访问
