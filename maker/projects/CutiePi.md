# CutiePi 开源树莓派平板电脑



## 简介

CutiePi 是一款以 Raspberry Pi Compute Module 3+ 位硬件核心的开源平板电脑，它搭载了 8 寸触控屏幕，并集成了 5000mAh 可充电电池，使得用户可以非常方便地将 Raspberry Pi 携带外出使用。同时，CutiePi 还在侧边提供了一组 6 个 GPIO 引脚，可用于连接各种传感器或物联网设备。



## 发展历程

第一代的 CutiePi 原型其实只是一个纸盒，配上现成的 HDMI 屏、Raspberry Pi 3 和一个移动电源。第二代则将 Pi 3 上包括 HDMI 等接头通通解焊，改用 FCC 软排线减少厚度，然后装进 3D 打印的外壳里。

一般的 Maker 项目可能就此满足了，但 CutiePi 团队马不停蹄地打造了第三代原型 —— 自行设计了一块主板 CutiePi board，可搭配树莓派 Compute Module 计算模组使用。
