# ZeroPhone 开源智能手机



![](https://static.getiot.tech/zerophone-product.jpg#center)

ZeroPhone 是基于树莓派 zero 自制一部智能手机，它的基础是运行 Linux 的 Rapsberry Pi Zero，以及 ESP8266 和 Arduino。

ZeroPhone 非常适合开发，因为它运行 Linux 并提供 root 访问权限，使用 SSH，并且可以连接显示器，键盘和鼠标以将其用作桌面。你可以使用 API 来控制 ZeroPhone 的行为，并以此创建你梦寐以求的手机。基于它的开放性，任何人都可以根据自己的需求更改软件。

GitHub：[https://github.com/ZeroPhone](https://github.com/ZeroPhone)

### 硬件组成

组成 ZeroPhone 项目的组件及规格：

- 基于 Raspberry Pi Zero、ESP8266 和 Arduino
- 具有 Wi-Fi、HDMI、全尺寸 USB 和 3.5 毫米输入（可选配蓝牙）
- GSM 2G 连接（即将推出 3G）
- 128 x 64 英寸 OLED 显示屏
- GSM / Wi-Fi / 麦克风硬件切换选项
- RGB LED 和振动马达
- puertos
- 红外线接收器/发射器
- 其他显示和按钮
- 5 MP / 8 MP相机
- 加长电池
- 各种传感器，模拟和数字
- 物联网无线电
- GPS，以太网和 MicroSD 扩展
