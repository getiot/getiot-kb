# Arduino Robot Arm 机械臂

![](https://static.getiot.tech/robot-arm-captcha-1024x576.jpg#center)

DIY 一个基于 Arduino 的开源 Robot Arm（六轴机械臂）—— MARK 1，还可以通过手势控制机械臂动作。



## 准备材料

| 材料                                                         | 数量 | 备注                     |
| ------------------------------------------------------------ | ---- | ------------------------ |
| [Arduino UNO](https://store.arduino.cc/products/arduino-uno-rev3/) | 1 个 |                          |
| 嘉立创定制 PCB                                               | 1 个 |                          |
| MG996R 舵机                                                  | 6 个 |                          |
| 5V 电池包                                                    | 1 个 |                          |
| [PCA9685 8通道驱动器](https://store.ncd.io/product/pca9685-8-channel-8w-12v-fet-driver-proportional-valve-controller-with-i2c-interface/) | 1 个 | 8W，12V，I2C 接口        |
| [HC-05 蓝牙模块](https://www.amazon.com/HiLetgo-Wireless-Bluetooth-Transceiver-Arduino/dp/B071YJG8DR) | 2 个 |                          |
| [A4988 步进电机控制器](https://www.sparkfun.com/products/12859) | 1 个 | SparkFun                 |
| NEMA-17 步进电机                                             | 1 个 |                          |
| 面包板                                                       | 1 个 | 通用（小）               |
| [MPU6050 传感器](https://www.amazon.com/dp/B008BOPN40/?tag=octopart00-20) | 1 个 | 六轴 IMU（加速度、位姿） |
| Arduino Nano R3                                              | 1 个 |                          |
| Flex 传感器                                                  | 1 个 |                          |

其他：3D 打印机
