# HoloCubic 透明小电视



![](https://static.getiot.tech/HoloCubic-01.jpg#center)

**HoloCubic** 是一款带网络功能的伪全息透明显示桌面站，由[稚晖君](https://pengzhihui.xyz/)设计并开源。

硬件方案基于乐鑫的  ESP32PICO-D4 微控制器，由于采用了 SiP 封装使得 PCBA 整板面积能做到一个硬币大小；软件方面主要是基于 LVGL-GUI 库，并移植了 ST7789 1.3 寸 240x240 分辨率屏幕的显示屏驱动，同时将 MPU6050 作为输入设备通过感应的方式模拟编码器键值来交互。

GitHub 仓库：[https://github.com/peng-zhihui/HoloCubic](https://github.com/peng-zhihui/HoloCubic)
