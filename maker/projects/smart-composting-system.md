# 智能堆肥系统

A smart system that can help anyone compost. The system aerates and hydrates your compost, and lets you know when you need to take action.

一个智能系统，可以帮助任何人堆肥。这个系统会给你的堆肥通气和补水，让你知道什么时候需要采取行动。

![](https://static.getiot.tech/smart-compost-schematics-2017.jpg)



## 准备材料

| 零件                 | 数量 | 说明                                                         |
| -------------------- | ---- | ------------------------------------------------------------ |
| Arduino 101          | 2个  | Use in the Compost Satellite System and the Kitchen Compost Bin |
| Intel Edison         | 1个  | Used to analyze the results, provide recommendations, and host the dashboard |
| 温湿度传感器         | 1个  | Used to measure ambient temperature                          |
| DS18B20              | 1个  | Used to measure compost temperature（will be replaced with a combo soil/moisture sensor） |
| MQ4 气体传感器       | 1个  |                                                              |
| 高精度土壤湿度传感器 | 1个  | Used to measure compost moisture [Note - will be replaced with a combo soil/moisture sensor] |
| Servos               |      | Used to open/close air vent                                  |
| 水泵                 |      |                                                              |
| 水位传感器           |      | Used to measure water level                                  |
|                      |      |                                                              |
