# CC 知识共享许可

Creative Commons 知识共享许可协议（创作共用许可证），简称 CC 协议，是**一种允许他人分发作品的公共版权许可**。由美国非盈利性组织（[Creative Commons](https://creativecommons.org)）于2002年12月16日首次发布。该许可证适用于自由文化作品，包括但不限于网站、图像、视频、博客、电子文档、书籍、数据集等。



## CC 许可协议简介

CC 许可协议（知识共享许可协议）是公共领域作品（比如博客）中最常见的许可协议。协议中主要规定了以下四种权利：

| 权利               | 说明                                                         | 图标                                     |
| ------------------ | ------------------------------------------------------------ | ---------------------------------------- |
| 署名（BY）         | 转载此作品时要附上原作者名称等信息。                         | ![](https://static.getiot.tech/cc-by.png) |
| 非商业使用（NC）   | 这个作品不能被用作商业目的。                                 | ![](https://static.getiot.tech/cc-nc.png) |
| 禁止演绎（ND）     | 转载时不能修改原内容。                                       | ![](https://static.getiot.tech/cc-nd.png) |
| 相同方式共享（SA） | 如果转载时修改了原内容那必须以相同的 CC 许可协议发布修改后的内容。 | ![](https://static.getiot.tech/cc-sa.png) |

与传统版权协议（Full CopyRight）不同，CC 协议只保留了四种权利。因此 CC 协议是比较宽松的，它没有限制使用者能做什么，只规定了不能做什么。

四种权利可以相互组合形成最终协议，但由于一些原因（比如 ND 与 SA 协议互斥），目前基本上只有以下六种组合协议：

1. 知识共享-署名（CC-BY）
2. 知识共享-署名-相同方式共享（CC-BY-SA）
3. 知识共享-署名-非商业性（CC-BY-NC）
4. 知识共享-署名-禁止演绎（CC-BY-ND）
5. 知识共享-署名-非商业性-禁止演绎（CC-BY-NC-ND）
6. 知识共享-署名-非商业性-相同方式共享（CC-BY-NC-SA）

这六种组合中，最宽松的是第一种 **CC-BY** 署名许可，限制性最强的是第五种 **CC-BY-NC-ND** 许可证。

以比较常见的一种 CC 许可协议 **CC-BY-SA-4.0** 为例，它的全称是 CreativeCommonsAttribution-ShareAlike 4.0 国际公共许可证，中文为“知识共享版权归属-相同方式共享 4.0 国际公共许可证”。它允许其他人只要声明作品来源（包括原作者等信息）即可以同样的 CC-BY-SA-4.0 协议进行发布。

关于 CC 许可协议的更多内容请查阅：[http://creativecommons.org/license/](http://creativecommons.org/license/)



## 为什么需要许可证

对于网站、图像、视频、博客、电子文档、书籍、数据集等文化作品，使用 CC 许可协议具有以下好处：

- 一定程度保护作者的权益；
- 作为公共领域的作品，给使用者充分的自由，以便于传播。



## 选择哪种 CC 许可协议

知识共享许可协议是不撤销的。这意味着，你不能够阻止已经依照知识共享许可协议获得了你的作品的人依照该许可使用你的作品。

当然，你可以根据自己的意愿，在任何时候，对你的作品的知识共享许可协议进行更改或停止使用；但是你不能对已经授权并流通的复制品要求其撤回或更改许可协议，无论他们是简单的复制品，还是汇编作品中收录了你的作品的复制品，或者基于你的作品创作的演绎作品的复制品。

因此在选择知识共享许可协议的时候，你需要考虑清楚，你是否愿意他人即使在你终止该作品的发行后，依然可以在遵守许可协议的情况下使用你的作品。
