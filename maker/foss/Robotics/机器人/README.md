# 机器人

本目录收录机器人中间件、运行时框架、AI 数据流和语音交互等方向的开源项目。

你可以按目标来选：

- 想进入主流机器人开发生态，先看 [ROS/ROS 2](/foss/ros/)。
- 关注 AI 机器人、多模态 pipeline 和数据流建模，可看 [Dora-rs](/foss/dora-rs/)。
- 关注现代 C++ 运行时、模块化和工程化部署，可看 [AimRT](/foss/aimrt/)。
- 想做中文语音助手或智能音箱实验，可看 [wukong-robot](/foss/wukong-robot/)。

这些项目定位不同：ROS/ROS 2 生态最完整，Dora-rs 更偏 AI 数据流，AimRT 更偏运行时底座，wukong-robot 更偏应用层语音交互。选型时先看团队技术栈和项目目标，不要只比功能清单。
