# 工业与制造

本目录收录工业控制、数字制造、数控加工、机器人制造单元等方向的开源项目。

这类项目和普通应用软件不同，通常会直接连接机床、电机、传感器、驱动器和工业总线。你在评估它们时，不能只看功能列表，还要重点关注实时性、硬件兼容性、安全机制、维护状态和现场调试能力。

## 适合关注的方向

- CNC 数控控制系统
- 机器人运动控制
- 工业现场通信
- 设备监控与数据采集
- 柔性制造与实验平台

## 阅读建议

如果你刚接触工业控制，建议先把项目分成三层来看：

1. **控制对象**：机床、机械臂、3D 打印机、激光切割机、等离子切割机等。
2. **实时控制**：轨迹规划、插补、伺服控制、I/O 响应、急停链路。
3. **上层集成**：HMI、G-code、工业网络、数据采集、远程监控。

工业设备有真实的机械和电气风险。任何开源控制系统都应先在仿真或空载环境中验证，再接入真实设备。

:::warning
涉及机床、电机、主轴、激光、电源和运动机构的实验，必须保留急停、限位、接地和防护措施。不要在不了解设备风险时直接运行控制程序。
:::
