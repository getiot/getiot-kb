# 数据存储单位



在计算机系统中，存储数据的基本单位是 **字节**（Byte），最小单位是 **位**（bit）。一个字节由 8 个位组成，能够容纳一个英文字符（[ASCII 码](/computerbasics/ascii/)）。

下表展示了数据存储单位的关系：（从小到大）

| 单位   | Unit       | 简写 | 容量大小           |
| ------ | :--------- | :--- | :----------------- |
| 位     | Bit        | b    | 1 or 0 (on or off) |
| 字节   | Byte       | B    | 8 bits             |
| 千字节 | KiloByte   | KB   | 1024 bytes         |
| 兆字节 | MegaByte   | MB   | 1024 kilobytes     |
| 吉字节 | GigaByte   | GB   | 1024 megabytes     |
| 太字节 | TeraByte   | TB   | 1024 gigabytes     |
| 拍字节 | PetaByte   | PB   | 1024 terabytes     |
| 艾字节 | ExaByte    | EB   | 1024 petabytes     |
| 泽字节 | ZettaByte  | ZB   | 1024 exabytes      |
| 尧字节 | YottaByte  | YB   | 1024 zettabytes    |
| 珀字节 | BrontoByte | BB   | 1024 yottabytes    |
| 诺字节 | NonaByte   | NB   | 1024 brontobytes   |
| 刀字节 | DoggaByte  | DB   | 1024 nonabytes     |
