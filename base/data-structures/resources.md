# 学习资源

学完本教程各章后，可用下面的书、站点与练习巩固。优先「能讲清楚 + 能默写核心代码 + 知道复杂度」。

## 在线书籍与站点

- [Hello 算法](https://www.hello-algo.com) — 动画与图解友好的开源算法书，适合对照本教程查缺  
- [GeeksforGeeks - Data Structures](https://www.geeksforgeeks.org/data-structures/) — 英文条目全，适合查具体结构  
- [CP-Algorithms](https://cp-algorithms.com/) — 偏竞赛与算法实现，进阶查阅  

经典纸质 / 教材（按需选一本精读即可）：

- 《数据结构（C 语言版）》等国内高校教材 — 与本教程目录接近  
- 《算法导论》— 理论更深，作查阅而非第一本入门书  

## 练习平台

- [LeetCode](https://leetcode.com/) / [LeetCode 中国](https://leetcode.cn/)  
- [牛客网](https://www.nowcoder.com/)  

建议：每学完一种结构，做 3～5 道「该结构标签」的简单题，再进中等题。先自己写，再对照题解。

## 与本站相关

- [C 语言教程](/c/) — 指针、结构体、内存是手写结构的基础  
- [C++ 教程](/cplusplus/) — 类与 STL 容器  

## 推荐复习顺序

1. 复杂度 + 递归 + 五种设计思想  
2. 数组、链表、栈、队列  
3. 哈希表、二分查找  
4. 树的遍历、BST、堆、并查集  
5. 图的 BFS/DFS，再最短路 / MST / 拓扑  
6. 排序与选型对比  

## 过关标准（自测）

| 主题 | 自测问题 |
| --- | --- |
| 线性表 | 顺序表插入为何 $O(n)$？链表头插怎么写？ |
| 栈队列 | 括号匹配；循环队列如何判满？ |
| 树 | 三种遍历顺序；BST 查找路径？ |
| 图 | 邻接表 DFS/BFS；Dijkstra 前提？ |
| 排序 | 快排最坏何时发生？哪些稳定？ |
