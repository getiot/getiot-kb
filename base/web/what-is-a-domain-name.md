# 什么是域名？

域名（Domain Name）是互联网上用于标识网站的唯一地址，类似于现实世界中的邮政地址。它由一串易于记忆的字符组成，旨在替代难以记忆的 IP 地址（如 `192.168.1.1`），使得用户能够更方便地访问网站。

域名是互联网基础设施的重要组成部分，可以说是连接用户与网站的桥梁。因此在选择和管理域名时，了解其结构、分类、安全性和注意事项等等，都是至关重要的。



## 域名的结构

一个域名是由几部分（有可能只是一部分，也许是两部分，三部分...）组成的简单结构，它被点分隔，不同于中文书写顺序，它**需要从右到左阅读**。

例如，在域名 `www.getiot.tech` 中，“getiot” 是二级域名，“.tech” 是顶级域名，“www” 则是子域名。

![域名的结构](https://static.getiot.tech/Domain_Name_Example.png#center)

域名的结构通常由两部分组成：

- **顶级域名（Top-Level Domain，TLD）**：这是域名的最后一部分，如 .com、.org、.net 等。
- **二级域名（Secondary Level Domain，SLD）**：这是顶级域名前的部分，如 google.com 中的 “google”。

除此之外，你还可以在二级域名前面添加子域名。实际上，二级域名和子域名都属于**标签**（Label），刚好位于 TLD 前面的标签被称为二级域名。同时，一个域名可以拥有多个标签，例如 [www.inf.ed.ac.uk](https://www.inf.ed.ac.uk) 是一个正确的域名。

:::tip

标签由 1 到 63 个大小写不敏感的字符组成，这些字符包含字母 `A-z`，数字 `0-9`，甚至 `-` 这个符号（不过 `-` 不能出现在标签开头或者标签的结尾）。

:::



## 域名的分类

域名系统通过层次结构将互联网中的计算机及其资源进行标识和定位，顶级域名（Top-Level Domain，TLD）作为这一层次结构中的最高级别，起着至关重要的作用。顶级域名按照用途和特性，可以分为以下几类：

### 通用顶级域名（gTLD）

通用顶级域名是最常见的顶级域名，适用于广泛的用途。主要包括：

- **.com**：最常见的域名，适用于商业组织，但现在几乎任何类型的网站都使用。
- **.org**：主要用于非营利组织，但没有严格限制。
- **.net**：原本为网络服务提供商保留，现在广泛使用。
- **.info**：用于信息性网站。
- **.biz**：主要用于商业和商业性网站。
- **.name**：用于个人网站和博客。

### 国家代码顶级域名（ccTLD）

国家代码顶级域名由两位字母组成，代表特定的国家或地区。这些域名通常用于标识某个国家的互联网资源。例如：

- **.cn**：中国
- **.uk**：英国
- **.us**：美国
- **.jp**：日本
- **.de**：德国

一些国家代码顶级域名由于其拼写的特殊性和吸引力，被广泛用于全球，如：

- **.co**（哥伦比亚）常被用作公司的域名。
- **.tv**（图瓦卢）被用于与电视相关的网站。

### 新通用顶级域名（new gTLD）

为了提供更多选择和灵活性，ICANN 在 2013 年开始推出新通用顶级域名。这些域名通常更具描述性和针对性，包括：

- **.app**：应用程序和软件
- **.blog**：博客
- **.tech**：技术和科技
- **.shop**：在线购物
- **.guru**：专家和顾问
- **.xyz**：通用域名，适用于各种用途
- **.online**：在线业务和存在

新通用顶级域名的出现，使得用户能够选择更符合其网站内容和品牌形象的域名。

### 基础设施顶级域名（ARPA）

**.arpa** 是互联网基础设施域名，主要用于技术基础设施，例如地址和路由参数区域（Address and Routing Parameter Area）。

### 保留顶级域名

这些域名为特定用途保留，不用于普通域名注册：

- **.example**：用于文档示例
- **.test**：用于测试
- **.localhost**：用于本地网络
- **.invalid**：表示无效的域名



## 域名的注册和管理

域名的注册和管理由全球范围内的多个机构共同负责，其中最主要的是互联网名称与数字地址分配机构（[ICANN](https://www.icann.org)）。域名注册商（如 GoDaddy、Namecheap 等）提供域名注册服务，用户可以通过这些平台查询并购买可用的域名。



## 域名的重要性

域名对于一个网站来说是相当重要的，主要包括以下三方面：

1. **品牌形象**：一个好的域名可以帮助企业建立强大的品牌形象，增强用户记忆和信任度。
2. **可访问性**：简洁易记的域名使得用户更容易找到和访问网站，提升用户体验。
3. **搜索引擎优化（SEO）**：相关性高且关键词优化的域名有助于提高网站在搜索引擎中的排名。

不过，在移动互联网时代，域名的重要性有所下降，因为通过用户可以通过 App 访问服务，而不是在浏览器中输入服务的域名或 URL。
