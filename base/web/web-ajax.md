# AJAX 技术



**AJAX** 是 Asynchronous JavaScript And XML 的首字母缩写。从名字可以看出，AJAX 具有异步、使用 JavaScript 和 XML 技术等特性。



AJAX 是客户端的技术，它让浏览器能够与 Web 服务器进行异步沟通，服务器端的程序写法不会因为导入 AJAX 技术而有太大差异。事实上，AJAX 功能已经成为 JavaScript 解释器原生的一部分。

总的来说，在网页中使用 AJAX 技术有以下好处：

- 异步沟通无须将整个网页内容返回 Web 服务器，能够节省网络带宽；
- 由于只返回部分数据，因此能够减轻 Web 服务器的负担；
- 不会像传统的动态网页那样产生短暂空白或闪动的情况。
