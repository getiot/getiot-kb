# Django 版本



## 版本依赖

Python 2.7 只支持到 Django 1.11 LTS 版本，因此建议用户安装最新的 Python 3，以便使用更新的 Django 版本。

| Django版本 | Python版本                              |
| :--------- | :-------------------------------------- |
| 1.8        | 2.7，3.2（直到2016年底），3.3, 3.4, 3.5 |
| 1.9, 1.10  | 2.7, 3.4, 3.5                           |
| 1.11       | 2.7 , 3.4 , 3.5 , 3.6                   |
| 2.0        | 3.5+                                    |
