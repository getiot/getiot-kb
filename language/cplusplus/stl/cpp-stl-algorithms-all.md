# C++ STL 算法介绍



STL 标准模板库 [`<algorithm>`](https://www.cplusplus.com/reference/algorithm/) 定义了一组基于算法的函数。这些算法函数可以通过迭代器或指针访问的任何对象序列，例如数组或某些 [STL 容器](/cplusplus/cpp-stl-containers/) 的实例。但是请注意，算法通过迭代器直接对值进行操作，不会影响容器的结构（它永远不会影响容器的大小或存储分配）。

下面我们直接看一下这些函数的功能介绍。 :eyes: ​（注：带 :octopus: 表示 function template）
