# C++ 常量

C++ 中的常量用于存储不会改变的数据，使用 **`const`** 关键字定义，有时候也称为“字面量”。C++ 常量是在编译时被创建，即使被定义为函数局部的也如此。



## 常量定义

常量可以是任何的基本数据类型，可分为整型常量、浮点常量、字符常量、字符串常量和布尔常量。

C++ 中，有两种简单的定义常量的方式：

- 使用 `#define` 预处理器
- 使用 `const` 关键字

由于 `#define` 预处理只是简单地替换宏定义，缺乏类型的检测机制，容易出现不易发现的错误。因此，C/C++ 引入了 `const` 关键字，本文也将主要介绍 `const` 的用法。

`const` 常量的定义有两种语法：

```cpp showLineNumbers
const type identifier = value;
type const identifier = value;
```

对于基本数据类型的变量而言，两种语法是等效的。但对于指针类型的变量，两者是有区别的。

在定义常量时，必须要进行初始化，因为常量是只读的（定义完了就不能再修改），因此必须要进行初始化。同时，在 C++ 中，定义常量时常量名一般都全大写。

示例：

```cpp showLineNumbers
const float PI = 3.1415926;
float const E = 2.7182818;
```



## 整型常量

整型常量可以是十进制、八进制或十六进制的常量。可通过前缀来区别，`0x` 或 `0X` 表示十六进制，`0` 表示八进制，不带前缀则默认表示十进制。

另外，整型常量还可以带一个后缀，后缀是 `U` 和 `L` 的组合。

- `U` 表示无符号整数（`unsigned`）
- `L` 表示长整数（`long`）

后缀可以是大写，也可以是小写，`U` 和 `L` 的顺序任意。

下面是几个整型常量:

```cpp showLineNumbers
212         // 合法的
215u        // 合法的
0xFeeL      // 合法的
078         // 非法的：8 不是八进制的数字
032UU       // 非法的：不能重复后缀
```

下面是各种类型的整数常量：

```cpp showLineNumbers
85         // 十进制
0213       // 八进制 
0x4b       // 十六进制 
30         // 整数 
30u        // 无符号整数 
30l        // 长整数 
30ul       // 无符号长整数
```



## 浮点常量

浮点常量由整数部分、小数点、小数部分和指数部分组成。

可以使用小数形式或者指数形式来表示浮点常量：

- 当使用小数形式表示时，必须包含整数部分、小数部分，或同时包含两者。
- 当使用指数形式表示时，必须包含小数点、指数，或同时包含两者。 带符号的指数是用 `e` 或 `E` 引入的。

下面是几个合法浮点常量的：

```cpp showLineNumbers
3.14159       // 合法的 
314159E-5L    // 合法的
```

下面是几个非法的浮点常量：

```cpp showLineNumbers
510E          // 非法的：不完整的指数
210f          // 非法的：没有小数或指数
.e55          // 非法的：缺少整数或分数
```



## 布尔常量

布尔常量只有两个，它们都是 C++ 的关键字：

- **`true`** 值代表真
- **`false`** 值代表假



## 字符常量

字符常量由单引号 `''` 包裹。如果常量以 `L`（仅当大写时）开头，则表示它是一个宽字符常量（例如 `L'x'`），此时它必须存储在 `wchar_t` 类型的变量中。否则，它就是一个窄字符常量（例如 `'x'`），此时它可以存储在 `char` 类型的简单变量中。

字符常量可以是一个普通的字符（例如 `x`）、一个转义序列（例如 `\t`），或一个通用的字符（例如 `\u02C0`）。

在 C/C++ 中，有一些特定的字符，当它们前面有反斜杠时，它们就具有特殊的含义，被用来表示如换行符（`\n`）或制表符（`\t`）等。

下表列出了一些转义字符：

| 转义序列     | 含义                       |
| ------------ | -------------------------- |
| `\\`         | `\` 字符                   |
| `\'`         | `'` 字符                   |
| `\"`         | `"` 字符                   |
| `\?`         | `?` 字符                   |
| `\a`         | 警报铃声                   |
| `\b`         | 退格键                     |
| `\f`         | 换页符                     |
| `\n`         | 换行符                     |
| `\r`         | 回车                       |
| `\t`         | 水平制表符                 |
| `\v`         | 垂直制表符                 |
| `\ooo`       | 一到三位的八进制数         |
| `\xhh . . .` | 一个或多个数字的十六进制数 |



## 字符串常量

字符串常量由双引号 `""` 包裹。一个字符串包含类似于字符常量的字符：普通的字符、转义序列和通用的字符。

可以使用空格做分隔符，把一个很长的字符串常量进行分行。

示例：显示一些字符串常量。

```cpp showLineNumbers
#include <iostream>
#include <string>
using namespace std;

int main()
{
    string greeting = "hello, getiot";
    cout << greeting;
    cout << "\n";     // 换行符
    string greeting2 = "hello, \
                        getiot";
    cout << greeting2;
    return 0;
}
```

注意：字符串常量所在的地方是内存中的代码段，只能被读不能被写。
