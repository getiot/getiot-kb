# C 语言 `__attribute__` 机制



`__attribute__` 实际上是 GCC 的一种编译器命令，用来指示编译器执行实现某些高级操作。`__attribute__` 可以设置函数属性（Function Attribute）、变量属性（Variable Attribute）和类型属性（Type Attribute）。



```c showLineNumbers
__attribute__ ((attribute-list))
```
