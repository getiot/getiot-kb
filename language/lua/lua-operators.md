# Lua 运算符

运算符是告诉解释器执行特定数学或逻辑运算的符号。Lua 内置了丰富的运算符，主要包括以下几类：

- 算术运算符（Arithmetic Operators）
- 关系运算符（Relational Operators）
- 逻辑运算符（Logical Operators）
- 其他运算符（Misc Operators）

本节将逐一介绍算术、关系、逻辑及其他运算符。

## 算术运算符

下表列出了 Lua 支持的所有算术运算符。假设变量 **A** 的值为 10，变量 **B** 的值为 20：

| 运算符 | 说明 | 示例 |
| :------: | :---------------------------------------------------------: | :------------------ |
| `+` | 加法 | `A + B` 结果为 30 |
| `-` | 减法 | `A - B` 结果为 -10 |
| `*` | 乘法 | `A * B` 结果为 200 |
| `/` | 除法 | `B / A` 结果为 2 |
| `%` | 取模（整数除法的余数） | `B % A` 结果为 0 |
| `^` | 幂运算 | `A^2` 结果为 100 |
| `-`（一元） | 取负 | `-A` 结果为 -10 |



## 关系运算符

下表列出了 Lua 支持的所有关系运算符。假设变量 **A** 的值为 10，变量 **B** 的值为 20：

| 运算符 | 说明 | 示例 |
| :------: | :----------------------------------------------------------: | :-------------------- |
| `==` | 判断两个值是否相等，相等则条件为真 | `(A == B)` 为 false |
| `~=` | 判断两个值是否不相等，不相等则条件为真 | `(A ~= B)` 为 true |
| `>` | 判断左值是否大于右值 | `(A > B)` 为 false |
| `<` | 判断左值是否小于右值 | `(A < B)` 为 true |
| `>=` | 判断左值是否大于或等于右值 | `(A >= B)` 为 false |
| `<=` | 判断左值是否小于或等于右值 | `(A <= B)` 为 true |

## 逻辑运算符

下表列出了 Lua 支持的所有逻辑运算符。假设变量 **A** 的值为 `true`，变量 **B** 的值为 `false`：

| 运算符 | 说明 | 示例 |
| :------: | :----------------------------------------------------------: | :------------------ |
| `and` | 逻辑与，两个操作数均为真时条件为真 | `(A and B)` 为 false |
| `or` | 逻辑或，任一操作数为真时条件为真 | `(A or B)` 为 true |
| `not` | 逻辑非，取反操作数的逻辑值 | `not (A and B)` 为 true |

## 其他运算符

Lua 还支持**连接（concatenation）**和**长度（length）**运算符：

| 运算符 | 说明 | 示例 |
| :------: | :----------------------------------------------------------: | :----------------------------------------------------------: |
| `..` | 连接两个字符串 | 若 `a` 为 `"Hello "`，`b` 为 `"World"`，则 `a..b` 结果为 `"Hello World"` |
| `#` | 一元运算符，返回字符串或表的长度 | `#"Hello"` 结果为 5 |

## 运算符优先级

运算符优先级决定表达式中各项的分组方式，进而影响求值顺序。某些运算符的优先级高于其他运算符；例如，乘法运算符的优先级高于加法运算符。

例如 `x = 7 + 3 * 2`，x 的值为 13 而非 20，因为 `*` 的优先级高于 `+`，先计算 `3 * 2`，再加 7。

下表中，优先级从高到低排列；在同一表达式中，优先级高的运算符先求值。

| 类别 | 运算符 | 结合性 |
| :------------: | :-------------: | :-----------: |
| 一元 | `not`, `#`, `-` | 从右到左 |
| 连接 | `..` | 从右到左 |
| 乘性 | `*`, `/`, `%` | 从左到右 |
| 加性 | `+`, `-` | 从左到右 |
| 关系 | `<`, `>`, `<=`, `>=`, `==`, `~=` | 从左到右 |
| 逻辑与 | `and` | 从左到右 |
| 逻辑或 | `or` | 从左到右 |
