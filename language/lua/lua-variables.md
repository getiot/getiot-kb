# Lua 变量

变量本质上是为存储区域起的名字，程序可以通过它读写数据。变量可以保存不同类型的值，包括函数和表（table）。

变量名由字母、数字和下划线组成，且必须以字母或下划线开头。Lua 区分大小写，因此大小写字母被视为不同的标识符。Lua 本身没有「变量类型」的概念，但可以根据作用域将变量分为以下三类：

- **全局变量（Global variables）**：除非用 `local` 显式声明，否则所有变量都是全局变量。
- **局部变量（Local variables）**：用 `local` 声明的变量，其作用域仅限于声明时所在的程序块（如函数体、`do...end` 块等）。
- **表字段（Table fields）**：存储在 table 中的特殊变量，键可以是除 nil 以外的任意类型，值可以是任意 Lua 类型（包括 nil）。

## 变量定义

变量定义告诉解释器创建哪些变量。定义时可以选用 `local` 关键字，并可一次声明多个变量，格式如下：

```lua
local variable_list
```

其中 **variable_list** 由一个或多个标识符组成，彼此用逗号分隔。以下是一些合法的声明示例：

```lua
-- 定义局部变量
local i, j
local i
local a, c
```

`local i, j` 这一行同时完成了 i 和 j 的声明与定义，解释器会创建这两个变量，并将它们的作用域限制为局部。

变量可以在声明时初始化（赋初值），初始化部分由等号和一个表达式组成：

```lua
local variable_list = value_list
```

示例：

```lua
local d, f = 5, 10    -- 将 d 和 f 声明为局部变量
d, f = 5, 10          -- 将 d 和 f 声明为全局变量
d, f = 10             -- 将 d 和 f 声明为全局变量，f 的值为 nil
```

未显式赋初值的变量，其默认值为 `nil`。



## 变量赋值

如上面的示例所示，多变量赋值遵循「变量列表 = 值列表」的格式。在 `local d, f = 5, 10` 中，`d` 和 `f` 构成变量列表，`5` 和 `10` 构成值列表。

Lua 按位置对应赋值：变量列表中的第一个变量对应值列表中的第一个值，依此类推。因此 `d` 的值为 5，`f` 的值为 10。

## 声明与变量使用示例

下面的示例中，变量在代码开头声明，随后在程序块中赋值和初始化：

```lua showLineNumbers title="main.lua"
-- 变量声明
local a, b

-- 初始化
a = 10
b = 30

print("value of a:", a)

print("value of b:", b)

-- 交换变量
b, a = a, b

print("value of a:", a)

print("value of b:", b)

f = 70.0/3.0
print("value of f", f)
```

运行上述代码，输出如下：

```bash
value of a:	10
value of b:	30
value of a:	30
value of b:	10
value of f	23.333333333333
```

## 左值与右值

Lua 中有两类表达式：

- **左值（lvalue）**：指向内存位置的表达式。左值可以出现在赋值语句的左侧或右侧。
- **右值（rvalue）**：存储在某个内存地址的数据值。右值不能作为赋值目标，只能出现在赋值语句的右侧。

变量是左值，可以出现在赋值语句的左侧。数字字面量是右值，不能被赋值，也不能出现在左侧。以下语句是合法的：

```lua
g = 20
```

而以下语句不合法，运行时会报错：

```lua
10 = 20
```

在 Lua 中，一条赋值语句可以同时包含多个左值和多个右值，例如：

```lua
g, l = 20, 30
```

上例中，20 赋给 `g`，30 赋给 `l`。

## 声明并初始化变量示例

下面的示例在声明变量的同时完成初始化：

```lua showLineNumbers title="main.lua"
-- 声明并初始化
a, b = 10, 30

-- 打印变量值
print("value of a:", a)
print("value of b:", b)
```

运行上述代码，输出如下：

```
value of a:	10
value of b:	30
```
