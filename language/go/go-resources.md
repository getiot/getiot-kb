# Go 语言学习资源

这里收集和分享一些优质的 Go 语言相关资源，包括一些开源技术书籍和教程、适合新手的练习项目等。

## 推荐教程

- [Learn Web Programming in Go by Examples](https://gowebexamples.com)
- [《The Way to Go》中文译本，中文正式名《Go 入门指南》](https://github.com/unknwon/the-way-to-go_ZH_CN/blob/master/eBook/directory.md)
- [Go 语言圣经中文版](https://golang-china.github.io/gopl-zh/)
- [从零开始学 Go Web 编程](https://github.com/astaxie/build-web-application-with-golang)
- [7天用 Go 从零实现 Web 框架 Gee 教程](https://geektutu.com/post/gee.html)
- [Go 语言高性能编程](https://geektutu.com/post/high-performance-go.html)
- [Go 开发者路线图](https://github.com/darius-khll/golang-developer-roadmap)
- [Go 语言高级编程](https://github.com/chai2010/advanced-go-programming-book)
- [Go 语言标准库](https://github.com/polaris1119/The-Golang-Standard-Library-by-Example)
- [Go 每日一库](https://github.com/darjun/go-daily-lib)

## 开源项目

- [TinyRPC](https://github.com/zehuamama/tinyrpc)：一个基于 Go 语言标准库 net/rpc 扩展的远程过程调用框架。
- [TinyBalancer](https://github.com/zehuamama/balancer)：一个基于 Go 语言标准库 net/http/httputil 扩展的反向代理负载均衡器。
- [cache2go](https://github.com/muesli/cache2go)：一个比较简单的缓存库，代码量很少，可以学习到锁、goroutines 等知识。
- [groupcache](https://github.com/golang/groupcache)：memcached 的 go 语言实现。
- [Lux](https://github.com/iawia002/lux)：Go 编写的视频下载工具，支持哔哩哔哩、YouTube 等视频网站。
