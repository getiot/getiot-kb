# Ruby 教程

![Ruby 语言教程](https://static.getiot.tech/cover-ruby-tutorial.webp#center)

Ruby 是一门强调表达力、对象模型和开发体验的动态编程语言。你可以用它编写脚本、命令行工具、Web 应用、自动化任务，也可以用它快速搭建原型。

这份教程面向初学者。你不需要先懂 Ruby，但最好已经接触过至少一门编程语言。学习过程中，你会看到 Ruby 的几个关键味道：一切皆对象、Block、Enumerable、Module、Mixin，以及 RubyGems 生态。

## 你会学到什么

学完这份教程后，你应该能够：

- 安装 Ruby，并使用 IRB 和 `.rb` 脚本运行程序。
- 理解变量、方法、条件、循环、输入输出等基础语法。
- 使用 String、Symbol、Array、Hash、Range、Time、Regexp 等核心对象。
- 掌握 Block、Proc、Lambda 和 Enumerable 的常见用法。
- 使用类、对象、Module、Mixin 和异常处理组织 Ruby 代码。
- 读写文件，处理 JSON、CSV、YAML，发送 HTTP 请求。
- 使用 RubyGems、Bundler、Rake、Minitest、RSpec 和 RuboCop。
- 理解 Rack、Sinatra、Ruby on Rails、Thread、Fiber、Ractor 等进阶主题。

## 学习建议

Ruby 很容易写出能运行的代码，但写出清楚、自然、可维护的 Ruby 仍然需要练习。你可以不断问自己：

1. 这个对象应该负责什么？
2. 这里是在处理集合吗？能不能用 Enumerable 表达？
3. 这段重复逻辑应该用方法、类、Module，还是 block？

如果你从 Python、JavaScript、C/C++ 或 Java 转来，不要急着套旧语言习惯。多读 Ruby 代码，理解它为什么喜欢 block、链式调用和约定命名。

## 版本约定

本教程以 Ruby stable 版本和 CRuby 作为主要讲解对象。截至 2026 年 7 月，Ruby 官方下载页显示当前稳定版本为 Ruby 4.0.6。实际学习时，请以 Ruby 官方网站和你项目的 `.ruby-version`、`Gemfile` 为准。
