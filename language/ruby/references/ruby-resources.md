# Ruby 学习资源

学习 Ruby 时，优先阅读官方和长期维护的资料。遇到版本、API、安装方式问题时，以官方文档为准。

## 官方资源

- Ruby 官网：https://www.ruby-lang.org
- Ruby 官方文档：https://docs.ruby-lang.org
- RubyGems：https://rubygems.org
- Bundler：https://bundler.io
- Ruby on Rails：https://rubyonrails.org
- Rack：https://github.com/rack/rack
- Sinatra：https://sinatrarb.com

## 推荐学习顺序

1. 用 IRB 试语法。
2. 写小脚本处理文件。
3. 熟悉 String、Array、Hash、Symbol。
4. 学习 block 和 Enumerable。
5. 使用类和模块组织代码。
6. 使用 Bundler 管理依赖。
7. 写 Minitest 或 RSpec 测试。
8. 学习 Sinatra 或 Rails。
9. 再进入 Thread、Fiber、Ractor、元编程。

## 如何读官方文档

Ruby 文档按类和模块组织。比如你想查字符串方法，就看 `String`；想查数组方法，就看 `Array`；想查集合处理，就看 `Enumerable`。

阅读文档时关注：

- 方法接收什么参数。
- 方法返回什么。
- 是否修改原对象。
- 失败时会返回 `nil`、`false`，还是抛异常。

## 小结

Ruby 学习的关键是多写小程序，多读错误信息，多查官方文档。你不需要一次学完所有框架，先把 Ruby 本身写顺。
