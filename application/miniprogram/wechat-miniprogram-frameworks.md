# 微信小程序开发框架



本文主要介绍几个常用的微信小程序开发框架，包括原生开发框架、uni-app、Taro、WePY 等。需要注意的是，虽然微信小程序开发框架有多种选择，但每种框架都有其自身的优缺点和适用场景，需要开发者根据自身开发经验和项目需求进行选择。



## 小程序原生开发框架

微信提供的小程序原生开发框架，使用 JavaScript 语言和 WXML 模板语言进行开发。该框架具有较好的性能和稳定性，并且可以直接访问微信的 API 和组件库。

- [微信小程序官方文档](https://developers.weixin.qq.com/miniprogram/dev/framework/)



## uni-app 框架

uni-app 是一个跨平台开发框架，可以用于开发微信小程序、H5、App 等多个平台。uni-app 使用 Vue.js 语法进行开发，可以快速构建小程序页面和组件，同时具有良好的跨平台兼容性。

- [uni-app 官方文档](https://zh.uniapp.dcloud.io)



## Taro 框架

Taro 是一个类 React 语法的小程序开发框架，可以在 React 语法的基础上，使用 JSX 语法进行开发。Taro 框架具有灵活的开发方式和多端兼容性，可以快速构建小程序和其他平台的应用。

- [Taro 官方文档](https://docs.taro.zone/docs)



## WePY 框架

WePY 是一个类 Vue 语法的小程序开发框架，使用 Vue.js 语法和组件化开发方式进行开发。WePY 框架具有良好的性能和易用性，并且可以快速开发出具有高度复用性的小程序组件。

WePY 框架在开发过程中参考了 Vue 等现有框架的一些语法风格和功能特性，对原生小程序的开发模式进行了再次封装，更贴近于 MVVM 架构模式，并支持 ES6/7 的一些新特性。

- [WePY 官方文档](https://wepyjs.github.io/wepy-docs/)
