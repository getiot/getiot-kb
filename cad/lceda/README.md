# 立创 EDA 教程 📚

![立创 EDA 教程](https://static.getiot.tech/cover-lceda-tutorial.webp#center)

立创 EDA 是一个基于云端平台的工具，无需下载安装，联网即可使用。在浏览器输入网址 [https://lceda.cn](https://lceda.cn) 进入立创 EDA 主页。立创 EDA 提供库文件共享功能，目前已有上百万的元器件原理图库和封装库，帮助开发者提高设计效率。通过立创 EDA 提供的团队管理功能，可以在工程设计中实现分工协作和版本管理，不仅有助于工程的完善，也能促进团队成员间的交流。此外，立创 EDA 还提供了一个硬件开源平台 OSHWHub，开发者可以分享自己的工程，也可以参考其他开发者的工程，实现“在分享中学习，在学习中实现价值”。

常用的 EDA 软件有 Altium Designer、Pads 和 Cadence Allegro 等，个人开发者建议使用 **KiCAD** 或 **立创 EDA** 。
