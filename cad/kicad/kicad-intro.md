# KiCad 简介

![KiCad Logo](https://static.getiot.tech/kicad_logo_small.png#center)

KiCad 是一个开源软件工具，用于创建电子原理图和印刷电路板（PCB）图形。KiCad 可在所有主要的操作系统和广泛的计算机硬件上运行，包括 Windows、macOS 和多种 Linux 发行版。并且采用 GPL 许可，是面向有意创建开源电子硬件的项目的工程师的理想工具。



## 软件组成

KiCad 是一个工具套装，在其独特的表面下，优雅地融合了以下独立软件工具：

| 程序名称         | 描述                                                       | 文件扩展                        |
| :--------------- | :--------------------------------------------------------- | :------------------------------ |
| KiCad            | 项目管理器                                                 | *.pro                           |
| Eeschema         | 原理图和元件库编辑器                                       | *.sch, *.lib, *.net             |
| Pcbnew           | PCB 和封装编辑器                                           | *.kicad_pcb, *.kicad_mod        |
| GerbView         | 光绘文件及钻孔文件查看                                     | \*.g\*, *.drl, etc.             |
| Bitmap2Component | 将位图转换为元件符号或封装                                 | *.lib, *.kicad_mod, *.kicad_wks |
| PCB Calculator   | 便携式计算器，可以用于方便的计算线宽/电气间隙/色环代码等等 | 无                              |
| Pl Editor        | 图框编辑器                                                 | *.kicad_wks                     |

**提示**：上述文件扩展名列表不完整，仅包含 KiCad 支持的文件的子集。但是它能帮助你了解 KiCad 使用的基本的文件。

![KiCad Ubuntu Screenshot](https://static.getiot.tech/KiCad-ubuntu-screenshot.png#center)

有充分的理由认为，KiCad 已足够成熟，并可以用于开发和维护复杂的电路板。

KiCad 对电路板的大小不做任何限制, 它可以轻松地处理多达 32 个铜层、多达 14 个技术层和多达 4 个辅助层的电路板。 KiCad 可以创建制造印刷电路板所需的所有文件、用于照片绘图仪的 Gerber 文件、钻孔文件、元件位置文件等等。



## 主要特点

KiCad 的主要特点包括：

1. **开源且免费**：KiCad 是完全免费的，用户可以自由下载、使用和修改。
2. **跨平台**：KiCad 支持多种操作系统，包括 Windows、Linux 和 macOS。
3. **模块化设计**：KiCad 的设计模块化，允许用户根据需要选择和启用特定功能。
4. **强大的元件库**：KiCad 拥有一个丰富的元件库，包括各种电子元件和连接器。
5. **3D 视图**：KiCad 提供了 3D 视图功能，可以帮助用户更好地理解 PCB 的三维结构。
6. **Gerber 文件生成**：KiCad 能够生成高质量的 Gerber 文件，用于 PCB 制造。
7. **社区支持**：KiCad 有一个活跃的开源社区，提供技术支持和帮助。



## 主要功能

KiCad 为电子工程师提供了一系列功能，以支持从概念设计到最终产品的整个电子设计流程。主要包括以下功能：

1. **原理图设计**：允许用户绘制电路原理图，包括元件放置、连接线、网络标签、文本注释等。
2. **PCB 布局和布线**：从原理图生成PCB布局，并进行布线设计，包括调整元件位置、布局优化、布线规则设置等。
3. **元件库管理**：KiCad 允许用户创建和管理自己的元件库，包括创建新的元件和封装。
4. **3D 视图**：提供 3D 视图功能，帮助用户在设计过程中检查 PCB 的三维效果。
5. **Gerber 文件生成**：KiCad 能够生成用于 PCB 制造的 Gerber 文件，包括钻孔文件、光绘文件等。
6. **报告和分析**：提供电路分析和设计报告，帮助用户检查电路设计中的问题。
7. **集成库和工具**：KiCad 支持与其他工具的集成，如电路仿真工具、PCB 制造商工具等。
8. **项目协作**：支持多人协作，方便团队共同完成电子设计项目。
9. **多语言支持**：KiCad 支持多种语言，方便全球用户使用。

这些功能帮助 KiCad 用户更有效地完成电子设计项目，提高设计效率和质量。
