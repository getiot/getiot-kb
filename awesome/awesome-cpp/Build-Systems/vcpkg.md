# Vcpkg - C++ 包管理工具

**vcpkg** 是一个开源的 C++ 库管理工具，由 Microsoft 开发和维护，旨在简化在 Windows 上使用第三方 C++ 库的流程。它的目标是成为 Windows 上的 C++ 库生态系统的标准包管理器，类似于 macOS 上的 Homebrew 或 Linux 上的 apt、yum 等。

它提供了一个集中化的存储库，包含了大量常用的 C++ 库，用户可以通过 vcpkg 快速安装和管理这些库。

虽然 vcpkg 主要面向 Windows 平台，但 vcpkg 也可以在 Linux 和 macOS 等操作系统上使用。
