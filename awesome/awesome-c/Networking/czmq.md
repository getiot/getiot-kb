# czmq 使用教程（ZeroMQ）

**czmq** 是 ZeroMQ 的高级封装，它提供了一组更加简单和易用的 API，用于构建基于 ZeroMQ 的应用程序。czmq 不仅封装了底层的 ZeroMQ 函数，还提供了一些额外的功能和工具，使得开发者可以更加方便地构建复杂的分布式系统。



## 主要特点

- **简单易用**：czmq 提供了一组简化的 API，使得开发者可以更加轻松地使用 ZeroMQ 构建应用程序。
- **线程安全**：czmq 是线程安全的，可以在多线程环境下安全地使用。
- **功能丰富**：czmq 不仅封装了 ZeroMQ 的底层功能，还提供了一些额外的功能和工具，使得开发过程更加高效和便捷。
- **支持高级特性**：czmq 支持一些高级特性，如自动重连、心跳检测等，使得开发者可以更加轻松地构建健壮和可靠的分布式系统。
- **活跃的社区支持**：czmq 有一个活跃的社区，提供了丰富的文档和示例，对于使用者来说是一个宝贵的资源。
