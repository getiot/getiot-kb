# mongoose 使用教程



![](https://static.getiot.tech/mongoose-web-server_usecases.png)

**Mongoose** 是一个轻量级、高效和易于集成的嵌入式 Web 服务器库，适用于各种嵌入式设备和物联网设备，具有多种网络协议支持和安全特性。使用 Mongoose，开发者可以在嵌入式设备上方便地创建 Web 服务。



## 主要特点

- **轻量级和高效**：Mongoose 被设计成轻量级的 Web 服务器库，具有高效的性能，适用于资源受限的环境。
- **嵌入式设备支持**：Mongoose 适用于各种嵌入式设备和物联网设备，可以方便地在这些设备上创建 Web 服务。
- **易于集成**：Mongoose 提供了简单而灵活的 API，使得开发者可以轻松地集成和使用它来创建 Web 服务。
- **支持多种协议**：Mongoose 支持 HTTP、HTTPS、WebSocket 等多种网络协议，使得开发者可以创建各种类型的 Web 服务。
- **安全性**：Mongoose 提供了一些安全特性，如 SSL/TLS 支持等，可以确保通信的安全性。
