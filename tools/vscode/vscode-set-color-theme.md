# VS Code 修改背景颜色



在VS Code的配置文件settings.json中添加如下参数

```json
 "workbench.colorTheme": "Atom One Light",
 "workbench.colorCustomizations": {
 "[Atom One Light]": {
  "editor.background": "#C7EDCC",
 "sideBar.background": "#e7f0e7",
 "activityBar.background": "#C7EDCC",
      },
 },
```
