# 云计算基础知识



## 云计算概述

简单来说，云计算就是通过 Internet（云）提供计算服务资源，包括服务器、存储、数据库、网络、软件、分析和人工智能等等，从而提供快速创新、弹性资源和规模经济。

你可以想象一下，过去我们通过计算机的硬盘驱动器来存储和访问数据，使用云计算之后，我们就可以通过互联网远程存储和访问数据，并与其他 Web 信息同步。这不仅减轻了用户的运维工作，还实现了资源的共享、弹性扩展和按需付费，大大降低了运营成本。

云计算的一个突出例子是在线协作文档，比如 Office 365，它允许多用户在线（在浏览器中）存储、访问，编辑他们的 Office 文档，而无需在其设备上安装实际程序。

![](https://static.getiot.tech/Cloud_computing_1200px.png#center)

## 云的存储类型

云上的存储类型有 3 种形式：公有云（public）、私有云（private）、混合云（hybrid）。

![](https://static.getiot.tech/Cloud_computing_public_private_hybrid.png#center)

**公共云** —— 通常指第三方提供商为用户提供的能够使用的云。公有云对公众开放，一般可通过互联网使用，成本比较低廉，其核心属性是共享资源服务。基础设施由 Google、Microsoft、阿里云等服务提供商拥有和运营。

**私有云** —— 这些云是服务于一个特定的组织。该特定组织可以使用云存储公司的数据，托管业务应用程序等，其核心属性是专有资源。存储在私有云上的数据不能与其他组织共享，由组织本身或第三方管理，因而提供对数据、安全性和服务质量最有效的控制。

**混合云** —— 当两个或多个云绑定在一起以提供公有云和私有云的优势时，它们被称为混合云。组织可以使用私有云进行敏感应用，而公共云可以用于非敏感应用。混合云为组织提供灵活，可扩展和具有成本效益的解决方案。



## 云的服务模式

云计算有 3 种服务模式，从架构的角度来讲，从下往上分别是 IaaS、PaaS、SaaS，从上往下每层都是向下包含的关系。

![](https://static.getiot.tech/cloud-service-models-iaas-paas-saas.jpg#center-600)

**IaaS（Infrastructure as a Service，基础架构即服务）**，处在整个架构的最底端，通过虚拟化技术将服务器等计算平台和存储和网络资源一起打包，通过 API 接口的方式提供给用户，这样用户就不用再租用机房，也不用自己维护服务器和交换机，只需要购买 IaaS 服务就可以获得这些资源。

**PaaS（Platform as a Service，平台即服务）**，构建在 IaaS 之上，除了基础架构之外，还提供软件应用的开发组件和运行环境通常还具备相应的存储接口，通常 IaaS 和 PaaS 的直接使用者是需要有一些相应的技术背景的，比如大家所熟知的 AWS、Azure、阿里云、腾讯云等都是典型的 IaaS 和 PaaS 服务商。

**SaaS（Software-as-a-Service，软件即服务）**，处在架构的最顶端，是直接面向用户的应用层，SaaS 是最成熟也是知名度最高的云计算服务类型，也是最流行的概念。所以这也是为什么大家一提到云计算就会想到 SaaS 的原因，SaaS 的模式就是将应用的后台放在互联网云端，这样用户只需要有一台能上网的电脑或者是一部手机就可以直接通过 Web 浏览器或者 App 来使用，不用在本地维护任何服务器等基础架构，也不需要技术人员的支持。手机的自动同步到云端功能，在线文档、网络云盘等都属于 SaaS 服务。



## 云的优势

云有很多好处，下面我们列举一些：

- 云服务提供可扩展性，资源的分配可以根据需求动态调整；
- 通过减少资本基础设施节省成本；
- 它允许用户独立于其位置和硬件配置来访问应用程序；
- 它简化了网络，并允许客户端访问应用程序，而无需为单个机器购买许可证；
- 在云上存储数据更加可靠，因为它不容易丢失。
