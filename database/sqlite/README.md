# SQLite 教程

![SQLite 教程](https://static.getiot.tech/cover-sqlite-tutorial.webp#center)

SQLite 是一个轻量级的嵌入式数据库，无需独立服务器，易于集成到各类应用中。SQLite 可以运行在各种操作系统上，包括 Windows、Linux、macOS、Android 等，甚至在 RTOS 上也能很好地运行。

### 本教程内容概要

1. **SQLite 基础**：介绍 SQLite 的基本概念、安装和基本操作。
2. **SQL 查询语言**：深入学习 SQLite 支持的 SQL 查询语言，包括基本查询、聚合查询等。
3. **时序数据处理**：学习 SQLite 的时序数据处理能力，包括时序数据扩展和时间函数。
4. **性能优化**：探讨 SQLite 的性能优化方法，包括索引、表设计等方面。
5. **事务处理**：理解 SQLite 的事务处理机制，确保数据的一致性和完整性。
6. **应用实践**：基于实际应用场景，演示 SQLite 在各个领域的实际应用。
