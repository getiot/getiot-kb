# TDengine 教程

![TDengine 教程](https://static.getiot.tech/cover-tdengine-tutorial.webp#center)

TDengine 是一款专注于时序数据存储和分析的数据库系统，其独特的架构和优化策略使得它在高速写入、实时查询、时序数据分析等方面表现出色。物联网应用通常涉及大量时序数据，学习 TDengine 有助于构建高效的物联网数据存储系统。

### 本教程内容概要

1. **TDengine 基础**：介绍 TDengine 的基本概念、安装和配置。
2. **数据模型和时序函数**：深入了解 TDengine 的数据模型和内置的时序函数。
3. **高性能写入**：学习如何实现高速写入，满足大规模时序数据的实时采集需求。
4. **分布式架构**：探讨 TDengine 的分布式架构，如何横向扩展和部署。
5. **SQL 查询和数据聚合**：使用 SQL 语言进行时序数据查询，并学习数据聚合的方法。
6. **TDengine 与物联网**：如何在物联网应用中应用 TDengine，构建高效的数据存储和分析系统。
7. **性能优化和调试**：深入了解 TDengine 的性能优化方法和调试技巧。
8. **实际应用案例**：基于实际案例深入探讨 TDengine 在不同领域的应用。
