# OpenCV 简介



**OpenCV** 是一个开源的跨平台计算机视觉库，其全称为 Open Source Computer Vision Library。可用于开发实时的图像处理、计算机视觉以及模式识别程序。

OpenCV 由英特尔公司发起并参与开发，2000年6月首次发布，以 BSD 许可证授权发行，这意味着你可以在商业和研究领域中免费使用它。时至今日，OpenCV 在计算机视觉的开发中扮演着非常重要的角色，为计算机视觉应用开发提供了灵活、功能强大的开发接口，因此成为计算机视觉专业人员所依赖的重要开发工具。



## 应用场景

OpenCV 常见的应用场景包括：

- 计算机视觉：人脸识别、物体检测、图像分类等
- 图像处理：图像降噪、图像增强、图像分割等
- 视频分析：视频监控、运动分析、行为识别等
- 深度学习：图像识别、目标检测、语音识别等
- 其他应用：机器人导航、医学图像分析、交通管理等
