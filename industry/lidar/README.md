# 激光雷达（LiDAR）教程

![](https://static.getiot.tech/cover-lidar-tutorial.webp#center)

激光雷达（LiDAR）利用激光束测量距离，可实现高精度的三维空间测绘，适用于多种领域，例如气象学、地图绘制、机器人学、自动驾驶等领域。尤其是近年来全球汽车行业的变革，仅靠摄像头和传统雷达无法完全保证驾驶的安全性，因此激光雷达在汽车上的安装和使用越来越频繁，有望提升交通运输的安全和效率水平。

本教程将介绍 LiDAR 技术的基本原理、组成和工作模式，同时会介绍常见的激光传感器的种类和特性，并结合实际应用场景，探索 LiDAR 在地形测绘和自动驾驶等领域的应用，包括环境感知和障碍物检测等技术。
