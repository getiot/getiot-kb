# 电动汽车充电接口



电动汽车的充电速度取决于三个环节 —— 充电站（电源类型）、充电电缆和车载充电器。但每一项新技术的开始都是艰难的，发展过程也充满了相互竞争的标准，电动汽车也不例外。就充电电缆的连接器（充电接口）而言，不同国家和地区也存在不同的类型。本文根据 AC/DC 类型和区域划分，介绍目前常见的几种接口标准。

![](https://static.getiot.tech/electric-vehicle-connector-types.jpg#center)



## AC 交流充电接口

目前有交流慢充和直流快充两种充电方式，我们先来看看交流充电接口。

### J1772 - Type 1

早在2001年，美国加州推出了一款名为 J1772 的方形插头，但它的功率只有 6.6kW。到了2008年，Yazaki 设计了一款功率为 19.2kW 的新插头，并在2010年以后成为美国所有电动汽车的充电接口标准。后来经过修改，形成了现在的 J1772 新标准，通常被称为 J-plug 或 Type 1。

最初，欧洲的电动汽车也有这种类型的连接器，所以许多旧的或混合动力汽车仍然配备 Type 1 充电接口。目前主要在美洲和亚洲部分地区使用。由于 Type 1 是早期的充电接口标准，所以它的缺点很明显 —— 只支持一阶段充电，不支持内置的自动锁定系统。

![](https://static.getiot.tech/ev-connector-j1772--type1.png#center)

> 近几年，电动车普遍使用了所谓三段式充电器，第一个阶段叫恒流阶段，第二个阶段叫恒压阶段，第三个阶段叫涓流阶段。从电子技术角度针对电池而言：第一个阶段叫充电限流阶段，第二个阶段叫高恒压阶段，第三个阶段叫低恒压阶段比较贴切。第二阶段和第三阶段转换时，面板指示灯相应变换，大多数充电器第一、二阶段是红灯，第三阶段变绿灯。第二阶段和第三阶段的相互转换是由充电电流决定的，大于某电流进入第一第二阶段，小于某电流进入第三阶段。这个电流叫转换电流，也叫转折电流。

### Mennekes - Type 2

欧洲的汽车厂商早期也使用 Type 1 连接器，后来开始寻找新的解决方案，以便可以充分利用充电的三个阶段。2003年，IEC 62196 建立了新的规范，带来了 Type 2（Mennekes）接口标准，并迅速成为新的欧洲标准。因为该标准是由一家名为 Mennekes 的德国公司设计的，因此 Type 2 也被称为 Mennekes。

事实上，Type1 和 Type2 接口使用相同的 J1772 信令协议进行通信，因此汽车制造商可以用同样的方式生产汽车，只是最后安装的插头不同而已。当然，Type 2 带来的一个重要优点是它支持内置的自动锁定系统。

![](https://static.getiot.tech/ev-connector-mennekes-type2.png#center)

### GB/T 国标

在国标标准化委员会的监督下，我国也有自己的 GB/T 标准，目前是国内汽车厂商使用的唯一接口标准。统一的标准可以促进了充电基础设施的发展。

![](https://static.getiot.tech/ev-connector-gb-t-standard.png#center)

从表面上看，我国的 GB/T 标准连接器与欧洲的 Type 2 相同，但其实内部的电缆排列顺序是不同的，因此不能兼容。



## DC 直流充电接口

直流充电使汽车的充电速度明显快于交流充电。目前，最常见的直流充电站的功率是 50kW，但 150kW 的充电站已经出现，270kW 和 350kW 的充电器也正在出现，所以在充电连接器这方面也在不断更新。

### CCS - Type 1 和 Type 2

CCS（Combined Charging System，组合充电系统）是快速直流充电的完美解决方案，也是目前最流行的直流连接器类型。其中，CCS - Type 1 在美国很常见，而 CCS - Type 2 则在欧洲使用。

![](https://static.getiot.tech/ev-connector-ccs-type1-and-type2.png#center)

### CHAdeMO

CHAdeMO 是由日本5家汽车制造商联合开发的直流充电接口，自2010年以来，他们一直试图将这一插头推广为全球标准，但并没有奏效。欧洲议会试图执行一项指令，让这种连接器逐渐从欧洲消失，转而支持 CCS。所以该标准未来只会在日本普遍使用。

![](https://static.getiot.tech/ev-connector-chademo.png#center)

### GB/T 国标

和交流充电一样，我国也有自己的直流充电标准。

![](https://static.getiot.tech/ev-connector-gb-t.png#center)



## Tesla 充电接口

特斯拉的连接器与其他任何品牌都不同，这使得特斯拉的客户可以在自己的充电站上充电，而其他任何车辆都无法使用。不过，为了方便使用，特斯拉也提供了与其他类型接口转换的适配器，包括 Type 1 或 CHAdeMO 接口，以及欧洲地区普遍使用的 CCS Type 2 接口。

![](https://static.getiot.tech/ev-connector-tesla-konektor.png#center)
