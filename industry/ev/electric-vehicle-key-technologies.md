# 电动汽车关键技术



![](https://static.getiot.tech/Audi-e-tron-s-3.jpg#center)



## 四个组成部分

按照汽车构造来拆解，可以一辆汽车（包括燃油车和电动车）划分为四个基本组成部分：

1. **底盘**（传动系统、制动系统、转向系统、悬架系统）
2. **车身**（内饰、外饰、整车空间）
3. **动力总成**（发动机、变速器、电池、电动机）
4. **电子电气设备**（传感器、控制器、执行器）

电动汽车和燃油汽车最大的区别就在于底盘和动力总成，统称为动力系统。



## “三电”系统

电动汽车技术的核心在于动力系统，包括**电驱系统**、**电池系统**和**电控系统**三个系统，简称为“三电”系统。

![](https://static.getiot.tech/electric-vehicle-key-technologies.png#center)

### 电驱系统

电驱系统也称为“电驱动系统”，包括驱动电机、传动机构和变换器等组成部分。

**驱动电机**（Motor）也称为“电动机”或“驱动电动机”，是把电能转换为机械能的装置，内部一般由定子和转子等结构组成。在电动汽车中，它的作用就是将存储在电池中的电能转换为机械能，为汽车行驶提供动力。

根据工作原理的不同，可分为直流电动机、交流电动机、同步电动机、异步电动机等多种电动机。目前市面上的电动汽车中，常用的是永磁同步电动机（国内车企常用）和三相异步电动机（特斯拉电动车）。

![](https://static.getiot.tech/electric-vehicle-drive-motors.jpg#center)

**传动机构**则是连接电动机和汽车主轴的机构，主要包括减速器和差速器两个部件。减速器是一种相对精密的机械，它的作用是降低电动机的转速，增加转矩。差速器的作用则是在汽车转弯时使两侧车轮转速不同。两者结合起来，可以调节电动机输出的转矩和转速，满足汽车行驶动力的要求。

**变换器**则包括逆变器（Inverter）和 DC/DC 变换器两个器件。逆变器的作用是将动力电池的直流输出转变为交流输出，以驱动交流电动机。DC/DC 变换器则用于直流高低压的转换，比如将动力电池的高压电（大于 400V）转换为低压电，为各种电子电气设备供电。



### 电池系统

对于电动汽车来说，电池系统是最复杂、成本最高的子系统，其核心就是储存电能的动力电池。由于锂离子电池技术成熟、商业化程度高，并且能量密度较高，可实现快速深度充放电。所以目前量产的动力电池均为锂离子电池。根据正极材料不同，锂离子电池可以分为磷酸铁锂、锰酸锂、钴酸锂、三元锂电池等几种类型。目前，电动汽车通常采用的是磷酸铁锂和三元锂电池两种。

为了启动电动汽车，需要相当于数千倍的智能手机电量的巨大电量。因此，需要数十个乃至数千个电芯。虽然电动汽车种类不同，其组成也会存在细微差异，但是通常电动汽车电池由电芯（Cell）、电池模块（Module）、电池包（Pack）组成。 

![](https://static.getiot.tech/electric-vehicle-battery-pack.png#center)

多个电芯以串联或并联的方式组成电池模块，多个电池模块再串联起来，为了安全有效地管理众多的电芯，将集成热管理系统、电池管理系统等部件，最终形成一个电池包。简单来说，电芯、模块、电池包是组成电池的单位。多个电芯组成模块，几个模块组成电池包。而电池最终以一个电池包的形态装入电动汽车。

| 单位     | 描述                                                         |
| -------- | ------------------------------------------------------------ |
| 电芯     | 也称为“电池单元”，是可以用来充电和放电的锂电池的基本单位。由正极、负极、隔离膜、电解液构成，通常封装成圆柱、方形或软包形式。 |
| 电池模块 | 为了保护电芯，避免外部冲击、热、振动等影响电芯正常工作，所以将一定数量的电芯联结在一起并放入一个框架中组成电池组件。 |
| 电池包   | 在电池模块上装配 BMS 电池管理系统、冷却系统等各种控制和保护系统制成，是装入电动汽车的电池系统的最终形态。 |



### 电控系统

电控系统包含三个子控制单元，分别是整车控制器（Vehicle Control Unit，VCU）、电池管理系统（Battery Management System，BMS）、驱动电机控制器（Motor Control Unit，MCU）。

- **整车控制器**（VCU）：负责管理整个电动汽车，监控汽车的各种运行状态，接收驾驶员的操作指令，同时也是各个子系统的调控中枢。
- **电池管理系统**（BMS）：负责管理动力电池，包括采集和监测电池系统的电压、电流、温度、剩余电量等数据，实时监测、分析和保护电池的安全。
- **驱动电机控制器**（MCU）：接收整车控制器的行驶控制指令，控制电动机输出指定的转速和扭矩，从而改变车速和方向。
