# 电动汽车的分类



前面《[电动汽车简介](/ev/electric-vehicle-intro/)》中简单介绍了电动汽车的分类，主要包括混合动力电动汽车（HEV）和纯电动汽车（BEV）两大类。其中，混合动力汽车又可分为非插电式混合动力汽车、插电式混合动力汽车（PHEV）以及增程式电动汽车（REEV）。

![](https://static.getiot.tech/new-energy-vehicle-types.png#center)



## 主要分类

简单来说，各类电动汽车的特点如下。

- **纯电动汽车**（BEV）就是指动力来源完全由电能提供，由电动机驱动的汽车，并且电能储存在电池中。
- **混合动力汽车**（HEV）则是指动力来源可以是化石燃料，也可以是电能，并且电能除了可以存储在电池中，还可以由化石能源转化而来。
- **非插电式混合动力汽车**虽然也有电池和电动机，但其电能完全由化石能源转化而来，不能外接充电。
- **插电式混合动力汽车**（PHEV）则可以通过外接充电获取电能，即可以当纯电动汽车使用，亦可当传统燃油汽车使用，是能源转型过渡期颇受欢迎的产品。
- **增程式电动汽车**（REEV）实际上是插电式混合动力汽车的串联形式。

顾名思义，增程器的作用就是增加电动汽车的行驶里程，它能让发电机为电动汽车的电池充电来延长车辆的行驶里程。大多数情况下增程式电动汽车工作在纯电动模式，少数情况下由增程器产生电能供电池充电，而增程器一般指的就是发动机与发电机的组合。实际上，最常用的增程器就是内燃机。



## 优缺点对比

下面针对纯电动汽车和混合动力汽车，列举其目前常见的优缺点。

| 类型         | 优点                                                         | 缺点                                                         |
| ------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 纯电动汽车   | - 零排放<br/>- 系统布置简单<br/>- 更为安静平顺，且动力响应更为迅速<br/>- 政策导向 | - 续航里程受限<br/>- 驾驶员续航里程焦虑<br/>- 电池失火风险<br/>- 电池寿命相对较低（持续输出和深度放电） |
| 混合动力汽车 | - 可作为纯电动汽车使用<br/>- 续航里程较长<br/>- 相对安全（电池更小） | - 仍存在发动机尾气排放<br/>- 内部结构复杂（两套动力系统）<br/>- 车厢空间较小（传动机构多） |

在我国目前的政策下，BEV、PHEV、REEV 电动汽车都是可以申领新能源汽车牌照的，但对纯电动汽车的支持力度明显更大，是未来发展的重要方向。相对来说，混合动力汽车在现阶段能弥补纯电动汽车续航里程不足的缺点，在一些地区可能是更好的选择。



## 其他分类

除了上述分类方式，还可以按照汽车动力系统结构的不同，分为并联、串联、混联三种形式。这种分类主要针对混合动力汽车，也就是内燃机和电动机两套动力系统的连接关系。具体区别将在下一节《[电动汽车工作原理](/ev/electric-vehicle-working-principle/)》详细介绍。

另外，按照油电混合度区分，还可以分为轻混电动汽车（Mild Hybrid Electric Vehicle）、强混电动汽车（Hybrid Electric Vehicle）、插电混动汽车（Plugin Hybrid Electric Vehicle）、纯电动汽车（Battery Electric Vehicle）四种类型。

油电混合度就是指电动汽车的电能部分占总能量的比例，显然，纯电动汽车的油电混合度为100%。考虑到生产成本，混合动力汽车的油电混合度与其搭载的动力电池能量大小成正比。也就是说，搭载的动力电池能源越大，该电动汽车的油电混合度就越高。
