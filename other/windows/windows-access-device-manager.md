# Windows 快速打开设备管理器

无论是开发者还是普通用户，Windows 的设备管理器都是一个非常有用的工具，它允许用户查看以及设置连接到电脑的硬件设备等，并将它们排列成一个列表。当任何一个设备无法使用时，设备管理器中就会显示提示给用户查看，用户可以针对各种设备安装或更新其驱动程序，激活或停用设备。

本文将介绍如何快速打开 Windows 系统的设备管理器，这些方法适用于 Windows 7、8、10 和 11 操作系统。



## 方法一

1、按 Win + R 键打开“运行”（Run）对话框窗口

![Windows Run Box](https://static.getiot.tech/windows-run-box.jpeg#center)

2、输入命令：`devmgmt.msc`

3、点击“确认”（OK）按钮

4、可以看到设备管理器（**Device Manager**）已经打开了！

![Windows Device Manager](https://static.getiot.tech/windows-device-manager.jpeg#center)



## 方法二

1、打开 CMD 命令行

2、输入命令：`devmgmt.msc`

3、按回车键（Enter）

4、可以看到设备管理器（**Device Manager**）已经打开了！



## 方法三

在桌面空白处点击右键 -> 新建 -> 快捷方式，输入 `devmgmt.msc`，点击下一步，输入该快捷方式的名称“设备管理器”。

这样，桌面就会出现一个“设备管理器”的图标，双击它就可以直接打开设备管理器啦！
