# Visual Studio 设置命令行参数



在 Visual Studio IDE 调试程序时，你可能会遇到一个问题 —— 如何为该程序添加命令行参数？以便在程序启动时进入不同模式，方便调试。

其实很简单，方法如下：

1. 在 Visual Studio 项目中依次选择 “Project（项目）” -> “Properties（属性）” 打开项目的属性页对话框。
2. 选择 “Configuration Properties（配置属性）” -> “Debugging（调试）” 。
3. 在列表框中找到 “Command Arguments（命令参数）”，输入调试程序所需的参数。
4. 点击右下角的 “确定” 按钮。
