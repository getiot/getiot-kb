# PyQt 教程

![PyQt 教程](https://static.getiot.tech/cover-python-pyqt-tutorial.webp#center)

Qt 是一款流行的 C++ 图形用户界面框架，PyQt 则是一套 Python 绑定 Qt 库的工具。通过 PyQt，开发者能够借助 Python 语言的便捷性，使用 Qt 强大的功能，轻松构建各种类型的桌面应用程序。

在这个教程中，我们首先学习 PyQt 的基础概念和设计思想，掌握如何使用布局管理器，如何创建和使用自定义控件，并通过实际项目案例构建 PyQt 应用程序。
