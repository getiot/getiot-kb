# wxPython 教程

![wxPython 教程](https://static.getiot.tech/cover-python-wxpython-tutorial.webp#center)

wxPython 是 Python 中强大而灵活的图形用户界面（GUI）工具包之一，提供了丰富的控件和强大的事件处理机制。甚至允许你使用 C++ 编写自定义控件，扩展应用的功能。

在这个教程中，我们将学习各种 wxPython 控件的使用方法，以及如何利用布局管理器实现界面的灵活排列。深入理解 wxPython 的事件处理机制，掌握如何处理各类用户交互。通过本教程，你将全面掌握 wxPython 的使用，从而能够独立开发出各类交互性强、外观炫酷的应用。
