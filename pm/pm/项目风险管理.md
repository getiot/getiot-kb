# 项目风险管理


## 概念和定义

风险是指与项目相关的若干不确定性事件或条件，一旦发生，将会对项目目标的实现产生正面或负面的影响。

风险可以用以下公式表示：
$$
R = f(P, C)
$$

```mathjax
R = f(P, C)
```

其中，R 代表“风险”；P 代表“不利事件发生的概率”；C 代表“不利事件发生的后果”。

项目风险管理则是指对项目风险从识别到分析乃至采取应对措施等一系列过程，包括将积极因素所产生的影响最大化和使消极因素产生的影响最小化两方面内容。



## 项目风险的特点

- 由于某一具体风险发生的偶然性和大量风险发生的必然性体现出风险**随机性**的特点；
- 相对于项目主体而言，风险具有**相对性**；
- 因风险的性质和后果的变化，加之出现新风险，构成风险的**可变性**；
- 此外，风险还具有**普遍性**和**客观性**的特点。



## 规划和识别风险

规划风险管理是在项目正式启动前或启动初期，对项目的一个纵观全局的对于风险的考虑、分析、计划，也是项目风险控制中最关键的内容。

为确保定性风险分析过程的质量和可信度，要求界定不同层次的风险概率和影响。在风险规划过程中，通用的风险概率水平和影响水平的界定将依据个别项目的具体情况进行调整，以便在定性风险分析过程中应用。

在具体识别风险时，需要综合利用一些专门技术和工具，以保证高效率地识别风险且不发生遗漏。常用的方法包括：文档审查、信息收集技术（德尔菲技术、头脑风暴、访谈、根本原因识别）、核对表分析、假设分析、SWOT 技术、专家判断和图解技术（因果图、系统或过程流程图、影响图）等。



### SWOT 分析

SWOT 技术从项目的每个优势（Strength）、劣势（Weakness）、机会（Opportunity）和威胁（Threat）出发，对项目进行考察，把产生于内部的风险都包括在内，从而更全面地考虑风险。

## 风险的定性和定量分析

风险定性分析包括对已识别风险进行优先级排序，以便采取进一步措施，如进行风险量化分析或风险应对。

风险定性和定量分析依据如下表所示。

| 定性分析依据                                                 | 定量分析依据                                                 |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 风险管理计划<br/>范围基准<br/>风险登记册<br/>事业环境因素<br/>组织过程资产 | 风险管理计划<br/>项目成本管理计划<br/>项目进度管理计划<br/>风险登记册<br/>事业环境因素<br/>组织过程资产 |



### 决策树相关知识

决策树分析法是指借助树型分析图，根据各种类型风险出现的概率及预期损益，计算与比较各方案的损益期望值，从而抉择最优方案的方法。

决策树的构成有四个要素：决策结点、方案枝、状态结点和概率枝。

决策树法的决策程序如下：

1. 绘制树状图，根据已知条件排列出各个方案和每一方案的各种自然状态。
2. 将各状态概率及损益值标于概率枝上。
3. 计算各个方案期望值，并将其标于该方案对应的状态结点上。
4. 进行剪枝，比较各个方案的期望值并标于方案枝上。将期望值小的（即劣等方案）剪掉，所剩的最后方案为最佳方案。
