# GitHub 简介



## GitHub 是什么

从功能上讲，Github 是一个带有简单社交功能的云端代码仓库服务。经过多年的发展，Github 已经成为这个领域事实上的标准。全世界绝大部分开源项目托管在 Github 上面，包括 Linux，OpenStack，Docker 等重量级项目。开源这几年蓬勃发展，极大的推动了 IT 行业的发展。很显然，计算机软件在人类生活中将会扮演越来越重要的角色，而 Github 就是人类软件的基因库。

![](https://static.getiot.tech/github-working-model.png)



## GitHub 的特点

Github 发明了两个碉堡了的功能，Fork 和 Pull Request。这两个功能创造了整个 Github 生态系统，使得“基因”得以繁衍和进化，充满了生命力。基因通过 Fork 被复制，而 Pull Request 使得基因得以进化。好的基因会被大量的 Fork，从而实现了优胜劣汰。这一整套体系才是精华所在，说 Github 是代码仓库显然太肤浅了。
