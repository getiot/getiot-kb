# 第十二部分：实战案例

这一部分把前面各章的知识串成“能跑的工程”。建议你把案例当作模板：后续写自己的项目时，直接以案例结构为起点。

## 学习目标

- 从最小命令行工具开始，逐步演进到“库 + 应用”
- 学会用 target-based 组织多目录项目
- 把测试、依赖、安装等能力自然地放入工程骨架

## 推荐阅读顺序

1. `CMake 实战案例一：简单命令行工具`
2. `CMake 实战案例二：库项目`
3. `CMake 实战案例三：复杂项目`

## 练习建议

- 用“案例三”的骨架，把你手头一个小项目迁移过去（先迁移构建，再迁移测试/安装）
