# 第五部分：项目组织

这一部分解决“项目变大之后怎么组织”的问题：多目录拆分、子目录管理、多子项目构建，以及一套可长期维护的工程结构最佳实践。

## 学习目标

- 能把工程拆成多个子目录，并用 `add_subdirectory()` 组合
- 理解“顶层负责组装、子目录负责内聚”的组织方式
- 能组织多个可执行文件/多个库/多个子项目共存的仓库结构

## 推荐阅读顺序

1. `CMake 多目录项目结构`
2. `CMake 子目录管理`
3. `CMake 编译多个子项目`
4. `CMake 项目结构最佳实践`

## 练习建议

- 把一个单目录工程拆成 `src/`、`include/`、`tests/`，并为每个目录写独立 `CMakeLists.txt`
- 添加一个 `examples/` 子项目，并让它复用主库 target
