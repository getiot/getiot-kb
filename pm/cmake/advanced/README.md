# 第九部分：高级特性

这一部分收录更偏“能力提升/工程技巧”的主题：生成器表达式、函数与宏、自定义命令、superbuild 等。建议在完成“库/依赖/安装”后再系统阅读。

## 学习目标

- 能读懂并使用生成器表达式（按配置/平台条件化设置属性）
- 能把重复逻辑抽成函数/宏，提升可维护性
- 能用自定义命令把代码生成、资源打包等流程纳入构建
- 理解 superbuild 的思路与适用场景

## 推荐阅读顺序

1. `CMake 生成器表达式`
2. `CMake 函数和宏`
3. `CMake 自定义命令`
4. `CMake Superbuild 超级构建`

## 练习建议

- 用生成器表达式为 Debug/Release 设置不同编译选项
- 把一段重复的 target 配置抽成函数（如统一开启警告、统一设置编译标准）
