# Linux pushd 命令 - 将目录压入目录栈



Linux **pushd** 命令把原目录和当前目录压入到一个虚拟的目录堆栈中（可通过 dirs 命令查看），如果不指定参数，则会回到前一个目录，并把堆栈中最近的两个目录作交换。

具体参考 [dirs 命令用法](/linux-command/dirs/)
