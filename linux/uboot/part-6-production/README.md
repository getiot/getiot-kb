# 高级功能与产品化

能把 Linux 启动起来，只是 U-Boot 工作的一半。产品还需要面对升级、安全、回滚、启动速度、可靠性和维护成本。本部分介绍这些更接近量产系统的问题。

你不需要在入门阶段把所有高级功能都实现一遍，但应该知道它们解决什么问题、引入什么代价，以及什么时候值得使用。

本部分会反复强调一个原则：产品化功能必须和恢复策略一起设计。FIT、Verified Boot、A/B、Recovery、启动优化都不是孤立功能。它们最终要服务于同一个目标：设备能可信、稳定、可维护地启动，并且在失败时有明确退路。
