# 第七部分：调试与实践

前面你已经学完了 U-Boot 的主要知识线索。本部分把它们收束到调试方法和综合实践中：如何保存证据、如何分层排查、如何在 QEMU 中组织一次完整 Linux 启动实验，以及如何把同样的方法带到真实开发板。

学习 U-Boot 最忌讳“看到错误就随机改变量”。你应该像排查一条启动链：每次确认一个阶段，每次只改变一个条件。

这一部分建议你带着实验环境一起读。哪怕暂时没有真实开发板，也可以先在 QEMU 中练习保存日志、加载文件、制造一个小错误并恢复。真正上板时，这些习惯会让你少走很多弯路。
