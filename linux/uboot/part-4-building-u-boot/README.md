# 第四部分：编译与理解 U-Boot

前面你主要是在 U-Boot 命令行中使用现成镜像。从这一部分开始，你要回到源码，理解 U-Boot 是如何被配置、编译和组织起来的。

本部分以 Mainline U-Boot v2026.07 为基准，主实验目标仍然是 QEMU ARM64 `virt`。你会看到 `defconfig` 如何选择板级配置，`make` 如何生成 `u-boot.bin`，构建产物分别有什么用途，以及源码中的初始化、重定位、Driver Model 和命令系统大致如何协作。

学完本部分后，你应该能够：

- 准备合适的交叉编译环境。
- 获取并确认 U-Boot v2026.07 源码。
- 使用 `qemu_arm64_defconfig` 配置并编译 U-Boot。
- 识别常见构建产物。
- 在源码树中找到板级、驱动、命令、启动框架相关代码。
- 添加一个简单自定义命令，理解命令注册机制。

建议你按顺序学习本部分。先把 U-Boot 编译出来，再去看产物和源码结构；如果还没有成功构建，直接读重定位、Driver Model 或命令注册，会缺少很多可观察的参照物。

本部分的源码阅读会以“够用”为原则。你不需要一次看懂所有初始化细节，只要能带着问题定位到相关目录和关键函数，就已经迈过了 U-Boot 开发入门最重要的一关。
