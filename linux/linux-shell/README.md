# Linux Shell 编程

![Linux Shell 编程](https://static.getiot.tech/cover-linux-shell-tutorial.webp#center)

欢迎来到 Linux Shell 编程教程。

Shell 是你与 Linux 交互的主要入口：既可以在终端里敲命令，也可以把一组命令整理成可重复执行的脚本。嵌入式开发、服务器运维、自动化测试和日常排错，几乎都会用到 Shell。

本教程面向 Linux 初学者与希望系统整理脚本能力的工程师，主要内容包括：

- Shell 概念、Bash 基础语法与数据类型
- 变量、数组、运算符与流程控制
- 脚本结构、参数传递与函数
- 通配符、正则表达式
- `grep`、`sed`、`awk` 文本处理
- 常见脚本模板，以及如何制作简单的脚本安装包

建议按目录顺序阅读：先掌握语法与变量，再写判断与循环，然后进入脚本工程化与文本处理。正文示例默认以 **Bash** 为准；Ubuntu 上 `/bin/sh` 往往指向 **dash**，两者语法有细微差别，涉及可移植脚本时会另行说明。

:::tip

学习时请在自己的 Linux 环境中亲自敲一遍命令。Shell 编程最好的教材，就是终端里那一行行真实的输入与输出。

:::
