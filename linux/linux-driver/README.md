# Linux 设备驱动开发教程

![Linux 设备驱动开发教程](https://static.getiot.tech/cover-linux-driver-tutorial.webp#center)

设备驱动连接操作系统与硬件。本教程从设备分类与设备节点入手，再介绍设备树（DTS），以及 GPIO、pinctrl、LED 等常用内核子系统，帮你建立「从用户空间到硬件」的完整图景。

建议按侧边栏顺序阅读：先建立概念，再进入设备树与各子系统。
