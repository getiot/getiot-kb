# 各类 Linux 会议

这里列出与嵌入式 Linux 开发相关的各类事件（会议）。另外有许多部分区域会议内容因为采用非国际语言，不方便阅读，因此没有收录。如有需要，请阅读 [elinux Events](http://elinux.org/Events)。

会议主要有如下几大类：
- **Kernel Summit**（内核峰会）

  面向全球核心内核开发者，讨论当前内核状态，并计划下一个开发周期的工作

- **LinuxCon**

  Linux 会议（分区域）

- **Embedded Linux Conference**

  ELC（嵌入式 Linux 会议）

- **Embedded Linux Conference Europe**

  ELCE，嵌入式 Linux 会议（欧洲）

- **渥太华 Linux Symposium**

  OLS，每年在加拿大举办的一个 Linux 和开源的年度会议

- **Linaro Developer Summit**

  Linaro 是一个 ARM 技术开源联盟

- **Android Builders Summit**

  面向 OEMs, 设备制作商，集成商，客制化用户和 不断增长的 Android 和 Linux 用户

- **FOSDEM**

  由社区组织的自由和非商业会议

- **中国 Linux 内核开发者大会**

  [CLK](http://ckernel.org)，由英特尔、阿里巴巴、富士通南大软件、腾讯、今日头条、华为等企业组织，以“自由，协作，创新”为理念，以开源技术的推广和普及 为使命，旨在促进 Linux 内核开发爱好者相互交流、共同进步。每届线下参会人数近500人，是中国 Linux 内核领域颇有影响力的峰会之一。
