# Linux 入门准备

这一章帮助你从零进入 Linux 世界。你会先了解 Linux 是什么、它从哪里来、常见发行版有什么区别，然后准备一个适合练习的环境。

如果你是第一次学习 Linux，建议按顺序阅读：

- [Linux 简介](linux-intro.md)
- [Unix 起源](a-brief-history-of-unix.md)
- [Linux 简史](linux-history.md)
- [Linux 发行版](linux-distributions.md)
- [Linux 学习环境搭建](linux-learning-environment.md)
- [终端、Shell 与命令提示符](linux-terminal-shell.md)
- [获取帮助：man、--help 与 info](linux-getting-help.md)

学完这一章，你应该能打开终端，知道自己正在使用什么系统，并能通过 `man`、`--help` 和站内命令文档查找帮助。
