# Linux 学习环境搭建

学习 Linux 最好的方式不是先背概念，而是尽快准备一个可以放心操作的环境。你需要一个能打开终端、能联网、能创建和删除文件、能安装软件包的 Linux 系统。

本文会帮你选择适合初学者的 Linux 学习环境，并完成最基本的检查。

## 选择学习环境

如果你只是刚开始学习，推荐按下面顺序选择。

| 方式 | 适合你吗 | 优点 | 注意事项 |
| --- | --- | --- | --- |
| 虚拟机 | 最推荐 | 隔离、安全、可以快照 | 占用一些内存和磁盘空间 |
| WSL | 使用 Windows 时很方便 | 启动快、和 Windows 文件互通 | 和真实 Linux 服务器仍有少量差异 |
| 云服务器 | 想练远程登录和服务部署 | 接近生产环境 | 需要注意费用和安全 |
| 旧电脑实装 | 想完整体验桌面 Linux | 最真实 | 安装过程可能清空磁盘 |
| Raspberry Pi 等开发板 | 做嵌入式或 IoT | 接近硬件场景 | 系统镜像和外设问题更多 |

对于大多数初学者，虚拟机或 WSL 已经足够。等你熟悉命令行、文件系统和软件安装之后，再去使用云服务器或开发板，会轻松很多。

## 推荐发行版

入门阶段建议选择 Ubuntu、Debian、Fedora 这类资料丰富、社区活跃的发行版。

- Ubuntu：资料最多，适合桌面、服务器和初学者。
- Debian：稳定、简洁，很多服务器和嵌入式系统都以它为基础。
- Fedora：更新较快，适合体验较新的 Linux 桌面和开发工具。

如果你暂时不知道选哪个，就选 Ubuntu。学习 Linux 基础时，发行版差异没有你想象得那么大；真正重要的是文件系统、命令行、权限、进程、网络这些共通知识。

## 虚拟机方案

虚拟机是在你当前电脑里运行一个完整 Linux 系统。你可以把它理解为“电脑里的另一台电脑”。

常见选择包括：

- VirtualBox
- VMware Workstation Player
- GNOME Boxes
- UTM

基本步骤如下：

1. 下载 Ubuntu 或 Debian 的 ISO 镜像。
2. 在虚拟机软件中创建一台新虚拟机。
3. 分配 CPU、内存和磁盘。
4. 挂载 ISO 镜像并启动安装。
5. 创建普通用户，完成安装。

入门练习建议至少分配：

- 内存：2 GB 或更多。
- 磁盘：20 GB 或更多。
- 网络：使用 NAT 模式即可。

:::tip
如果虚拟机软件支持快照，建议在系统刚安装完成时创建一个快照。以后练习命令时即使把环境弄乱，也可以快速恢复。
:::

## WSL 方案

如果你使用 Windows，可以安装 WSL，然后从 Microsoft Store 安装 Ubuntu。安装完成后，你会得到一个 Linux 终端，可以练习大部分命令行操作。

WSL 很适合学习：

- 基本命令
- 文件操作
- Shell 脚本
- 软件包管理
- 开发工具链

但你也要知道，WSL 和真实 Linux 服务器不是完全一样。比如系统启动、硬件设备、systemd 服务、网络栈等行为可能有差异。学习基础命令没问题，学习服务管理和网络排错时，虚拟机或云服务器更接近真实环境。

## 云服务器方案

云服务器适合练习 SSH、systemd、网络端口、防火墙和服务部署。你可以选择一台最低配置的 Linux 云服务器，安装 Ubuntu Server、Debian 或 Rocky Linux。

使用云服务器时请记住三件事：

- 不要把弱密码暴露在公网。
- 不要随意开放端口。
- 不用时及时释放资源，避免继续计费。

第一次登录服务器通常会用到 SSH。后面你会在 [通过 SSH 连接 Linux](../network/connect-using-ssh.md) 中系统学习。

## 打开终端

在 Linux 桌面环境中，终端程序通常叫 Terminal、Console、Konsole 或 GNOME Terminal。打开后，你会看到类似这样的提示符：

```bash
rudy@ubuntu:~$
```

它大致表示：

- `rudy`：当前用户名。
- `ubuntu`：主机名。
- `~`：当前位于用户家目录。
- `$`：普通用户提示符。

如果提示符最后是 `#`，通常表示你正在使用 root 用户。初学阶段建议尽量使用普通用户，需要管理员权限时再使用 [sudo](/linux-command/sudo/)。

## 做一次环境检查

打开终端后，先运行几条不会改变系统状态的命令：

```bash
uname -a
whoami
pwd
ls
```

你不需要马上看懂每一列输出。先知道它们分别在回答什么问题：

- [uname](/linux-command/uname/)：当前系统和内核信息。
- [whoami](/linux-command/whoami/)：当前登录用户是谁。
- [pwd](/linux-command/pwd/)：当前所在目录。
- [ls](/linux-command/ls/)：当前目录下有什么。

## 建立练习目录

后续教程会经常让你创建文件、删除文件、重定向输出。为了避免误操作，建议你先建立一个专门的练习目录：

```bash
mkdir -p ~/linux-practice
cd ~/linux-practice
pwd
```

预期输出类似：

```text
/home/rudy/linux-practice
```

从现在开始，除非教程特别说明，你都可以在这个目录里练习。这样即使输错命令，也不容易影响系统文件。

## 学习时的安全习惯

Linux 很强大，也很直接。命令写对了，它会高效完成任务；命令写错了，它也可能高效地制造麻烦。

请养成这些习惯：

- 看懂命令的大意之后再回车。
- 不在不了解含义时使用 `sudo`。
- 对 `rm`、`dd`、`mkfs`、`fdisk`、`parted` 等命令保持警惕。
- 操作系统目录前先确认当前路径，可以先运行 [pwd](/linux-command/pwd/)。
- 删除文件前先用 [ls](/linux-command/ls/) 检查目标。
- 在虚拟机中练习高风险操作前先创建快照。

:::warning
不要把网上看到的长命令直接复制到终端执行，尤其是包含 `sudo`、`rm -rf`、磁盘设备路径或管道下载脚本的命令。先拆开理解每一段。
:::

## 小结

你现在需要完成的准备工作是：

- 选择一个 Linux 环境。
- 能打开终端。
- 能运行 `uname`、`whoami`、`pwd`、`ls`。
- 建立 `~/linux-practice` 练习目录。
- 知道哪些命令需要格外小心。

下一篇文章会介绍终端、Shell 和命令提示符。你会知道自己输入的命令到底交给了谁处理。
