# Linux 操作系统



## Linux 简介

Linux 是一款广泛使用的开源操作系统，全称 GNU/Linux，与 Windows、macOS 操作系统一起被称为“三大操作系统平台”。和其他操作系统一样，Linux 也有诸如通信、接收用户指令、向磁盘读写数据和运行应用软件等功能。

操作系统最重要的部分就是内核（kernel），在 GNU/Linux 系统中，Linux 是内核组件，其余组件则由 GNU 项目开发，包括编译器、调试器、文本编辑器、Shell 终端、图形界面等。

Linux 操作系统的设计灵感来源于 UNIX 操作系统，支持多用户、多任务，并且是自由和开源的。这意味着，用户拥有对 Linux 操作系统的所有控制权限，使得 Linux 成为计算机黑客和极客的理想选择。可以说，Linux 操作系统是目前世界上最受欢迎的操作系统之一。

扩展阅读：[Linux 简史](/linux/linux-history/)



## Linux 特点

- 自由、开源（遵循 GPLv2 许可证）
- 支持多用户、多任务
- 类 UNIX 操作系统
- 支持 POSIX 接口



## Linux 发行版

Linux 现在拥有许多发行版本，它们都是以 Linux 内核为核心组件，在此基础上增加图形界面、系统管理工具、软件包管理器等组件。目前来说，最流行的几个 Linux 发行版本是 Ubuntu、Debian 和 Fedora，以及在服务器领域广泛使用的 Redhat、CentOS 等。

扩展阅读：[Linux 发行版](/linux/linux-distributions/)



## 应用场景

Linux 操作系统主要应用领域包括：

- 服务器
- 嵌入式设备
- 桌面电脑
- 手机/平板电脑（Android）

虽然 Linux 在桌面操作系统中的市场占有率仅 2% 左右，但在服务器领域，Linux 是绝对霸主，甚至统治了世界上功能最强大的超级计算机的前 500 名。

另外，Linux 在嵌入式领域也早已渗透到各行各业，包括工业控制、通信设备、医疗电子、消费电子等领域。我们熟知的 Android 系统就是运行在 Linux 内核之上的，而 Android 是世界上最受欢迎的移动操作系统。
