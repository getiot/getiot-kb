# Linux 文件系统与权限

Linux 把文件、目录、设备、链接和权限组织成一棵从 `/` 开始的目录树。理解这棵树，是理解 Linux 日常操作和排错的关键。

本章会带你学习目录结构、文件类型、软硬链接、用户权限和磁盘挂载。
