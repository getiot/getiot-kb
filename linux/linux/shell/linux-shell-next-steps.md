# Linux Shell 教材下一步

到这里，你已经知道 Shell 脚本是什么，能写一个简单脚本，也理解了变量、参数、退出状态、条件、循环和函数的基本形状。

但 Shell 脚本是一门值得单独学习的技能。本教程不打算把 Shell 全部内容塞进《Linux 基础教程》，因为那会让 Linux 主线变得过重。

## 你已经具备的基础

在继续学习 Shell 前，你应该已经掌握：

- 终端和 Shell 的关系。
- 文件和目录操作。
- 管道与重定向。
- `grep`、`find`、`cat`、`less`、`tail` 等文本和文件命令。
- 基本文件权限。
- 简单脚本执行方式。

这些知识会让你学习 Shell 时轻松很多。

## 接下来读什么

建议继续阅读 [Shell 教材](/linux-shell/)。可以按下面顺序学习：

1. Shell 简介和基础语法。
2. 变量、数据类型和数组。
3. 判断语句和循环语句。
4. 输入输出和传递参数。
5. 函数调用。
6. 通配符和正则表达式。
7. `grep`、`sed`、`awk` 文本处理。
8. Shell 脚本示例和脚本安装包。

如果你只是日常使用 Linux，先掌握前五项已经足够。如果你要做日志分析、文本处理或运维自动化，再重点学习 `sed` 和 `awk`。

## Shell 脚本写作建议

写脚本时请保持朴素：

- 一个脚本只解决一个明确问题。
- 变量名表达含义。
- 路径尽量使用变量保存。
- 操作前检查参数。
- 删除、覆盖、同步前提供确认或演练模式。
- 复杂逻辑及时换 Python、Ruby、Go 等语言。

## 小结

《Linux 基础教程》中的 Shell 内容到这里为止。你已经有能力阅读简单脚本，也能把重复命令封装起来。

下一步请进入 [Shell 教材](/linux-shell/) 深入学习。等你再回来看 Linux 服务管理、日志分析和自动化任务时，会发现很多内容都串起来了。
