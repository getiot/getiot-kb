# Linux 基础教程

![Linux 基础教程](https://static.getiot.tech/cover-linux-tutorial.webp#center)

<!-- ![Linux 基础教程](https://static.getiot.tech/Linux-basic-tutorial.png#center) -->

欢迎进入神奇的 Linux 世界！在这里，我们将从零开始，学习 Linux 操作系统的基本概念和操作技能，为你打开计算机领域的新视野。

Linux 是一个强大而自由的操作系统，以其开源的本质和广泛的应用领域而闻名。它不仅用于服务器和工作站，还是嵌入式系统、移动设备等领域的首选。

通过学习本教程，你将了解 Linux 的设计哲学和基本使用方法，这些知识都非常重要，它会帮助你在 Linux 开源世界中走得更远，探索无限的可能。

## 你会学到什么

本教程面向 Linux 初学者，目标不是让你背下所有命令，而是帮你建立一条清晰的学习路径：

- 先准备一个安全的练习环境，理解终端、Shell 和命令提示符。
- 学会文件、目录、文本、搜索、管道、压缩归档等常用命令行操作。
- 理解 Linux 文件系统、用户、用户组和权限。
- 掌握软件包管理、环境变量和 Shell 配置文件。
- 学习进程、服务、定时任务、日志和时间同步。
- 入门 Linux 网络、SSH、文件传输和防火墙。
- 了解 Shell 脚本的基本概念，并知道什么时候继续阅读《Shell 教材》。
- 初步认识 `/proc`、`/sys`、`/dev`、udev、PAM、audit 等系统内部机制。
- 学会从权限、磁盘、服务、网络、日志等角度排查常见问题。

如果你是第一次接触 Linux，建议按照左侧目录顺序阅读，并在 `~/linux-practice` 目录中动手练习。遇到具体命令的详细参数，可以跳转到 [Linux 命令大全](/linux-command/) 继续查看。
