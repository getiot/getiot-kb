# Ubuntu 安装

本文将带你完成一次常见的 Ubuntu 桌面版安装：下载镜像、制作启动 U 盘、安装到电脑，以及装完后的第一批操作。

文中步骤以 **Ubuntu Desktop LTS**（如 22.04 / 24.04）为主。安装器界面会随版本微调，但整体流程相近。服务器版（Ubuntu Server）安装逻辑类似，只是默认不装桌面环境。

## 你需要准备什么

- 一台可以改启动项的电脑（台式机或笔记本）  
- 一只容量建议 ≥ 8 GB 的 U 盘（制作启动盘会清空 U 盘数据）  
- 稳定的网络（下载镜像、安装时可选联网）  
- 约 25 GB 以上可用磁盘空间（实际建议预留更多）  

:::warning 备份很重要
安装时若选择「清除整块磁盘并安装 Ubuntu」，目标盘上的原有系统与数据都会丢失。双系统或手动分区前，请先备份重要文件，并确认选对了磁盘。
:::

## 1. 选择版本并下载镜像

1. 打开官网下载页：https://ubuntu.com/download/desktop  
2. 优先选择 **LTS** 版本（长期支持，更适合日常与开发环境）  
3. 下载得到 `.iso` 文件  

版本与代号说明见站内 [Ubuntu 版本](/ubuntu/ubuntu-versions/)。

:::tip 校验镜像（推荐）
官网通常会提供校验和（如 SHA256）。下载后在已有系统上核对，可降低镜像损坏或被篡改的风险。具体校验命令因平台而异，以官网说明为准。
:::

## 2. 制作启动 U 盘

把 ISO 写入 U 盘，做成可启动安装介质。常用工具：

| 平台 | 常见工具 |
| --- | --- |
| Windows | [Rufus](https://rufus.ie/)、[balenaEtcher](https://etcher.balena.io/) |
| macOS / Linux | balenaEtcher，或命令行 `dd`（需小心设备名） |

要点：

- 选择正确的 U 盘设备，**写错盘会毁掉那块盘的数据**  
- 分区方案一般选 GPT + UEFI（较新电脑），老机器可能是 Legacy BIOS  
- 写入完成后安全弹出 U 盘  

## 3. 从 U 盘启动

1. 插入启动 U 盘，重启电脑  
2. 进入启动菜单或 BIOS/UEFI 设置（常见键：`F2` / `F10` / `F12` / `Del`，以主板说明为准）  
3. 选择 U 盘启动（若同时出现 USB HDD / UEFI USB，优先尝试 UEFI 项）  

若进不去安装界面，检查：Secure Boot、启动顺序、U 盘是否制作成功、接口是否为 USB 2.0/3.0 兼容问题等。

## 4. 安装过程中的关键选择

进入安装程序后，按向导完成即可。下面几项最容易踩坑：

### 语言、键盘与网络

- 选好语言和键盘布局  
- 有条件时连接网络，方便安装中下载更新与部分驱动（也可稍后更新）  

### 安装类型（分区）

常见选项含义（文案因版本略有差异）：

| 意图 | 做法 |
| --- | --- |
| 整机只装 Ubuntu | 清除磁盘并安装（确认目标盘无误） |
| 与 Windows 共存 | 选择「与其他系统共存」或手动分区，保留 Windows 分区 |
| 完全自己控制 | 手动分区（至少准备根分区 `/`；交换分区可用 swap 文件代替） |

双系统建议：

- 先装 Windows，再装 Ubuntu，引导管理通常更省事  
- 预留未分配空间给 Ubuntu  
- 装完后若进不了某个系统，再排查 GRUB / 启动项  

:::danger 选错磁盘
笔记本电脑常有系统盘 + 数据盘 / 外接盘。分区界面务必核对容量、型号，不要误清外接备份盘。
:::

### 用户与时区

设置用户名、计算机名、密码（或登录方式）。记住管理员密码，后续 `sudo` 会用到。

## 5. 首次进入系统

安装结束并重启后：

1. 拔出 U 盘，避免再次进入安装程序  
2. 登录桌面  
3. 打开终端，更新软件索引并升级（网络通畅时）：

```bash
sudo apt update
sudo apt upgrade
```

国内网络若官方源很慢，可先阅读 [Ubuntu 更换源](/ubuntu/ubuntu-change-apt-source/)。

## 6. 装完后建议马上做的事

1. **确认系统版本**

```bash
cat /etc/os-release
```

2. **了解软件从哪来**：见 [Ubuntu 软件源](/ubuntu/ubuntu-software-repositories/)  
3. **按需启用 Livepatch**（减少内核安全补丁导致的重启）：见 [Ubuntu Livepatch](/ubuntu/ubuntu-livepatch/)  
4. **安装常用工具**：见 [Ubuntu 应用软件](/ubuntu/ubuntu-software/)  

## 常见问题

| 现象 | 可能原因与处理 |
| --- | --- |
| 无法从 U 盘启动 | 启动项/Secure Boot/制作失败；换工具重写 U 盘 |
| 安装后只进 Windows | 调整 UEFI 启动顺序，或在 Ubuntu 下修复 GRUB |
| Wi-Fi / 独显异常 | 先有线联网更新；再查专有驱动（Additional Drivers） |
| 虚拟机安装 | 在 VirtualBox / VMware 中新建虚拟机并挂载 ISO，流程更简单，适合先练手 |

## 小结

安装 Ubuntu 的主线是：**下对 ISO → 写好启动盘 → 选对磁盘分区 → 装完先 update**。分区一步最需要谨慎；其余步骤跟着安装向导走即可。

下一篇可了解 [Ubuntu Livepatch](/ubuntu/ubuntu-livepatch/)，减少关键内核补丁带来的停机重启。
