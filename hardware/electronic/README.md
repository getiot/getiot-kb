# 电子技术入门教程：电路基础、工具与动手技巧

![电子技术入门](https://static.getiot.tech/cover-electronic-tutorial.webp#center)

欢迎来到电子技术入门。如果你曾觉得电路“又抽象又容易冒烟”，不妨先放松一点：你只要把**电压、电流、电阻**和**怎么安全搭电路、怎么用表测量**真正弄懂，就已经能点亮 LED、读取按键，并给单片机接上常用外围。

本教程面向创客与嵌入式初学者，不假设你有大学电路课程背景。我们会尽量用第二人称带你走完一条可动手的路：先建立直觉，再动手验证，最后学会排错。


## 你将学到什么

- 电学基础与简单计算（够用、能上手）  
- 原理图识读与面包板搭建  
- 常用电路积木：LED、按键、分压、二极管/三极管用法  
- 数字电平、GPIO 与 ADC 的直觉  
- 万用表、电源、示波器、信号发生器、逻辑分析仪等台面仪器  
- 焊台焊接、热风拆焊、钢网手贴入门与辅助工具  
- 排错清单与安全习惯  


## 和其他专栏如何分工

- 器件百科：请看 [电子器件基础教程](/electronic-components/)——偏“这个器件是什么、怎么选”  
- 传感器专题：请看 [传感器原理](/sensor/)——偏“各类传感器怎么用”  
- 本专栏：关注**电路怎么用、怎么测、怎么排错**  

三者可以交叉阅读：在本专栏学会分压与 ADC 后，再去传感器专栏接温湿度模块，会顺很多。


## 建议阅读顺序

1. 先完成「基础概念」与「识图与搭建」  
2. 动手做 LED 与按键，建立成功体验  
3. 工具篇可与实践穿插：有表再排错，事半功倍  
4. 工艺篇（焊接/热风）可在你开始打样或修板时再深入  
5. 需要外壳与结构件时，再去 [3D 打印教程](/3d-printing/)  

准备好了，就从 [什么是电路与电子系统](/circuit/what-is-circuit/) 开始吧。卡住时，也可以直接跳到 [常见故障排查清单](/circuit/troubleshooting-checklist/) 对照自查。
