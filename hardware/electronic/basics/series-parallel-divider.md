# 串联并联与分压电路：电阻网络入门

实际电路很少只有一颗电阻。你会看到电阻串联、并联，以及最常见的**分压器**。把这三种网络吃透，读原理图时会轻松很多。


## 串联：电流同一条路

串联时电流只有一条路径，总电阻是相加：

```bash
R_total = R1 + R2 + ...
```

同一串联支路里电流相同；电压则按电阻大小分配——电阻越大，分到的电压越多。


## 并联：电压相同，电流分流

并联时各支路电压相同，总电阻会**变小**。两个电阻并联：

```bash
R_total = (R1 × R2) / (R1 + R2)
```

直觉：并联等于给电流多开几条路，整体更“容易通过”，所以等效电阻下降。


## 分压器：你一定会用到的结构

最常见接法是两个电阻串在 VCC 与 GND 之间，从中间取出电压：

```bash
Vout = VCC × R2 / (R1 + R2)
```

（R1 在上方接 VCC，R2 在下方接地时。）

例如 VCC=5V，R1=R2=10kΩ，则中间约 2.5V。你可以用来：

- 把较高电压降到 ADC 可测范围（还要考虑精度与阻抗）  
- 配合电位器做可调电压  
- 理解某些传感器模块的分压输出  


## 怎么选分压电阻的“大小”

这是新手容易忽略的点：

- **太小**（比如几百欧硬分压）：空耗电流大，电阻可能发热  
- **太大**（比如数兆欧）：省电，但容易被噪声和后级输入阻抗拖偏  

接 MCU ADC 时，还要看 ADC 输入特性；必要时加缓冲或按手册选阻值范围。


## 和上拉/下拉的关系

上拉、下拉也是电阻网络，但目标不同：它们给数字输入一个**默认电平**，而不是精确中间电压。详见 [按键、上拉与下拉](/circuit/pull-up-pull-down/)。


## 建议你动手验证

在面包板上用两只 10kΩ 做分压，接 5V，用万用表测中点。然后把下面那只改成 4.7kΩ，再测一次，看看是否符合公式直觉。测的时候记得共地、并表。
