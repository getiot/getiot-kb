# 欧姆定律入门：V=IR 与限流电阻计算

欧姆定律看起来只是一行公式，但对入门者来说，它几乎是“能自己算限流电阻”的分水岭。你可以先把它记成：

```bash
V = I × R
I = V / R
R = V / I
```

在理想电阻上，电压与电流成正比。电压一定时：电阻越大，电流越小。


## 你怎么在脑子里用它

遇到实际问题，按这个顺序想：

1. 我已知哪些量？想求哪个量？  
2. 单位统一了吗？（V、A、Ω）  
3. 这个元件能不能近似当电阻？（LED 往往不能全程当线性电阻）  


## 经典例子：给 LED 算限流电阻

假设你手上是：

- 电源 5V  
- LED 正向压降约 2V（以器件手册/实测为准，颜色不同会差很多）  
- 希望电流大约 10mA = 0.01A  

那么电阻两端大约分到：

```bash
V_R = 5V - 2V = 3V
R = V_R / I = 3 / 0.01 = 300Ω
```

标准阻值里你可以选 330Ω。再估功率：

```bash
P = I² × R ≈ 0.01² × 330 ≈ 0.033W
```

1/4W 电阻通常足够。完整搭法与排错见 [LED 限流与指示灯电路](/circuit/led-current-limiting/)。


## 为什么不能“5V 直接怼 LED”

因为 LED 导通后电压不会像电阻那样线性上升，电流可能迅速飙高，几秒钟就能热坏。限流电阻就是在给电流设上限。你可以记住：

> 对 LED：先限流，再谈亮不亮好看。


## 常见误区

- **把 LED 当纯电阻去套完整欧姆定律**：导通后要按“压降 + 限流电阻”模型来估。  
- **只算阻值不算功率**：大电流时电阻会烫。  
- **单位混乱**：用 mA 却当 A 代入，结果会差 1000 倍。  


## 小练习

电源 3.3V，LED 压降约 2.0V，想要约 5mA，限流电阻大约是多少？

```bash
R ≈ (3.3 - 2.0) / 0.005 = 260Ω
```

可选 270Ω 或 330Ω，然后上电用万用表测电阻两端电压，反推实际电流，和你的目标对比一下。
