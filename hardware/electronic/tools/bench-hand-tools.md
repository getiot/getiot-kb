# 电子制作常用辅助工具：剪钳吸锡放大镜与台面装备

仪器负责“看到”和“激励”，辅助工具负责让动手过程更稳、更干净。很多人仪器买得很齐，却缺少一把好用的镊子和斜口钳，结果效率反而低。你可以按下面清单逐步配齐。


## 机械类

| 工具 | 你可以用它做什么 |
| --- | --- |
| 斜口钳 / 剪线钳 | 剪元件脚、修线头 |
| 剥线钳 | 剥杜邦线/排线绝缘皮 |
| 镊子（尖头/弯头） | 夹贴片电阻电容 |
| 第三手 / 小台钳 | 固定 PCB |
| 零件盒 | 按阻值/封装分类，减少翻找 |


## 焊接耗材

| 物品 | 作用 |
| --- | --- |
| 助焊剂 | 改善润湿，减少虚焊 |
| 吸锡带 / 吸锡器 | 清除多余焊锡 |
| 酒精与刷子 | 清洁残留（按工艺选择） |
| 热缩管 | 绝缘与线缆收尾 |


## 观察类

- 台式/头戴放大镜：看桥连与虚焊  
- 电子显微镜（可选）：检查贴片与方向标记  
- 强光手电：斜打光看焊点表面状态  


## 安全与静电

- 防静电腕带与垫（处理敏感 IC 时）  
- 排烟风扇或保持通风  
- 烙铁架与高温警示  


## 采购建议（务实版）

第一阶段先保证：

1. 好用的斜口钳 + 镊子  
2. 吸锡带 + 助焊剂  
3. 放大镜  
4. 一台 [恒温焊台](/circuit/soldering-esd/)  

等你开始频繁修板，再上热风枪与显微镜；钢网手贴见 [热风枪拆焊与钢网手贴](/circuit/hot-air-rework/)。

如果你还要做外壳、支架、治具，桌面 3D 打印很有用，但那是另一条主线——请看本站 [3D 打印教程](/3d-printing/)，本专栏不展开切片与机型细节。

工艺练会后，排错会更从容。下一章建议阅读：[常见故障排查清单](/circuit/troubleshooting-checklist/)。
