# 可调电源与限流：安全给试验电路供电

台式可调直流电源能让你设定电压，并用**电流限制**保护电路。对创客来说，它比“随便找个大电流适配器直接怼”安全得多：接错时常常先进入限流，而不是先冒烟。你可以把限流想象成电源的“安全带”——平时几乎感觉不到，出事时能给你几秒冷静时间。


## 你为什么需要限流

面包板试验难免接错：杜邦线插歪、电解电容反接、电源与地短接。如果电源能无限输出大电流，短路瞬间可能烧掉芯片、排线甚至电源本身。限流后，短路更像“输出电压被拉低、电流顶在上限”，面板上的电流表会顶满，电压可能掉得很厉害——这正是你该立刻关掉输出、去查接线的信号。


## 基本操作建议

1. **输出关闭**时，设置目标电压（如 5.00V）  
2. 设置电流上限（逻辑电路试验可先从 100–200mA 起步，按负载再调整）  
3. 接好电路并确认极性、共地  
4. 打开输出，观察是否立刻撞到电流上限  

若一开输出就顶流，别继续硬顶：先关输出，用通断档查短路。


## 使用中的好习惯

- 先接线、再输出；先关输出、再改线  
- 红正黑负，别反接（除非你在做有防反接保护的专门试验）  
- 电机等大电流负载把限额调合理，并注意电源功率与线径  
- 锂电充电请用专用充电管理，不要把可调电源当“随手充电器”  
- 两路电源同时用时，想清楚是否共地、谁给谁供电（详见 [电源与共地](/circuit/power-and-ground/)）  


## 和模块供电的关系

很多开发板可以用 USB 供电。可调电源更适合：

- 单独验证电源模块（LDO、DC-DC）  
- 给电机/灯带等提供受控功率  
- 复现“电压跌落”类问题（配合限流与万用表/示波器测量）  

USB 口有时“看起来有 5V”，但瞬时电流不够；可调电源能帮你分清是电路问题还是供电能力问题。
