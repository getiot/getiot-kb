# 逻辑分析仪入门：抓取数字波形与协议解码

逻辑分析仪专门观察数字线的高低变化。它不追求模拟细节，而擅长多通道、较长时间抓取，并对 UART、I2C、SPI 等做协议解码——这正是你调传感器与 MCU 通信时最痛的点。


## 什么时候用它，而不是示波器

| 你的需求 | 更合适的工具 |
| --- | --- |
| 看噪声、上升沿、模拟畸变 | [示波器](/circuit/oscilloscope-basics/) |
| 同时看很多根数字线、解码协议 | 逻辑分析仪 |
| 两者都要 | 混合信号示波器或两台配合 |


## 关键概念

- **通道数**：8/16 很常见  
- **采样率**：要明显高于信号翻转速度，否则解码会鬼畜  
- **门限电压**：按 1.8V/3.3V/5V 逻辑设置  
- **触发条件**：某根线边沿，或特定协议事件  


## 典型工作流

1. 共地，把探针接到 SCL/SDA 或 TX/RX 或 SPI 四线  
2. 设置门限与采样率  
3. 操作板子触发一次通信（上电、读传感器、按键）  
4. 用解码功能查看地址、数据、ACK/NACK  

当你第一次在解码里看到传感器地址和数据字节时，调试效率通常会跃升一个台阶。


## 入门设备怎么选

低成本 USB 逻辑分析仪配合开源上位机，足够学 I2C/SPI/UART。专业机会更深、更稳，价格也更高。先把“会抓、会解码、会对照代码”练会，比先买旗舰重要。


## 注意

- 确认分析仪输入耐压，避免 5V 总线硬戳只能耐 3.3V 的输入  
- 线尽量短；排线乱飞时高速边沿会很难看  
- 解码不对时，先怀疑采样率、地线与门限，而不是先怀疑芯片坏了  

MCU 日志与烧录见 [USB 转串口与调试器](/circuit/usb-serial-debugger/)。
