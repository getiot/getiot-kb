# 万用表入门：测电压电流电阻的正确方法

万用表是电子学习的“眼睛”。你可以先不追求买最贵的型号，但一定要把**测电压、测通断、测电阻**练熟；电流档稍后再上，因为它最容易用错。


## 认识表笔与孔位

- `COM`：黑表笔，公共端  
- `V/Ω`：红表笔测电压、电阻、通断  
- `mA` / `10A`：测电流时红表笔要改插（不同表布局略有差异）  

测完电流后，请立刻把红表笔插回电压孔——这是保护你下一块板子的好习惯。


## 测电压：并表

1. 选择直流电压档，量程大于被测值（不确定就先大量程）  
2. 黑笔接 GND，红笔接点位  
3. 读数；若显示不稳定，检查接触与档位  

你可以测：电池电压、面包板电源轨、稳压模块输出、分压中点。


## 测电阻 / 通断：断电测

- 测量电阻时尽量让元件脱离电路，或至少断电  
- 通断档蜂鸣：检查导线、焊点、保险丝、杜邦线是否内部断芯  

带电打电阻档硬测，可能得到乱读数，也有损坏仪表的风险。


## 测电流：串表（易错）

1. 红笔改到电流孔  
2. 选合适电流档  
3. **断开原回路，把表串进去**  
4. 测完改回电压档  

:::warning

用电流档的表笔直接去戳电源正负极，约等于短路，可能烧保险甚至更糟。请只在你明确“串进回路”时使用电流档。

:::


## 建议练习路径

1. 测一节电池电压  
2. 测 LED 限流电阻两端电压，反推电流  
3. 用通断档检查杜邦线  
4. 在教师/有经验者指导下练一次小电流测量  

有了表，再配合 [可调电源](/circuit/bench-power-supply/) 做限流试验会安心很多。需要看波形时，进入 [示波器](/circuit/oscilloscope-basics/)。
