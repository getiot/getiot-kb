# 信号发生器入门：正弦方波与测试激励

信号发生器（函数发生器 / 任意波形发生器）能产生**已知的测试波形**，当作电路输入。你可以把它和示波器组成最小“激励—观察”闭环：发生器喂信号，示波器看结果。对滤波、放大、比较器这类电路，这比“干等传感器碰巧出信号”高效得多。


## 常见波形与用途

| 波形 | 你可以用它做什么 |
| --- | --- |
| 正弦波 | 粗测放大器/滤波电路是否变形 |
| 方波 / 脉冲 | 当简易时钟，看数字电路响应 |
| 三角波 / 锯齿波 | 观察非线性、做简单扫频直觉实验 |
| 噪声（部分机型） | 粗看抗扰表现 |


## 关键参数：你要会调这几个

- **频率**：变化有多快  
- **幅度**：输出摆幅多大（注意后级耐压）  
- **直流偏置**：波形整体上移/下移多少  
- **占空比**：方波高电平占比  
- **输出阻抗**：常见 50Ω；接到不同负载时幅度显示要按说明书理解  

偏置特别容易被忽略：你以为输出了“0～3.3V 方波”，结果实际带了负半周，可能直接损伤输入脚。接电路前先用示波器确认一次。


## 推荐工作流

1. 先用示波器只看发生器输出，确认频率与幅度符合预期  
2. 共地后，再接到被测电路输入  
3. 示波器同时观察输入与输出，对比幅度、相位、失真  
4. 改一个参数（比如频率），观察输出如何变化，并记录  


## 注意

- 先小幅度，再慢慢加大  
- 输出端误接到电源或长时间短路可能损坏仪器（视保护设计而定）  
- USB 口袋发生器方便，台式机通常更稳、界面更完整  
- 不要把发生器输出直接接到电源轨或大功率负载，除非你明确知道自己在做什么  

数字总线更适合交给 [逻辑分析仪](/circuit/logic-analyzer/)。元件参数筛选见 [LCR 表](/circuit/lcr-meter/)。
