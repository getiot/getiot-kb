# 电子原理图入门：常用符号与读图方法

原理图（schematic）不是美术图，它用符号告诉你：**哪些引脚在电气上连在一起**。你会读图，才能对照面包板、洞洞板或 PCB，也才能看懂别人的开源硬件项目。


## 先把最常见的符号认熟

| 含义 | 读图时你要抓住什么 |
| --- | --- |
| VCC / 3V3 / 5V | 电源网络；同名通常表示相连 |
| GND | 参考地；同名相连 |
| 电阻 R | 看阻值标注，如 10k、4.7k |
| 电容 C | 注意有无极性；去耦电容常靠近芯片 |
| 二极管 / LED | 方向（三角形指向）决定极性 |
| 开关 / 按键 | 默认是通还是断 |
| 连接器 / 排针 | 核对引脚编号，别镜面反了 |

更细的元件说明在 [电子器件基础](/electronic-components/)。本篇目标是：你打开一张图，不至于完全迷路。


## 推荐读图顺序

你可以按这个流程读任何一张入门原理图：

1. **找电源与地**：系统用的是 5V 还是 3.3V？有几路电源？  
2. **找主芯片/模块**：MCU、稳压、USB 转串口在哪？  
3. **追网络名**：例如 `KEY1` 从按键经过电阻到哪个引脚？  
4. **看去耦与保护**：电源脚旁有没有 0.1µF？输入有没有防反接二极管？  

读图不是一次盯完全部线条，而是像查地图：先主干，再支路。


## 网络名：原理图的“超能力”

原理图里经常出现同名标签（如 `SDA`、`LED_RUN`）。它们表示电气相连，即使中间没有把线画在一起。复杂图几乎全靠网络名组织，所以你看到同名，就要想到“它们是一根网”。


## 原理图 vs 实物图

- 原理图：强调连接关系  
- 实物/PCB：强调位置、封装、走线长短  

初学时不要要求原理图像照片一样摆放元件。你会渐渐习惯：图上的“远”不等于板上的“远”。


## 建议练习

找一张最简单的 LED + 限流电阻原理图（可以自己画），用手指点着念：

> 电流从 5V 出来，经过 330Ω，进入 LED 正极，再从负极回到 GND。

念得顺，说明你真的读懂了。下一篇把它落到手上：[面包板与杜邦线](/circuit/breadboard-jumper/)。
