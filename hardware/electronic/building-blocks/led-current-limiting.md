# LED 限流与指示灯电路：计算电阻并搭通

很多人对电子的兴趣，是从“点亮第一颗 LED”开始的。你可以把它当作第一个完整闭环：电源、限流、负载、地，一个都不能少。


## 电路怎么接

最常见结构是：

```bash
VCC → 电阻 R → LED 正极（长脚常见为正） → LED 负极 → GND
```

电阻放在 LED 阴极侧也可以，关键是**与 LED 串联限流**。LED 器件细节见 [发光二极管](/electronic-components/leds/)。


## 电阻怎么估

```bash
R ≈ (VCC - Vf) / I
```

- `Vf`：LED 正向压降（红光常约 1.8–2.2V，蓝/白更高，以实测或手册为准）  
- `I`：目标电流（指示灯常用 5–15mA）  

例如 5V 电源、Vf≈2V、I≈10mA，则 R≈300Ω，可选 330Ω。然后再估功率，确认不会烫坏电阻。计算细节复习 [欧姆定律](/circuit/ohms-law/)。


## 建议你这样验证

1. 按图搭好，先不接 MCU，用电源直接供电  
2. LED 应稳定发光，灯珠与电阻都不明显发烫  
3. 用万用表测电阻两端电压，反推电流是否接近目标  
4. 再改接到 GPIO 输出（记得 GPIO 电流能力有限）  


## 常见失败对照表

| 现象 | 你可以先查什么 |
| --- | --- |
| 完全不亮 | 极性反了、没共地、虚接、电阻过大、电源没开 |
| 很亮且发烫 | 限流电阻被短接或阻值太小 |
| 亮一下就灭 | 电源保护、接触不良、电池内阻太大 |
| 一端亮一端不亮（多颗） | 某路限流或地线断开 |


## 小提示

- 面包板上 LED 脚很容易插反，插之前认清长脚/扁边  
- 不要用 GPIO 直接硬推大功率 LED，必要时加三极管/MOSFET  
- 成功后，把阻值写在原理图旁边，形成你的“个人零件库”
