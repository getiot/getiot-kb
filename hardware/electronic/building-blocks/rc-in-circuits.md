# 电阻电容在电路中的角色：滤波与时间常数直觉

电阻限制电流，电容储存电荷。二者合在一起（RC），在入门阶段你最常遇到的不是复杂滤波器设计，而是两件事：

1. 芯片电源脚旁的**去耦电容**  
2. 简单的**延时 / 消抖 / 平滑**直觉  


## 时间常数：先建立感觉

```bash
τ = R × C
```

你可以先记住：电阻越大或电容越大，电压变化往往越慢。精确计算可以后补；先有“快慢”的直觉，读图时就不会懵。


## 电源去耦：本地小水库

芯片在翻转 GPIO、跑射频或突发运算时，电流会突然变化。电源线又有电感，远程电源来不及瞬间响应，电压就可能掉一下，表现为复位、通信错误或莫名其妙的毛病。

解决办法之一，就是在电源脚与地之间就近放电容（常见 0.1µF 陶瓷，有时再并联更大电解/钽电容）：

> 让芯片“伸手就能摸到”临时电荷。

布置要点是**靠近、回路短**，而不是只在原理图角落随手画一个。


## 你还会在这些地方看到 RC

- 简单上电复位/延时（粗略）  
- 按键消抖（需计算与试验）  
- 模拟输入前的小滤波（抑制毛刺）  

电容种类与选型见 [电容](/electronic-components/capacitors/)；电阻见 [电阻](/electronic-components/resistors/)。本专栏只要求你看懂：它在电路里扮演什么角色。


## 动手观察（可选）

如果你有示波器，可以对比：MCU 电源脚“有去耦”和“故意拿掉去耦”（在可牺牲的试验板上）时的纹波差异。没有示波器也没关系，先把“靠近芯片放电容”养成习惯。
