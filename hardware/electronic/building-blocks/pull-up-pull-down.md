# 按键上拉下拉电阻：稳定 GPIO 输入电平

MCU 输入引脚如果悬空，电平可能随干扰乱跳，看起来像“自己按下了按键”。上拉/下拉电阻的作用，就是给引脚一个**默认的、确定的电平**。


## 先记住结论

- **上拉**：默认拉到高电平  
- **下拉**：默认拉到低电平  
- 按键动作则把电平拉到另一侧  


## 最常见：上拉 + 按键接地

```bash
VCC → 电阻（如 10k）→ MCU 引脚
                └─ 按键 ─→ GND
```

- 未按下：引脚被电阻拉到高  
- 按下：引脚被接到地，读到低  

很多芯片内部已有弱上拉，但外部再加 4.7k–10k 往往更稳妥，尤其是长线或干扰环境。


## 下拉怎么用

默认低，按下接到 VCC 变高。原理对称。你选上拉还是下拉，常取决于原理图习惯与芯片复位/启动要求——以手册为准。


## 机械抖动：你按一下，电信号可能抖很多次

按键金属触点闭合时会抖动。软件里常见做法是延时消抖；硬件上也可以加简单 RC。入门阶段，你可以先保证：

1. 默认电平明确（有上下拉）  
2. 按下时电平干净到地或到电源  
3. 软件不要在中断里做过于敏感的边沿计数（先轮询+消抖也行）  


## 和分压器别混淆

分压器追求某个中间模拟电压；上拉/下拉追求数字输入的默认态。两者都用电阻，目标不同。分压复习见 [串并联与分压](/circuit/series-parallel-divider/)。


## 建议实验

把按键接到 MCU 输入，串口打印电平。然后故意拿掉上拉电阻，观察是否出现随机跳变——你会立刻理解“为什么要上拉”。
