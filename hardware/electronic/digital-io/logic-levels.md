# 高低电平与逻辑门槛：3.3V/5V 系统入门

数字电路并不用“任意电压”表达信息，而是用两档范围表示逻辑 1/0。你把这块直觉建立起来，后面接 3.3V/5V 模块时会少烧很多引脚。


## 门槛：不是越高越好那么简单

对某一种逻辑电平标准而言，通常有：

- 高于 VIH：可靠视为高电平  
- 低于 VIL：可靠视为低电平  
- 中间区域：不确定，可能误判或抖动  

具体数值请看芯片数据手册。你可以用万用表看静态电平是否“够高/够低”；动态边沿则更适合示波器。


## 3.3V 与 5V：创客最常见的混接问题

很多 USB-串口、老模块是 5V 逻辑，现代 MCU 常是 3.3V：

- **5V 输出直接进 3.3V 引脚**：有损坏风险  
- **3.3V 输出进 5V 输入**：有的芯片认作高，有的不够，必须查手册  

常用处理思路：

1. 用电平转换芯片（更稳妥）  
2. 开漏输出 + 上拉到目标电平（适合部分总线）  
3. 电阻分压（权宜之计，速度与阈值要评估）  


## 你怎么自查

1. 先确认两边标称电压域  
2. 上电前别急着互连数据脚  
3. 用万用表看空闲电平是否符合预期  
4. 通信异常时，用 [示波器](/circuit/oscilloscope-basics/) 或 [逻辑分析仪](/circuit/logic-analyzer/) 看边沿与协议  


## 小结

高低电平是约定，不是“有电压就行”。混接前先问一句：这根线的电压，对方引脚扛得住吗？
