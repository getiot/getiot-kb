# 电子技术下一步学习路径：器件传感器MCU与PCB

如果你已经能点亮 LED、读按键、用万用表排错，说明你具备继续往下走的基础。接下来不必“全都学”，按目标选一条主线即可。


## 想把元件认全

→ [电子器件基础教程](/electronic-components/)  

系统看电阻电容、二极管三极管、继电器、连接器等。你会把“会用”升级成“会选”。


## 想接传感器做物联网

→ [传感器原理](/sensor/)  

建议从 [传感器概论](/sensor/sensor-overview/) 开始，再选温湿度、IMU、水质等专题。遇到分压、GPIO、ADC 不懂时，随时回本专栏复习。


## 想让 MCU 真正跑起来

结合本站单片机/嵌入式相关教程（STM32、Arduino、ESP32 等，按你的板子选）：

- GPIO / UART / I2C / SPI  
- 中断与定时器  
- 低功耗与电源管理  

调试时善用 [USB 转串口与调试器](/circuit/usb-serial-debugger/) 和 [逻辑分析仪](/circuit/logic-analyzer/)。


## 想做成产品形态

- 原理图规范与器件选型  
- PCB 封装、走线、EMI 入门  
- 结构、认证与可制造性（DFM）  
- 小批量贴片：把钢网/贴片交给 SMT 代工；台面热风手贴见 [热风枪拆焊与钢网手贴](/circuit/hot-air-rework/)，不必自己上贴片机  


## 想做外壳、工装与结构件

桌面 3D 打印机很适合出外壳、支架、治具，但它是另一条数字制造主线，本专栏不展开参数与切片。

→ [3D 打印教程](/3d-printing/)


## 学习方法建议

保持“小项目驱动”：每个项目只新增一个陌生点。例如本周只攻 I2C，下周再加屏幕。进度会慢一点，但更扎实。
