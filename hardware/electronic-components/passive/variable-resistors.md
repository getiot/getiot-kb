# 可变电阻与电位器：分压调节原理与用法

在搭建电子电路的过程中，你有时可能希望调整某个参数，比如改变音量、亮度、灵敏度，甚至调节电机速度。这时，可变电阻（Variable Resistor）就是你离不开的“调节器”。在本节中，你将了解可变电阻的基本结构、工作原理、常见类型、应用场景以及如何识别与使用它。无论是手动旋转、滑动，还是由电压控制的变化，这些元件都能让你的电路更灵活、更智能。



## 可变电阻的作用

可变电阻是一种阻值可以手动或自动调节的电阻元件。你可以用它来：

- 调节电压或电流大小
- 实现音量、电平、速度等连续变化的控制
- 设置传感器的参考电压或工作点
- 替代多个固定电阻，实现灵活调试
- 构建调节范围可变的分压器或滤波器



## 工作原理

可变电阻的基本结构包括一个电阻体和一个可移动的触点（称为滑片）。当你旋转或滑动它时，滑片在电阻体上移动，改变了两个端点之间的电阻值。

### 三引脚可变电阻（电位器）

这类元件有三个引脚：两个固定端接在整个电阻体两端，中间的滑动端可以在电阻体上移动。你可以将它看作两个电阻串联，中间点可调。例如：

```markdown
  A ----/\/\/\/----+----/\/\/\/---- B
                   |
                   C（滑动端）
```

- A 到 C 是一个可变电阻
- C 到 B 是另一个可变电阻
- A 到 B 是总电阻（固定）
- 改变滑片位置，相当于改变两端阻值的比例

### 两引脚可变电阻

如果你只使用一个固定端和滑动端，那它的阻值范围就从 0Ω 到最大阻值。它就像一个普通电阻，只不过你可以调节它的阻值。



## 可变电阻的类型

### 按操作方式分类

- **旋转式电位器**：最常见，你通过旋转旋钮调节阻值
- **滑动式电位器**：通过滑块前后滑动调节阻值，常见于音响设备
- **数字电位器（数控电阻）**：由 MCU 控制，阻值可通过程序调节
- **多圈电位器**：旋转数圈实现精细调节，适合精密应用
- **带开关的电位器**：一边旋转一边可控制电源开关，常见于老式收音机

### 按材质分类

- **碳膜电位器**：成本低、常见，适用于普通场合
- **线绕电位器**：精度高、功率大，适合精密调节或高功率环境
- **导电塑料电位器**：稳定性高、寿命长，适用于工业设备



## 常见规格与型号

可变电阻也有常见阻值（如 1kΩ、10kΩ、100kΩ 等）和不同的外形封装：

- 常见封装如 WH148（旋转式，塑料壳）、Bourns 多圈精密电位器
- 常见贴片型有 SMD 数字电位器（如 MCP41010）
- 阻值变化曲线分为线性（B 类）和指数（A 类），常见标注如 B10K 表示线性 10kΩ

:::tip 小贴士

A/B/C 标注在不同国家可能不一样，有些厂商用 A 表示线性，使用前最好查规格书确认。

:::



## 典型应用场景

1. **音量调节**

   最常见的用途就是控制音响设备的音量旋钮，调节输入电平。

2. **亮度调节**

   在 LED 灯电路中使用电位器可以调节亮度（配合 PWM 控制更精确）。

3. **电机调速**

   通过调节电压或设置参考电压，控制直流电机的转速。

4. **传感器校准**

   对一些模拟传感器（如光敏、热敏元件），你可以用电位器设定阈值或基准电压。

5. **微调和精密设定**

   在运算放大器或电压比较器电路中，使用多圈电位器进行微调。
