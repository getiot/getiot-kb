# 变压器基础：变压、隔离与线圈比

在本节中，你将认识一种在电力系统、电源设计和电子设备中非常重要的器件——**变压器（Transformer）**。无论是手机充电器、开关电源还是工业电气控制系统，变压器都扮演着至关重要的角色。它能改变电压、实现隔离，还能进行能量传输，是电子世界中的“大力士”。



## 变压器的作用

变压器的主要作用包括：

1. **变换电压**：升压或降压，比如将220V交流电变为5V、12V等低压电；
2. **电气隔离**：将不同电气系统隔离开，提高安全性；
3. **阻抗匹配**：在一些音频、通信电路中，用于优化信号传输；
4. **能量传输**：在无线充电、谐振电源中进行非接触式能量传输。



## 工作原理

变压器的工作基于**电磁感应**。简单来说，它由两个或多个绕组线圈组成，缠绕在一个共同的磁芯上：

- **原边线圈（Primary Coil）**：连接输入电压；
- **副边线圈（Secondary Coil）**：输出变换后的电压；
- **磁芯**：一般用铁芯或铁氧体，用于增强磁通量。

当你给原边加上交流电时，交流电产生交变磁场，磁场通过磁芯传递到副边，副边感应出电压。电压大小由绕组匝数比决定：

> **副边电压 / 原边电压 = 副边匝数 / 原边匝数**

这就是“变压”本身的由来。

:::tip

变压器只能工作在 **交流电**（AC）条件下，直流电不能感应磁场变化，因此不会产生输出电压。

:::



## 变压器的分类

变压器种类很多，按用途和结构可以分为：

#### 按功能分类

- **电力变压器**：用于输电系统，电压高达几千伏；
- **电源变压器**：你在电源适配器里经常见到；
- **隔离变压器**：只用于电气隔离，原副边匝数相同；
- **脉冲变压器**：用于脉冲信号传输；
- **高频变压器**：工作频率高于20kHz，广泛用于开关电源。

#### 按结构分类

- **铁芯变压器**：常用于低频、大功率场合；
- **环形变压器**：效率高、噪音低，常见于音响设备；
- **E型、EI型变压器**：适合传统电源应用；
- **高频小型变压器**：用于电源模块、电池充电器中。



## 常见型号和参数

| 型号        | 类型           | 应用                 |
| ----------- | -------------- | -------------------- |
| EI-16/19/28 | 小型电源变压器 | AC→AC、降压整流      |
| EE10/EE16   | 高频变压器     | 开关电源、DC-DC 模块 |
| RM、PQ、ETD | 高频、磁性结构 | 通信电源、工业控制   |
| 环形变压器  | 低频线性电源   | 音响、精密设备       |

主要参数包括：

- **额定输入/输出电压**
- **输出功率（VA）**
- **绝缘等级**
- **工作频率（Hz）**
- **漏感、磁通密度、效率等**



## 典型应用场景

1. **线性电源**

   老式的电源适配器中，经常能看到大块黑色变压器，先把220V降到12V，再整流为直流。

2. **开关电源**

   现代手机充电器、LED 驱动电源几乎都用高频变压器，体积小、效率高。

3. **音频设备**

   环形变压器在高端功放中被广泛使用，提供稳定电源，降低噪声。

4. **工业与医疗隔离**

   使用隔离变压器，确保操作人员安全，保护设备避免感应干扰。



## 使用注意事项

- 变压器不能直接用于直流电；
- 使用时要确认输入输出电压与功率；
- 高频变压器绕制工艺复杂，不能随便替换；
- 原副边之间要有足够的绝缘安全距离；
- 选型要考虑发热、磁饱和、EMI 辐射等因素。



## 简单实验建议

如果你想亲手体验变压器的作用，可以尝试使用一个小型 EI 型变压器，接市电（注意安全！）和一组整流二极管、电容，组成一个简单的线性电源，观察电压变化。

:::warning

涉及220V交流电实验时请格外注意安全！不建议新手单独操作。

:::



## 小结

通过这一节，你了解了变压器的基本工作原理、常见类型、实际应用和使用注意事项。变压器在电子设备中无处不在，是电能“搬运工”和“电气隔离员”。未来当你设计电源、电机驱动或工业控制系统时，它会成为你可靠的好伙伴。
