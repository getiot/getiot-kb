# 电子器件名词解释：常用术语速查

- **电阻器**（Resistor）：限制电流或分压的被动元件，单位欧姆（Ω），用于电流控制和电压分配。
- **电容器**（Capacitor）：存储电荷的元件，单位法拉（F），用于滤波、耦合或储能。
- **电感器**（Inductor）：存储磁能的元件，单位亨利（H），用于滤波或振荡电路。
- **二极管**（Diode）：具有单向导电性的半导体元件，用于整流、限幅和开关（信号隔离）。
- **光电二极管**（Photodiode）：将光信号转换为电信号的元件，用于光检测和测量。
- **发光二极管**（LED）：通电发光的二极管，常用于指示灯或显示屏。
- **有机发光二极管**（OLED）：自发光显示技术，无需背光。
- **液晶显示器**（LCD）：利用液晶分子偏转控制显示的平面屏幕。
- **三极管**（Transistor）：又称晶体管，具有放大和开关功能，分双极型（BJT）和场效应型（FET）。
- **场效应管**（MOSFET）：电压控制型晶体管，用于高频或大功率开关电路。
- **晶闸管**（Thyristor）：半控型半导体开关，用于交流调压或电机控制。
- **集成电路**（Integrated Circuit，IC）：将多个电路集成到芯片中，分模拟 IC、数字 IC 和混合信号 IC。
- **运算放大器**（Op-Amp）：高增益差分放大器，用于信号调理或数学运算。
- **变压器**（Transformer）：用于改变电压和电流大小的元件，基于电磁感应原理。
- **保险丝**（Fuse）：过流保护元件，熔断后切断电路。
- **继电器**（Relay）：通过电信号控制机械开关的元件，用于远程控制和电路隔离。
- **电位器**（Potentiometer）：可变电阻，用于调整电路中的电阻值，常见于音量控制和传感器。
- **热敏电阻**（Thermistor）：电阻值随温度变化的元件，用于温度测量和补偿。
- **光敏电阻**（LDR）：电阻值随光照强度变化的元件，用于光检测。
- **压敏电阻**（Varistor）：电阻值随电压变化的元件，用于过电压保护。
- **磁敏电阻**（Magnetoresistor）：电阻值随磁场强度变化的元件，用于磁场检测。
- **晶振**（Crystal Oscillator）：利用石英晶体的压电效应产生稳定振荡信号的元件，用于时钟电路。
- **蜂鸣器**（Buzzer）：发声元件，分有源（自带振荡）和无源（需外部驱动）。
- **霍尔效应传感器**（Hall Sensor）：检测磁场变化的传感器，用于位置或速度测量。
- **温度传感器**（Thermocouple）：热电偶（又称温差电偶），用于测量温度的传感器，基于热电效应。
- **湿度传感器**（Hygrometer）：用于测量湿度的传感器，基于电容或电阻变化。
- **压力传感器**（Pressure Sensor）：用于测量压力的传感器，基于电容或电阻变化。
- **加速度传感器**（Accelerometer）：用于测量加速度的传感器，基于电容或电阻变化。
- **陀螺仪**（Gyroscope）：用于测量角速度的传感器，基于光学或机械原理。
- **光电耦合器**（Optocoupler）：通过光信号隔离输入与输出的器件。
- **整流桥**（Bridge Rectifier）：由四个二极管组成的全波整流电路。
- **稳压器**（Voltage Regulator）：稳定输出电压的器件，如 LM7805（线性稳压）、LM2596（开关稳压）。
- **电桥**（Wheatstone Bridge）：用于测量电阻的电路结构，由四个电阻组成。
- **MOSFET**（Metal-Oxide-Semiconductor Field-Effect Transistor）：一种场效应晶体管，用于开关和放大。
- **IGBT**（Insulated-Gate Bipolar Transistor，绝缘栅双极型晶体管）：一种复合型半导体器件，结合了 MOSFET 与 BJT 优点的高压开关器件。
- **晶闸管**（Thyristor）：一种半导体器件，具有单向导电性和可控开关特性，用于电力电子。
- **可控硅**（SCR）：一种晶闸管，用于可控整流和开关。
- **肖特基二极管**（Schottky Diode）：低正向压降二极管，用于高频整流。
- **齐纳二极管**（Zener Diode）：反向击穿稳压二极管，用于电压基准或保护。
- **瞬态电压抑制二极管**（TVS Diode）：快速响应过压保护的半导体器件。
- **排针**（Header Pin）：用于电路板间连接的引脚阵列。
- **排母**（Header Socket）：与排针配套使用的插座。
- **接线端子**（Terminal Block）：方便导线连接的模块化接口。
- **按钮开关**（Push Button）：手动触发通断的瞬时开关。
- **滑动开关**（Slide Switch）：通过滑动切换电路通断的机械开关。
- **薄膜电容**（Film Capacitor）：介质为塑料薄膜，高频特性好。
- **电解电容**（Electrolytic Capacitor）：极性电容，容量大，用于低频滤波。
- **陶瓷电容**（Ceramic Capacitor）：非极性电容，高频性能优异。
- **超级电容**（Supercapacitor）：高容量电容，介于电池与传统电容之间。
- **光耦继电器**（Photo Relay）：通过光信号控制通断的无触点继电器。
- **EEPROM**（Electrically Erasable Programmable Read-Only Memory）：可电擦除的可编程只读存储器，支持数据反复写入。
- **SRAM**（Static Random Access Memory）：静态随机存取存储器，用于高速缓存和临时存储。
- **DRAM**（Dynamic Random Access Memory）：动态随机存取存储器，用于计算机内存。
- **SDRAM**（Synchronous Dynamic Random Access Memory）：同步动态随机存取存储器，用于计算机内存。
- **DDR SDRAM**（Double Data Rate Synchronous Dynamic Random Access Memory）：双倍数据速率同步动态随机存取存储器，用于计算机内存。
- **Flash Memory**（闪存）：非易失性存储器，用于存储数据和程序。
- **NOR Flash**：一种闪存技术，支持随机访问和快速读取。
- **NAND Flash**：一种闪存技术，支持块擦除和快速写入。
- **MCU**（微控制器）：集成 CPU、存储器和外设的单片机，如 STM32、Arduino。
- **DSP**（数字信号处理器）：专用于高速数字信号处理的芯片。
- **FPGA**（现场可编程门阵列）：用户可编程的逻辑器件，用于灵活设计数字电路。
- **MEMS**（Micro-Electro-Mechanical Systems，微机电系统）：集微型传感器、执行器以及信号处理电路于一体的微型系统。通过微加工技术将机械元件和电子元件集成在同一芯片上，实现对物理量（如加速度、压力、温度等）的检测和控制。
- **IMU**（Inertial Measurement Unit，惯性测量单元）：用于测量物体三轴姿态角（或角速率）以及加速度的装置。核心组件包括陀螺仪和加速度计，一些高级 IMU 还配备了磁力计，用于协助校准方向漂移，从而提高测量的准确性。
- **PCB**（Printed Circuit Board）：印刷电路板，用于固定和连接电子元件。
- **PCBA**（PCB Assembly，PCB 组装）：将电子元件安装到印刷电路板上的过程。
