# 发光二极管 LED：发光原理、限流与驱动

在本节中，你将认识一种既常见又富有魅力的电子元件 —— **发光二极管**（Light Emitting Diode，简称 LED）。从电路指示灯、数码管、彩色灯带，到电视、照明灯具，LED 无处不在。它不仅能发光，还节能、长寿命，是现代电子设计中不可或缺的元件。



## 发光二极管的作用

发光二极管是一种能够将电能转换为光能的半导体器件，主要用于：

- **状态指示**：如电源是否接通、设备是否运行等；
- **照明**：家用灯具、应急灯、汽车灯等；
- **显示**：数码管、LED 屏幕；
- **装饰**：灯带、氛围灯；
- **传感与通信**：红外遥控器、光通信等。



## 工作原理

LED 的工作原理其实和普通二极管类似——它允许电流只在一个方向流动，但不同的是，它在导通时会发出光。

LED 是由不同材料的半导体 PN 结构组成。当你给它施加正向电压时，电子和空穴在 PN 结处复合并释放能量，部分能量以光子的形式释放出来，这就是你看到的光。

不同的半导体材料决定了发出的光的颜色，比如：

| 发光颜色 |    材料例子    | 正向电压范围 |
| :------: | :------------: | :----------: |
|   红色   | GaAsP、AlGaInP |  1.8～2.2V   |
|   绿色   |   GaP、InGaN   |  2.0～3.2V   |
|   蓝色   |  InGaN、ZnSe   |  3.0～3.6V   |
|   白色   |  蓝光+荧光粉   |  3.0～3.6V   |



## 主要类型

LED 的种类非常丰富，你可以根据颜色、封装、亮度等多种标准进行分类：

#### 按颜色分类

- 单色 LED：常见的红、绿、黄、蓝、白；
- 多色 LED：如双色（红+绿）、三色 RGB（红绿蓝）等；
- 红外 LED：发射不可见红外光，用于遥控器。

#### 按封装分类

- 普通直插式 LED：5mm、3mm 等圆头；
- SMD LED：贴片式，广泛用于小型电子设备；
- COB LED：大功率发光模块，用于照明；
- 数码管/点阵模块：用于数字和字符显示。

#### 特殊类型

- 闪烁 LED：内置振荡电路，自动闪烁；
- 高亮度 LED：用于照明；
- 红外发射管：用于红外通信；
- UV LED：发射紫外光，用于杀菌、固化等。



## 如何使用 LED

### 限流电阻不可少

LED 是电流敏感型元件，如果直接接电源，可能会烧毁。所以你必须为它**串联一个限流电阻**。

例如，使用 5V 电源、红色 LED（正向电压 2V）、希望工作电流为 10mA：

```markdown
电阻值 = (5V - 2V) / 0.01A = 300Ω
```

你可以选择一个 330Ω 的标准电阻。

### 极性要分清

LED 有两个引脚：

- 长脚是正极（阳极）；
- 短脚是负极（阴极）；
- 扁平边或内部小电极也是负极。

在电路中，一定要正向连接，否则 LED 不会发光。



## 选型建议与注意事项

1. 根据供电电压和期望电流计算限流电阻；
2. 注意正向电压，不同颜色的 LED 差异较大；
3. 若需更高亮度，可考虑高亮或大功率 LED；
4. 若用于照明，需配散热片或铝基板；
5. 注意使用合适的电源，避免过压烧毁 LED。
