# 电子器件基础教程：电阻电容到半导体与常用模块

![](./images/Basic-Electronic-Components-Featured-Image.jpg#center)

《电子器件基础教程》带你认识电路中最常用的元器件：从电阻、电容、电感，到二极管、三极管、继电器，再到显示、传感、电池与嵌入式存储。每一篇都尽量讲清它是什么、为什么用、怎么选、怎么接，方便你边学边做。

你可以按侧边栏分组查找：

1. **无源元件** — 电阻、电容、电感、变压器及光敏/热敏电阻  
2. **半导体器件** — 二极管、LED、晶体管/三极管、光耦  
3. **机电与执行器** — 开关、继电器、电机、蜂鸣器  
4. **显示与交互** — LCD、数码管、麦克风、红外收发  
5. **电源** — 电池等供电相关器件  
6. **传感器** — 霍尔传感器等检测类器件  
7. **存储** — Flash、eMMC 等存储器件  
8. **连接器件** — iButton、简牛连接器等互联接口  
9. **附录** — 电子器件名词解释  

建议从[电阻](/electronic-components/resistors/)开始，再逐步进入电容、二极管和三极管；做创客项目时，可按需查阅执行器、显示与存储相关章节。
