# EMW3080

![](https://static.getiot.tech/emw3080.png#center-300)

### 产品介绍

EMW3080 是单 3.3V 供电的、集成 Wi-Fi 和 Cortex-M4F MCU 的嵌入式 Wi-Fi 模块，最高支持 133M 主频和 256K RAM，强大的浮点运算，分为 A（硬件加密版）/ B（标准版）2个版本。

- EMW3080(A)：内部集成加密芯片，为客户固件的完整性、合法性，以及与云端通信的安全性提供硬件加密保障。
- EMW3080(B)：无内部加密芯片，Memory、外设接口资源丰富，能满足大部分应用需求和多云的要求。

另外还有一个 C 版本，是阿里专供模块，转为运行在阿里平台的智能设备提供。

![](https://static.getiot.tech/emw3080-module-block-diagram.png)



### 开发资料

《庆科 EMW3080》里有关于EMW3080模组的相关资料，包括规格书、参考设计、标准AT固件、阿里直连云AT固件及对应的指令、测试工具等等。

1. 拿到模组后首先确认模组内的固件版本号，查询固件版本号命令 `AT+FWVER?`；
2. 如不能响应AT命令，可以通过拉低 BOOT 引脚进入 BOOT 模式，在用户串口（波特率 921600）下输入 QC 查看产测信息，通过产测信息确认模组内固件版本号；
3. 以上两点都不能确认固件版本号时，请重新烧录所需固件；
   - 通过拉低 Debug_TX，进入原厂烧录模式，烧录 all.bin；
   - 通过 SWD 口，用 Jlink 工具搭配庆科上位机软件 MXflash 烧录 all.bin；
   - 通过拉低 BOOT 引脚，进入 BOOT 模式，在用户串口输入"`4 -dev 1`"用 Ymodem 发送 all.bin。
