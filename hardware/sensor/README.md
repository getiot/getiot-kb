# 传感器原理教程：常见传感器工作原理与应用

![传感器原理](https://static.getiot.tech/cover-sensor-tutorial.webp#center)

传感器把物理世界的光、声、力、温度、位置等信息转换成电信号或数据，是物联网与嵌入式系统的入口。本教程按主题分组介绍常见传感器的原理、特点与使用注意，便于你按项目需求查阅。

建议先阅读[传感器概论](/sensor/sensor-overview/)，建立“被测量 → 传感机理 → 信号接口 → 误差与校准”的框架，再按侧边栏进入各专题。

你可以按侧边栏分组查找：

1. **运动与惯性** — IMU、加速度计、陀螺仪、磁力计  
2. **力与压力** — 压力传感器、气压传感器  
3. **环境感知** — 温度、湿度、粉尘、紫外线、环境光  
4. **光学与成像** — 距离/接近、手势、颜色、RGB-D  
5. **位置与磁场** — GNSS 定位、霍尔传感器  
6. **声学传感** — 数字麦克风  
7. **水质检测** — pH、TDS  
8. **生物医疗** — 心率、血氧  

做产品时，请以器件数据手册为准，并在真实整机环境中完成标定与验证。
