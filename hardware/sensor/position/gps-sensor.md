# GPS/GNSS 定位传感器：卫星定位入门

GPS 传感器（更准确常称 **GNSS 模块**）通过接收卫星信号计算接收机的位置、速度与时间。除美国 GPS 外，常见系统还包括北斗（BDS）、GLONASS、Galileo 等，多系统模块往往统称 GNSS。


## 工作原理（简化）

卫星广播带时间戳的信号，接收机测量信号传播时间，估计到多颗卫星的距离，再解算出三维位置。可见卫星数量、几何分布和信号质量决定定位好坏。


## 常见接口与数据

- 串口输出 **NMEA** 语句（如 `$GNGGA`、`$GNRMC`）很常见
- 也有通过 I2C/SPI/USB 提供位置数据的模块
- 关键字段：经纬度、海拔、速度、定位状态、卫星数、时间


## 影响精度的因素

- 天空视野：室内、高楼峡谷、隧道会显著变差或失锁
- 天线质量与放置：天线朝向天空，远离电磁干扰
- 多路径反射：玻璃幕墙、水面会造成误差
- 差分/RTK 等增强技术可提高精度，但系统更复杂


## 应用场景

车载导航、轨迹记录、共享出行、户外运动、农业机械、时间同步（部分场景）等。


## 小结

GNSS 适合**室外开阔环境**的绝对定位。嵌入式集成时重点抓：天线、供电噪声、冷热启动时间，以及 NMEA 解析与定位状态判断（没有 fix 就不要当有效坐标用）。
