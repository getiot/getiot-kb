# 霍尔传感器：霍尔效应与磁场检测应用

霍尔传感器基于**霍尔效应**：电流通过导体/半导体时，在垂直磁场作用下产生横向电势差（霍尔电压）。利用该效应可以检测磁场有无或磁场强弱。


## 常见类型

- **开关型霍尔**：磁场超过阈值输出高低电平，适合接近开关、测速齿盘
- **线性霍尔**：输出随磁场强度变化，适合位置、电流（配合磁芯）等模拟测量
- **锁存型等**：按磁场极性翻转状态，适合转子位置检测


## 应用场景

- 电机/车轮转速测量（磁铁 + 霍尔）
- 盖板开合、门磁类检测
- 无刷电机换相
- 电流检测（闭环霍尔电流传感器模块）


## 使用注意

- 磁铁极性、间距和温度会影响阈值与线性度
- 强干扰磁场会造成误触发
- 与机械结构一起设计，才能保证重复性


## 小结

霍尔传感器是“用磁场做检测”的常用方案，结构简单、寿命长（非接触）。做转速与开合检测时，优先明确用开关型还是线性型。电子元件角度的补充说明也可参考[电子器件教程中的霍尔传感器](/electronic-components/hall-sensor/)。
