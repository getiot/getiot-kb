# 紫外线传感器：UV 指数与紫外辐射检测

紫外线（UV）传感器用于检测紫外辐射强度。紫外线按波长常分为 UVA、UVB、UVC 等波段，对皮肤、材料老化和消毒效果的影响不同。


## 工作原理

常见方案包括：

- **光电二极管 + 紫外滤光**：对特定 UV 波段更敏感，输出光电流或电压；
- **专用 UV 指数传感器 IC**：内部完成滤波与换算，给出与 UV Index 相关的读数。

输出可能是模拟电压，也可能是 I2C 等数字接口。


## 应用场景

- 可穿戴与手机配件：防晒提醒、户外 UV 指数显示
- 紫外消毒设备：灯管工作状态与剂量粗监测（需按产品规范设计）
- 材料与印刷等工业过程中的紫外工艺监控


## 使用注意

- **波段要匹配**：测日光 UVA/UVB 与测 254 nm 消毒灯不是同一回事。
- 避免传感器被普通强可见光饱和；安装角度与遮挡会影响结果。
- UVC 对人体有害，调试消毒设备时务必遵守安全规范。


## 小结

选型时先确认目标波段、量程和输出接口。对创客项目，数字 UV 模块更易上手；对消毒与工业场景，要以器件光谱响应曲线和安全要求为准。
