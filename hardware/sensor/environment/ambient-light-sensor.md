# 环境光传感器：照度检测与自动调光

环境光传感器（Ambient Light Sensor，ALS）用于测量周围可见光强弱，常以**照度**（单位 lux）表示。手机自动调节屏幕亮度，很多就依赖 ALS。


## 工作原理

典型 ALS 使用光电二极管接收光线，经放大器与 ADC 得到与照度相关的数值。较好的器件会尽量贴近人眼视觉响应，并抑制红外干扰，避免“看起来不亮但读数很高”。


## 与接近传感器的关系

手机顶部常把 **ALS + 接近传感器** 做在同一模组：通话靠近脸部时息屏，同时根据环境光调亮度。二者原理不同，但机械上经常相邻布置。


## 应用场景

- 显示设备自动调光
- 智能照明与背光控制
- 根据昼夜切换 UI 或节能策略
- 简易气象/环境节点的光照记录


## 使用注意

- 开孔与导光柱设计会显著影响读数。
- 避免被自身屏幕或指示灯直射造成闭环误调节。
- 动态范围很重要：既要能分辨暗光，又不能在强光下饱和。


## 小结

ALS 是“让设备适应环境亮度”的基础传感器。选型看量程、分辨率、接口（I2C 常见）以及光谱响应是否接近人眼。
