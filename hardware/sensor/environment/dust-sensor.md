# 粉尘传感器：PM2.5/颗粒物浓度检测入门

粉尘传感器（颗粒物传感器）用于估计空气中悬浮颗粒物的浓度，常见输出与 **PM2.5**、**PM10** 等指标相关。它广泛用于空气净化器、新风系统和环境检测仪。


## 常见原理

主流消费级方案多为**光学散射法**：

1. 风扇或气流把空气送入检测腔；
2. 激光/红外光照射颗粒；
3. 光电探测器接收散射光；
4. 根据散射强度与粒径模型估计质量浓度或粒子计数。

实验室级还可能使用称重法、β射线衰减等，成本和体积通常更高。


## 能说明什么、不能说明什么

- **能**：反映空气中颗粒物大致水平，用于“变脏/变干净”的趋势监测与风机控制。
- **不能**：精确替代官方环境监测站；不同品牌算法、校准与气流设计会导致读数差异。
- 对烟雾、水雾也可能有响应，需要结合场景理解。


## 使用注意

- 进风口防堵，定期清洁或更换滤网相关结构。
- 注意供电噪声与风扇振动对读数的影响。
- 室外雨雾、高湿环境可能导致误判，需结合湿度传感器做策略。


## 应用场景

空气净化器自动控制、室内空气质量显示、智慧楼宇、简易环境站、创客空气监测项目等。


## 小结

粉尘传感器适合做**趋势与控制**，不要把它当成法定计量仪器。联调时建议与温湿度一起采集，并给读数做滑动平均，减少抖动。
