# 血氧传感器：SpO2 脉搏血氧测量原理

血氧传感器常指脉搏血氧检测方案，用于估计血氧饱和度 **SpO2** 与脉搏率。医疗场景有指夹式脉搏血氧仪；消费电子则常见于手环、手表等穿戴设备。


## 工作原理

1. 使用红光（约 660 nm）与红外光（约 940 nm）LED 照射组织；
2. 光电探测器接收透射或反射光；
3. 氧合血红蛋白与还原血红蛋白对不同波长吸收不同；
4. 通过两路光吸收比值，结合标定模型估计 SpO2。

计算常与比尔-朗伯特定律相关的光吸收模型有关，实际产品还依赖大量标定与信号处理。


## 应用场景

围术期与重症监测、慢病管理、高原与运动场景的血氧趋势观察、消费级穿戴健康提醒等。


:::warning

消费级穿戴的血氧读数多用于参考与趋势，不能简单替代医疗诊断设备。涉及健康决策请遵循医疗规范。

:::


## 常见模组示例

### MAX30102

MAX30102 是集成脉搏血氧与心率监测的光学生物传感器模组，内含红光/红外 LED、光电检测器与环境光抑制等电路，常出现在创客与可穿戴原型中。具体指标以厂家数据手册为准。


## 小结

血氧测量的核心是**双波长光学差分 + 标定**。做产品时要把光学结构、佩戴稳定性和运动伪影处理放到和传感器芯片同等重要的位置。
