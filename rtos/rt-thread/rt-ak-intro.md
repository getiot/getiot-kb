# RT-AK 简介

RT-AK 是 RT-Thread 团队为 RT-Thread 实时操作系统所开发的 AI 套件，能够一键将 AI 模型部署到 RT-Thread 项目中，使用户可以在统一的 API 上进行业务代码开发，又能在目标平台上获得极致优化的性能，从而更简单方便地开发端侧 AI 应用程序。

GitHub 地址：[https://github.com/RT-Thread/RT-AK](https://github.com/RT-Thread/RT-AK)

在 RT-AK 支持下，仅需要一行命令，`python aitools.py --model xxx...`，即可将 AI 模型部署到 RT-Thread 系统中。
