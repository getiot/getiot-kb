# RT-Thread 教程

![RT-Thread 教程](https://static.getiot.tech/cover-rtthread-tutorial.webp#center)

RT-Thread 是一款面向嵌入式系统的开源实时操作系统，具有优秀的可裁剪性和可扩展性。其设计目标是为嵌入式设备提供一个高效、小巧的实时内核，适用于从微控制器到 ARM Cortex-M/R、MIPS、x86、RISC-V 等不同架构的嵌入式系统。

本教程从零开始介绍 RT-Thread 的基础概念、开发环境搭建和工程创建、线程与任务管理、设备驱动与外设使用、网络通信与协议栈、文件系统与存储，以及 RT-Thread 软件包生态。
