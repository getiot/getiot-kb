# Mbed OS 教程

![Mbed OS 教程](https://static.getiot.tech/cover-mbedos-tutorial.webp#center)

2018年10月22日下午消息，据中国台湾地区媒体报道，近日 ARM 推出新的物联网操作系统 Mbed Linux OS。

ARM 表示，推出 Mbed Linux OS 的目的，就是建立 IoT 产品的基础模块，让其他厂商可以集中开发附加价值高的功能。此外，该操作系统也与自家物联网管理平台 Pelion 深度整合，企业用户可以直接执行装置建置、更新，并确保设备连线正常。

自 2014 年开始，ARM 就推出自家物联网平台 Mbed，涵括专用作业系统 Mbed OS、服务器以及微控制器。　

ARM 表示，Mbed Linux OS 既延续 Mbed OS 的特点，同样使用 Cortex-A 架构。同时，Mbed Linux OS 采取开源放出，并整合 Linux Kernel 以及 Yocto 方案。随着 Cortex-A 的性价比逐渐提高，即便是物联网装置，未来也有可能处理更为复杂的应用程序。如此一来，除了可以增加服务可用性外，企业亦能减少部署于边缘环境的装置数量。

而这一款新推出的物联网作业系统，也和开发者常用的容器技术接轨，应用程序可透过相容开放容器标准（OCI）的容器，进行打包。而 Mbed Linux OS 可以和企业内部的持续整合、测试流程结合，借以加快物联网应用程式的部署速度。此外，企业内部个别开发团队也可针对不同的应用需求，独立更新操作系统、固件。
