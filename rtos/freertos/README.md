# FreeRTOS 教程

![FreeRTOS 教程](https://static.getiot.tech/cover-freertos-tutorial.webp#center)

FreeRTOS 是一款由英国工程师 Richard Barry 创建的实时操作系统，其设计目标是提供轻量级、可移植、开放源代码的实时内核。FreeRTOS 支持多种处理器架构，包括 ARM、MIPS、RISC-V 等，广泛应用于各种微控制器和嵌入式设备。

本教程将介绍 FreeRTOS 的基本概念，包括任务、调度器、信号量、定时器等，学习如何搭建 FreeRTOS 的开发环境，并通过实际案例学习如何开发基于 FreeRTOS 的项目。
