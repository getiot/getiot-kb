# μCOS-II 教程 📚

![uCOS-II/III 教程](https://static.getiot.tech/cover-ucos-tutorial.webp#center)

uCOS（MicroC/OS，μCOS）是一款经典的嵌入式实时操作系统（RTOS），由美国 Micrium 公司开发，被广泛应用于嵌入式系统的开发中，包括通信、汽车电子、工业控制等领域。虽然如今 uC/OS 的市场热度有所下降，但学习它仍然有很多好处，通过学习 uC/OS 可以为以后理解和构建更现代化的 RTOS 打下坚实基础。

uCOS 主要有两个版本 —— uCOS-II 和 uCOS-III，本教程将着重介绍 uCOS-II 任务调度、消息传递、信号量、定时器、中断服务、内存管理等实时操作系统特性，并对比 uCOS-II 和 uCOS-III 的区别。从基础概念到高级应用，助你在嵌入式世界中驾驭实时操作系统的精髓。
