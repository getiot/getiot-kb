# Zephyr 嵌入式实时操作系统

![Zephyr 教程](https://static.getiot.tech/cover-zephyr-tutorial.webp#center)

Zephyr 是由 Linux 基金会支持的开源项目，设计目标是为微控制器和嵌入式设备提供轻量级、可裁剪的实时内核。其采用模块化的设计，使得用户能够根据项目需求选择性地保留或删除功能，实现更灵活的定制。

如果你是第一次接触实时操作系统和 Zephyr，本教程将从基础开始，引导你逐步了解 Zephyr 的核心概念和功能。对于有经验的开发者，我们提供了高级特性和最佳实践，以优化 Zephyr 的使用和性能。
